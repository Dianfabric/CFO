## 1. 개요

### 1.1 목적
본 카테고리는 **디안의 가격 결정을 "그때그때"의 직관에서 "체계"의 의사결정으로 전환**하는 것을 목적으로 한다. 가격이 가장 강력한 이익 동인임을 인식하고, 각 제품·각 거래처에 대한 가격 결정이 명확한 전략과 데이터에 근거하여 이루어지도록 한다.

### 1.2 배경
**디안의 현재 상태 (대표님 자기 진단)**:
- 가격 결정 방식: 체계적이지 않고 그때그때
- 가격 포지셔닝: 저가 ~ 프리미엄까지 운영 중, 럭셔리 도전 예정 (멀티 티어)

**책의 핵심 진단**:
- *"가격은 가장 적게 주목받지만 가장 강력한 효과를 발휘한다."*
- *"CEO가 직접 가격 결정에 참여하는 기업은 35% 더 높은 가격결정력을 보유한다."*
- *"가격 전략을 전문적으로 잘 실천에 옮기면, 순영업이익률이 대체로 2~4%포인트 사이로 올라갈 수 있다."*

따라서 본 카테고리는 **디안에 가장 큰 이익 임팩트를 만들 가능성이 있는 영역**이다. 영업이익률 2~4%포인트 개선은 디안 규모에서 의미 있는 절대 금액 차이를 만든다.

### 1.3 카테고리의 위치
본 카테고리는 디안 대시보드 7대 영역 중 **#4 영역**이며, 다음과 같은 양방향 흐름의 중심에 있다.

- **입력**: #3 측정·분해의 공헌이익 데이터 + #2a 영업의 거래처 협상 정보 + #2b 마케팅의 가치 소통 자료
- **출력**: 결정된 가격 정책 → #2a 영업 (협상 가이드) + #2b 마케팅 (가치 소통 메시지) + #2c 운영 (실제 가격표) + #3 측정 (가격 변경 이후 이익 영향 추적)

### 1.4 핵심 철학 (책에서 추출)
다음 메시지들은 본 카테고리의 모든 페이지·기능 설계의 변하지 않는 기준이다.

- **"전략이 가격을 결정하지, 가격이 전략을 결정하지 않는다."** ― 가격 결정 전에 항상 포지셔닝·가치·이익 목표가 먼저 정의되어야 한다.
- **"가치 = 가격의 정당성"** ― 모든 가격은 그에 상응하는 가치(본질적·확장적)로 뒷받침되어야 한다.
- **"매출은 사람을 우쭐하게 만들고, 이익은 사람을 부유하게 만든다."** ― 시장점유율·매출 추구의 함정에서 벗어나 이익에 집중한다.
- **"집중이 이익의 견인차다. 힘의 분산은 이익 파괴자다."** ― 멀티티어 운영에서 라인 간 명확한 분리가 필수.
- **"가격은 너무나 바꾸기 쉽기 때문에, 가격 변경의 이점은 경쟁자에 의해 곧바로 사라져버린다."** ― 가격 결정은 신중하고 일관되게.

## 2. 핵심 원칙

1. **CEO 참여 강제**: 모든 신제품 가격, 주요 거래처 가격 변경, 할인 결정은 CEO 승인 워크플로우를 거친다. 책의 35% 가격결정력 데이터에 근거.
2. **4단계 프로세스 의무화**: 모든 가격 결정은 **전략 → 분석 → 의사결정 → 시행/감시**의 4단계를 통과한다. "그때그때"를 시스템적으로 차단.
3. **티어별 분리 운영**: 저가·프리미엄·럭셔리 각 라인은 별도 식별자·별도 가격 정책·별도 할인 규칙을 갖는다. 라인 간 메시지 충돌 방지.
4. **할인은 예외, 정상가가 원칙**: 할인은 자동 차단, 의식적 사유와 승인을 거쳐야만 가능. 책의 "프리미엄/럭셔리에서 할인은 자기파괴" 메시지 반영.
5. **가치-가격 정합성 자가점검**: 디안 자기 인식(프리미엄)과 실제 매출총이익률이 정합하는지 자동 모니터링. 책의 *"매출총이익이 25%밖에 안 된다면 자기기만"* 경고 자동화.

## 3. 사용자 시나리오

### 3.1 페르소나

**페르소나 A: 대표 (CEO)**
- 신제품 출시 시 가격 결정 워크플로우 주도
- 주요 거래처 가격 협상 시 시뮬레이션 활용
- 분기별 가격 정책 검토
- 할인 승인 의사결정

**페르소나 B: 영업 임원·팀원**
- 거래처별 가격 협상 시 가이드 라인 참고
- 할인 요청 시 시뮬레이터로 영향 파악 후 승인 요청
- 거래처별 가격 이력·차별화 정책 조회

**페르소나 C: 마케팅 임원·팀원**
- 각 라인의 가치 소통 메시지 작성 시 포지셔닝 매트릭스 참고
- 가격 심리학 도구로 표시 가격·번들 패키지 설계

### 3.2 핵심 사용자 여정

**여정 1: 신제품 가격 결정 (대표 + 영업 + 마케팅)**
1. ① 가격 포지셔닝 매트릭스에서 신제품의 티어 결정 (저가/프리미엄/럭셔리)
2. ② 가치 정의 워크북에서 본질적 가치 + 확장 가치 명문화
3. ③ 4단계 가격 책정 워크플로우 시작
   - 전략 단계: 포지셔닝·이익 목표 확인
   - 분석 단계: 원가 + 경쟁사 가격 + 고객 지불용의 분석
   - 의사결정 단계: ④ 가격-이익 시뮬레이션으로 영향 검증
   - 시행/감시 단계: 가격 확정 → ⑥ 가격 심리학 적용 → 발표 일정
4. CEO 승인 → 가격 적용 → 90일 후 ⑧ 가격 결정 이력에서 결과 검증

**여정 2: 거래처 가격 협상 (영업)**
1. ⑤ 가격 차별화 매트릭스에서 해당 거래처의 등급·기존 가격 확인
2. 협상 시 시뮬레이터로 *"이 거래처에 −5% 할인하면 공헌이익에 어떤 영향?"* 즉시 계산
3. 임계값 초과 시 자동 CEO 승인 요청
4. 협상 결과는 ⑧ 가격 결정 이력에 기록 (성공/실패 학습 자산화)

**여정 3: 가격 인상 검토 (분기 단위)**
1. ⑦ 경쟁사 가격 모니터링에서 시장 가격 동향 확인
2. ④ 가격-이익 시뮬레이션에서 +3% / +5% / +7% 시나리오
3. 책의 데이터 *"평균적 회사는 1% 가격 인상 시 영업이익 10~15% 증가"* 적용
4. 시뮬레이션 결과 + 가치 소통 계획 → CEO 승인 → 단계적 시행

**여정 4: 럭셔리 라인 출시 준비 (대표)**
1. ① 매트릭스에 신규 럭셔리 라인 등록 + 명확한 분리 (별도 브랜드·채널·인력)
2. ② 가치 정의 워크북에 럭셔리 라인의 본질·확장 가치 정의 (희소성·장인정신·고객 경험)
3. ③ 4단계 프로세스에서 *"고객의 지불용의"*를 가격 결정의 최우선 인풋으로 설정 (책의 럭셔리 원칙)
4. 할인 정책: 절대 금지로 시스템 설정
5. ⑤ 차별화 매트릭스에서 럭셔리 라인은 일반 거래처에서 제외, 별도 채널로 배정

### 4.1 ① 가격 포지셔닝 매트릭스

**목적**: 디안의 모든 제품·라인을 **저가/중가/프리미엄/럭셔리** 4티어 중 하나로 명확히 분류하고 명문화한다. 멀티티어의 핵심 도구.

**주요 컴포넌트**:
- (상단) 4분면 매트릭스:
  - 가로축: 가격 (저 → 고)
  - 세로축: 가치 (저 → 고)
  - 4분면: 저가 / 가성비(중가) / 프리미엄 / 럭셔리
  - 각 제품·라인을 점으로 배치
- (중단) 라인별 카드:
  - 라인명 (저가 라인은 별도 브랜드명 권장 ― 책의 메시지 분리 원칙)
  - 티어 분류
  - 핵심 메시지 (저가는 가격, 프리미엄은 가치, 럭셔리는 희소성)
  - 타겟 거래처 유형 (가구사 / 디자이너 / 스튜디오 / 럭셔리 컨설턴트)
  - 채널 분리 (어떤 채널에서만 판매되는지)
- (하단) **티어 일관성 체크리스트** (자동):
  - 이 라인의 매출총이익률은 티어와 정합하는가? (저가 ≈ 20-30% / 프리미엄 ≈ 50-60% / 럭셔리 ≈ 70%+)
  - 이 라인이 정의된 채널에서만 판매되는가?
  - 이 라인의 할인 빈도가 티어 원칙을 벗어나지 않는가?
  - 경고: *"우리는 프리미엄이라고 정의했는데 매출총이익이 25%밖에 안 됩니다 ― 자기기만 가능성"*

**핵심 인터랙션**:
- 신제품 등록 시 티어 분류가 필수
- 매트릭스 위치 변경 시 모든 연관 정책 자동 재검토 알림
- 티어별 성공 요인 가이드 자동 표시 (책의 8/8/8가지 성공 요인 체크리스트)

**시각 요소**:
- 4분면 산점도
- 라인별 카드 그리드
- 정합성 신호등 (✓ / ⚠ / ✗)

**권한**:
- 임원·대표: 작성·수정
- 전 직원: 조회

---

### 4.2 ② 가치 정의 워크북

**목적**: 책의 *"가치를 창조하라 / 소통하라 / 보존하라"* 3원칙에 따라, 각 제품·라인의 가치를 본질적 차원과 확장적 차원으로 명문화한다.

**주요 컴포넌트**:
- (상단) 라인 선택 + 본질적 가치 영역:
  - 기본 기능과 품질 (예: 내구성 30,000+ Martindale)
  - 내구성·신뢰성 (방오·방염·방수 스펙)
  - 사용 편의성·접근성
- (중단) 확장적 가치 (2차 효과) 영역:
  - 브랜드 이미지 (디안의 "텍스처 큐레이터" 정체성)
  - 감성적 만족 (촉각·시각·공간감 표현)
  - 사후 서비스·지원 (스왓치·재고 보장·맞춤 컷)
  - 고객 경험 총체성 (디안과 거래하는 전 과정)
- (중단) **B2B 가치의 수치화** (책의 핵심 메시지):
  - *"B2B에서는 가능한 한 자주 명확한 데이터를 이용해 가치를 소통하라"*
  - 디자이너 입장의 ROI: "이 원단을 쓰면 시공 시간 X% 단축, 클레임률 Y% 감소"
  - 가구 제작사 입장의 ROI: "내구성으로 사후 클레임 비용 Z원 절감"
  - 자동 카드 생성: "가치 소통용 한 줄"
- (하단) 가치-가격 정합성 자동 점검:
  - 정의된 가치 vs 책정된 가격
  - 책의 50% 룰 적용: *"20% 높은 가치 → 10% 가격 프리미엄"*
  - 정합성 점수

**핵심 인터랙션**:
- 작성 완료 시 #2b 마케팅·브랜딩 카테고리에 자동 송출 (스토리텔링·콘텐츠 작성 인풋)
- 작성 완료 시 #2a 영업 카테고리에 자동 송출 (협상 가이드)
- 분기마다 가치 정의 검토 알림 (가치는 시간에 따라 변함)

**시각 요소**:
- 본질·확장 가치 트리
- ROI 카드 (가치 소통용)
- 정합성 게이지

**권한**:
- 대표·마케팅 임원: 작성·수정
- 전 직원: 조회 (책의 "투명성" 원칙)

### 4.3 ③ 4단계 가격 책정 워크플로우

**목적**: 책의 4단계 가격 책정 프로세스(전략·분석·의사결정·시행/감시)를 디안의 모든 가격 결정에 강제 적용한다. **"그때그때"를 시스템적으로 차단**하는 핵심 도구.

**워크플로우 단계**:

**[Step 1] 전략 단계**
- 의사결정 대상 (신제품 / 기존제품 인상·인하 / 거래처별 차별화 / 캠페인 가격)
- 포지셔닝 확인 (① 매트릭스에서 자동 가져오기)
- 이익 목표 설정 (목표 공헌이익률, 목표 매출총이익률)
- 책의 자동 점검: *"이번 결정이 단기 매출이 아니라 이익을 우선하는가?"*

**[Step 2] 분석 단계**
- 원가 분석 (#3 측정·분해에서 자동 가져오기)
  - 단위 변동비
  - 배분된 고정비
  - 활동기준 원가 (해당 거래처에 들이는 영업 시간)
- 경쟁사 가격 분석 (⑦ 경쟁사 모니터링에서 가져오기)
- 고객 지불용의 (Willingness to Pay) 입력 영역
  - 영업이 거래처와의 대화에서 추정한 가격 한계
  - 과거 협상 이력
- 3가지 가격 책정 방식 결과 자동 비교:
  - **원가 기반** (총원가 + 목표 마진)
  - **경쟁 기반** (경쟁사 ± 가치 차이)
  - **가치 기반** (고객 지불용의 기준)

**[Step 3] 의사결정 단계**
- 후보 가격안 입력 (보통 3개)
- 각 안에 대해 ④ 가격-이익 시뮬레이션 자동 실행
- 의사결정 매트릭스:
  - 가격 안 × 판매량 시나리오 (낮음·중간·높음) = 9개 결과
  - 각 셀에 공헌이익·영업이익 표시
- 책의 핵심 점검: *"이 결정이 가격 동인을 활용하는가, 아니면 무의식적으로 판매량 동인에 의존하는가?"*
- CEO 승인 워크플로우 (책의 35% 데이터 근거)

**[Step 4] 시행/감시 단계**
- 가격 확정 + 시행일
- ⑥ 가격 심리학 적용 (표시 방식·번들·앵커링)
- 가치 소통 계획 (#2b 마케팅에 자동 연결)
- 영업 가이드 자동 생성 (#2a 영업에 자동 송출)
- **90일 후 자동 검증**:
  - 실제 판매량 vs 예측
  - 실제 공헌이익 vs 예측
  - 거래처 반응 (#2a 활동 다이어리에서 자동 수집)
  - ⑧ 가격 결정 이력에 자동 기록

**핵심 인터랙션**:
- Step 1~4 진행 상황 진척도 표시
- 각 단계 미완료 시 다음 단계 진행 차단
- Step 1, 2 자동 인풋 가능 항목은 자동 채움 (수동 입력 최소화)

**시각 요소**:
- 4단계 진척도 바
- 의사결정 매트릭스 (3×3 시나리오)
- 후보 가격안 비교 카드

**권한**:
- 영업·마케팅 임원: 시작·진행
- 대표: 의사결정 단계 승인 권한
- 전 직원: 진행 상황 조회 (Step 4 시행일 이후만)

### 4.4 ④ 가격-이익 시뮬레이션

**목적**: 가격 변경 시 공헌이익·영업이익에 미치는 영향을 즉시 시뮬레이션한다. ③ 워크플로우의 의사결정 단계에서 핵심 도구.

**주요 컴포넌트**:
- (상단) 시나리오 입력:
  - 대상 제품·라인 선택 (또는 전체)
  - 가격 변동률 슬라이더: −20% ~ +20%
  - 가격 변동 시 판매량 변동 가정 (탄력성 입력)
  - 적용 기간 (월/분기/12주)
- (중단) 즉시 시뮬레이션 결과:
  - 매출 변화
  - 공헌이익 변화 (절대값 + %)
  - 영업이익 변화
  - 손익분기점 변화
  - 책의 데이터 자동 표시: *"평균적으로 1% 가격 인상 시 영업이익 10~15% 증가, 1% 인하 시 10~15% 감소"*
- (중단) 가격 탄력성 학습:
  - 과거 가격 변경 + 판매량 변화 데이터에서 자동 추정
  - 라인별·거래처별 탄력성 학습
- (하단) 비교 시나리오:
  - 가격 +5% / +3% / 동결 / -3% / -5% 동시 비교
  - 각 시나리오의 최선·최악·기대 결과
  - 추천 안 자동 표시 (이익 극대화 + 위험 최소화)

**핵심 인터랙션**:
- 슬라이더로 즉각 반응
- 시나리오 저장 → ③ 워크플로우 의사결정 단계에 자동 첨부
- 가격 인하 시 *"필요한 추가 판매량은 X%"* 자동 계산 (책의 "한계수입 = 한계비용" 원리)

**시각 요소**:
- 슬라이더 + 즉시 결과 카드
- 시나리오 비교 매트릭스
- 손익분기점 그래프 (#3 카테고리와 연동)

**권한**:
- 임원·대표 전용 (가격 정보 보호)

---

### 4.5 ⑤ 가격 차별화 매트릭스

**목적**: 책의 *"가격 차별은 현대 경제의 필수 요소"* 메시지에 따라, 거래처·세그먼트별 차별화된 가격 정책을 체계화한다. 디안 같은 B2B에서 특히 중요.

**주요 컴포넌트**:
- (상단) 거래처 등급 정의 (#3 ⑤ 고객 수익성 분석과 연동):
  - VIP / 일반 / 소규모 / 럭셔리 전용
  - 각 등급별 기본 가격 정책 (정상가 대비 %)
- (중단) 거래처 × 라인 매트릭스:
  - 가로축: 라인 (저가 / 중가 / 프리미엄 / 럭셔리)
  - 세로축: 거래처 등급
  - 셀: 적용 가격 정책 (정상가, 5% 할인, 10% 할인, 거래 금지 등)
  - 럭셔리 라인 + 일반 거래처 = 자동 차단 (책의 럭셔리 원칙)
- (중단) **묶음 가격(Bundle) 설계**:
  - 패키지 상품 구성 (예: "벽패널 풀 솔루션 ― 원단 + 시공 가이드 + 샘플북")
  - 옵션 아이템 활용
  - 총합 대비 할인 제공
  - 책의 "묶음가격" 전략 적용
- (중단) **할인 구조**:
  - 증분할인 (특정 수량 초과 시) ― 판매자 유리
  - 전량할인 (전체 수량에 적용) ― 구매자 유리
  - 복수고객 할인 (대형 스튜디오 그룹)
  - 책의 가이드라인 자동 표시
- (하단) 차별화 결과 모니터링:
  - 등급별 평균 마진율
  - 차별화의 이익 임팩트
  - 등급 간 가격 누수 (정보 노출 위험) 점검

**핵심 인터랙션**:
- 거래처 등급 변경 시 자동 가격 정책 업데이트 알림
- 새로운 거래처 추가 시 자동 등급 추천 (#3 수익성 분석 기반)
- 할인 결정은 임계값 초과 시 CEO 승인 워크플로우

**시각 요소**:
- 매트릭스 그리드
- 번들 패키지 카드
- 등급별 마진 히트맵

**권한**:
- 대표·영업 임원: 작성·수정
- 영업 팀원: 본인 담당 거래처 조회·협상 가이드 활용
- 전 직원 노출 금지 (가격 차별화 정보는 매우 민감)

### 4.6 ⑥ 가격 심리학 적용 도구

**목적**: 책의 가격 결정 심리학(앵커링·문턱 가격·9.99·손실 회피)을 디안의 가격 표시·패키징·소통에 적용한다.

**주요 컴포넌트**:
- (상단) 가격 표시 최적화:
  - 통화 기호 사용 여부 (책: *"$ 표시 없으면 뇌의 통증 중추 자극이 약해짐"*)
  - 문턱 가격 (예: 100만원 → 99.9만원)
  - 9.99 가격 적용 여부 (저가·중가 라인에 권장, 프리미엄·럭셔리에는 비권장)
- (중단) 앵커링 효과 도구:
  - "효자 상품" 설정 (책의 캐리어 사례 ― 900달러짜리를 진열해 다른 상품을 사게 만드는 효과)
  - 디안 적용: 럭셔리 라인 진열로 프리미엄 라인 판매 촉진
  - 중간 가격대 권장 표시 (책의 "중간의 마법")
- (중단) 손실 회피 활용:
  - "기존 거래처 5% 인상" vs "신규 거래처 5% 할인" 효과 비교 (책: 손실의 고통이 이득보다 큼)
  - 보장 정책 설계 (반품·교환·하자 보증)
- (중단) 지불 방식 영향:
  - 후불 / 분할 / 일시불 옵션
  - B2B 거래에서의 지불 조건 설계
- (하단) 라인별 권장 적용:
  - 저가: 9.99 + 가격 강조 광고
  - 프리미엄: 가격 표시 절제 + 가치 강조
  - 럭셔리: 가격은 문의 ("Price upon request") 옵션

**핵심 인터랙션**:
- ③ 워크플로우 Step 4 시행 단계에서 자동 호출
- 라인별 권장사항 자동 적용
- 적용 결과 → ⑧ 이력에 기록

**시각 요소**:
- 가격 표시 미리보기
- 심리학 효과 가이드 카드
- 지불 방식 비교 표

**권한**:
- 대표·마케팅 임원: 설정
- 영업 팀원: 가이드 조회

### 4.7 ⑦ 경쟁사 가격 모니터링

**목적**: 디안의 가격 결정에 필요한 경쟁사 정보를 체계적으로 수집·분석한다.

**주요 컴포넌트**:
- (상단) 경쟁사 마스터:
  - 직접 경쟁사 (동일 티어 원단 유통사)
  - 간접 경쟁사 (다른 티어, 대체재)
  - 럭셔리 진입 시 글로벌 럭셔리 원단 브랜드 추가
- (중단) 가격 정보 수집:
  - 수동 입력 (영업이 시장에서 수집한 정보)
  - 공개 가격 자동 수집 (가능한 경우)
  - 거래처 피드백 ("경쟁사가 X원에 제안했음")
- (중단) **포지셔닝 맵**:
  - 가로축: 가격
  - 세로축: 가치 (인지)
  - 디안의 라인 + 경쟁사 점들 배치
  - 책의 "가격-가치 그래프" 시각화
- (하단) 경쟁 대응 의사결정 가이드:
  - 경쟁사 가격 인하 시: 자동 추천 (가치 강조 vs 일부 인하 vs 무대응)
  - 책의 핵심 경고: *"가격 변경의 이점은 경쟁사에 의해 곧바로 사라지므로, 신중하라"*

**핵심 인터랙션**:
- 영업의 시장 정보 수집을 ⑦ 페이지에 직접 입력 가능
- 정보 수집 시 #2a 영업 카테고리의 활동 다이어리에서 자동 추출
- 분기별 경쟁 상황 리포트 자동 생성

**시각 요소**:
- 경쟁사 카드
- 포지셔닝 맵 (가격-가치)
- 가격 추세 라인

**권한**:
- 임원·대표: 전체
- 영업 팀원: 정보 입력 + 본인 거래 관련 조회

### 4.8 ⑧ 가격 결정 이력 (Pricing Decision Log)

**목적**: **"그때그때"를 "체계적 학습"으로 전환**하는 핵심 도구. 모든 가격 결정을 기록하고, 90일 후 자동 검증하여 학습 자산으로 축적한다.

**주요 컴포넌트**:
- (상단) 결정 기록 카드 (시간순):
  - 결정 일자
  - 대상 (제품·라인·거래처)
  - 결정 유형 (신제품 가격 / 인상 / 인하 / 할인 / 차별화)
  - 결정한 가격
  - 결정 근거 (③ 워크플로우의 4단계 요약)
  - CEO 승인 여부
- (중단) **90일 후 자동 검증** (결정 후 90일이 지나면 자동 활성화):
  - 예측 판매량 vs 실제 판매량
  - 예측 공헌이익 vs 실제 공헌이익
  - 거래처 반응 (#2a 영업의 활동 다이어리에서 추출)
  - 의사결정의 질 점수 (1~5)
- (중단) **학습 노트**:
  - 잘 된 점 / 잘못된 점
  - 다음 유사 결정에 가져갈 학습
  - 책의 "차이와 분석의 학습 구조" 적용
- (하단) 패턴 분석:
  - 거래처별 가격 결정 성공률
  - 라인별 가격 결정 성공률
  - 인상 vs 인하의 평균 성공률
  - 시간대별 학습 (분기/연 단위)

**핵심 인터랙션**:
- 90일 후 자동 알림 → 학습 노트 작성 요청
- 학습 노트는 #1 사후 검토에 자동 첨부
- 유사한 새 결정 시작 시 과거 학습 자동 추천

**시각 요소**:
- 타임라인 (결정 이력)
- 검증 결과 카드
- 패턴 분석 차트

**권한**:
- 대표·임원: 전체 조회·작성
- 전 직원: 본인 부서 관련 결정 조회 (책의 투명성 원칙)

## 5. 데이터 모델

### 5.1 핵심 엔티티

| 엔티티 | 핵심 필드 | 비고 |
|---|---|---|
| `PriceTier` | id, name(저가/중가/프리미엄/럭셔리), targetMargin, channelRules, discountPolicy | 4티어 정의 |
| `ProductLine` | id, name, brandName, tierId, value_essential, value_extended, valueRoiNote | 가치 정의 포함 |
| `PriceDecision` | id, type(신제품/인상/인하/할인/차별화), targetId, decidedPrice, decisionRationale, ceoApproved, decidedAt | 모든 결정 |
| `PricingWorkflow` | id, decisionId, step1_strategy, step2_analysis, step3_decision, step4_execution, status | 4단계 진행 |
| `PriceSimulation` | id, decisionId, scenario, priceChange, volumeAssumption, predictedContribution, predictedOperatingProfit | 시뮬레이션 |
| `ClientPricing` | id, clientId, lineId, tier, basePolicy(정상가/-X%), bundlePackages, status | 차별화 매트릭스 |
| `Competitor` | id, name, tier, isDirect, products[], priceInfo[] | 경쟁사 모니터링 |
| `PriceDecisionReview` | id, decisionId, reviewedAt(D+90), predictedVsActual, lessonsLearned, qualityScore | 90일 검증 |
| `BundlePackage` | id, lineId, components[], totalPrice, discountFromComponents | 묶음 가격 |
| `Discount` | id, type(증분/전량/복수), threshold, rate, appliedTo, requiresApproval | 할인 구조 |

### 5.2 핵심 관계

- `ProductLine`은 `PriceTier`에 속함 (티어별 정책 자동 적용)
- 모든 `PriceDecision`은 `PricingWorkflow`를 거쳐야 함 (4단계 강제)
- `PriceDecision` 90일 후 → `PriceDecisionReview` 자동 생성
- `ClientPricing`은 `Client` (#3 카테고리) + `ProductLine`의 교집합

### 5.3 외부 연동

- 외부 가격 정보 수집 (선택적): 시장 정보 사이트, 경쟁사 공개 카탈로그
- 거래처 협상 정보 수집: #2a 영업 카테고리 활동 다이어리에서 자동 추출

| ⑤ 가격 차별화 매트릭스 | (조회 금지) | 본인 거래처 | 전체 작성 | 매우 민감 |
| ⑥ 가격 심리학 도구 | 가이드 조회 | 설정 | 설정 | |
| ⑦ 경쟁사 모니터링 | (제한) | 정보 입력+조회 | 전체 | 영업이 주 입력 |
| ⑧ 가격 결정 이력 | 본인 부서 결정 조회 | 본인 부서 결정 조회·작성 | 전체 | 학습 자산화 |

### 6.1 권한 원칙

1. **가격 차별화 정보는 매우 민감**: ⑤ 매트릭스는 영업 외 직원에게 노출 금지. 거래처 간 정보 누수 차단.
2. **CEO 승인 워크플로우**: 신제품 가격, 5% 초과 인상·인하, 임계 할인은 CEO 승인 필수.
3. **포지셔닝·가치 정의는 투명**: ①, ②는 전 직원이 조회 가능 (브랜드 일관성을 위해).

## 9. v1.0 마이그레이션 계획

### 9.1 v1.0과의 관계

v1.0에는 가격 결정·차별화·시뮬레이션 영역이 명시적으로 존재하지 않는다. 본 카테고리는 신규 추가다.

단, 다음 v1.0 자산은 본 카테고리의 데이터 소스로 활용된다:

| v1.0 메뉴 | 본 카테고리에서의 활용 |
|---|---|
| 제품 관리 | ① 포지셔닝 매트릭스의 제품 마스터 |
| 거래처 관리 | ⑤ 가격 차별화 매트릭스의 거래처 |
| 분석/시뮬레이션 | ④ 가격-이익 시뮬레이션의 기반 |
| AI CFO 자문 | ③ 워크플로우의 의사결정 보조 |
| 공문 작성 | 가격 결정 후 거래처 통지 자동화 |

### 9.2 데이터 보존 원칙

- v1.0의 기존 가격 데이터는 **삭제하지 않는다**.
- 본 카테고리 추가는 v1.0 데이터 위에 **포지셔닝 메타데이터, 4단계 워크플로우, 결정 이력**을 얹는 방식.

### 9.3 마스터 데이터 초기 설정 (1회성)

본 카테고리가 작동하려면 다음 마스터 데이터의 1회성 분류 작업이 필요하다.

1. **가격 티어 정의**: 저가/중가/프리미엄/럭셔리 각각의 목표 마진, 채널 규칙, 할인 정책
2. **제품·라인 티어 분류**: 모든 제품을 4티어 중 하나로 매핑
3. **각 라인의 가치 정의**: 본질적·확장적 가치 명문화 (시간 소요)
4. **거래처 등급 가격 정책**: VIP/일반/소규모/럭셔리 전용의 기본 정책
5. **경쟁사 마스터**: 직접·간접 경쟁사 등록

이 분류는 1회 설정 후 신규 데이터에 자동 적용되며, 분기마다 검토·업데이트한다.

## 10. 구현 우선순위 (참고)

| Phase | 페이지 | 비고 |
|---|---|---|
| **P0 (1차)** | ① 포지셔닝 매트릭스, ③ 4단계 워크플로우, ⑧ 결정 이력 | "그때그때"의 즉시 차단 |
| **P1 (2차)** | ② 가치 정의, ④ 시뮬레이션, ⑤ 차별화 매트릭스 | 분석·실행 도구 |
| **P2 (3차)** | ⑥ 심리학 도구, ⑦ 경쟁사 모니터링 | 정교화 단계 |

**P0 우선순위 근거**: 
- ① 매트릭스가 없으면 멀티티어 운영의 충돌이 계속됨
- ③ 워크플로우가 없으면 "그때그때" 결정이 계속됨
- ⑧ 이력이 없으면 학습이 축적되지 않음
- 이 셋이 들어와야 비로소 "체계"가 시작됨

## 11. 미해결 사항 / 추후 결정 필요

### 11.1 대표님 결정 대기

- 디안의 4티어(저가/중가/프리미엄/럭셔리) 각각의 **목표 매출총이익률 범위**
- 럭셔리 라인의 **별도 브랜드명** 도입 여부 (책의 분리 원칙 적용)
- 각 티어의 **할인 정책** 명문화 (특히 프리미엄·럭셔리의 할인 금지 여부)
- CEO 승인 임계값 (몇 % 이상 가격 변경부터 승인 필요한가)
- 90일 검증의 알림 주기 및 학습 노트 작성 의무화 여부

### 11.2 시범 운영 후 재검토

- 4단계 워크플로우의 실제 통과 시간 ― 너무 무거우면 단순화
- 가격 탄력성 자동 학습의 정확도
- 거래처 등급 변경 빈도

### 11.3 다른 카테고리에서 결정될 사항

- 단위 변동비 계산 방식 → #3 측정·분해 PRD
- 거래처 등급 결정 기준 → #3 ⑤ 고객 수익성 PRD
- 가치 소통 콘텐츠 운영 → #2b 마케팅·브랜딩 PRD
- 영업 협상 가이드 운영 → #2a 영업 전략 PRD

### 11.4 멀티티어 운영의 별도 검토 사항

대표님이 럭셔리 라인 도전을 계획하시는 만큼, 다음 사항은 별도 의사결정 회의가 필요할 수 있다:
- 럭셔리 라인의 별도 브랜드 도입 (책의 토요타-렉서스 사례)
- 럭셔리 라인의 별도 채널 (직영 쇼룸? 별도 디지털 채널?)
- 럭셔리 라인의 별도 영업 인력 (전담 어카운트 매니저)
- 럭셔리 라인의 별도 마케팅 (#2b 카테고리에서 별도 운영)
