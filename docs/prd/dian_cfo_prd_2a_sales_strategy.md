## 1. 개요

### 1.1 목적
본 카테고리는 **디안의 영업을 "카톡과 머릿속"에서 "기록 가능한 시스템"으로 전환**하고, 그 위에 **세그먼트별 차별화된 영업 전략**과 **사람·AI를 동등한 영업 자원으로 운영하는 구조**를 구축한다.

키엔스의 시스템(SFA·니즈카드·KPI·타임차지)과 트레이시의 인간 차원(자기경영·심리·습관)을 두 레이어로 결합하여, 영업이라는 행위가 디안의 가치 큐레이션 철학과 정합하도록 설계한다.

### 1.2 배경
**디안의 현재 상태 (대표님 자기 진단)**:
- 영업 담당자: 아직 명확하게 배정되어 있지 않음. AI 영업 담당자도 운영 가능. 거래처 유형별 분담 선호.
- 영업 활동 기록: 단순 카톡 공유 또는 머릿속
- 핵심 활동 단위: 미팅 건수, 샘플 발송 건수, 신규 컨택 건수, 견적 작성
- 세그먼트 구조: **6직업군 × 4제품군 = 24셀 매트릭스**
  - 직업군: 인테리어 프로젝트 / 브랜드 가구 / 프로젝트 가구 / 업소용(천갈이) / 커튼스타일링 / 디스플레이
  - 제품군: 소파원단 / 커튼원단 / 벽원단 / 소품원단

**책의 핵심 진단**:
- 키엔스: *"기록하지 않으면 행동하지 않는 것이다."* + 영업이익률 55%의 비결은 분 단위 활동 기록과 시스템화
- 트레이시: *"상위 20%가 매출 80%를 만든다."* + *"목표를 상상만 하지 말고 행동하라."* + 자기 이미지가 영업 성과를 결정

따라서 본 카테고리는 **디안이 영업 zero에서 시작하는 만큼, 처음부터 잘 설계된 시스템을 도입할 수 있는 절호의 기회**다. 기존 시스템 교체보다 백배 쉽다.

### 1.3 카테고리의 위치
본 카테고리는 디안 대시보드 7대 영역 중 **#2a 영역**이며, 다음과 같은 핵심 흐름의 중심에 있다.

- **입력**: #1 목표·계획의 12주 목표 (영업 KPI) + #4 의사결정의 가격 정책·협상 가이드
- **출력**: 활동 기록 → #1 선행지표 / 매출 → #3 측정·분해 / 거래처 인사이트 → #2b 마케팅 / 활동기준 원가 → #3 ⑤ 고객 수익성 / 핵심 영업 인사이트 → #7 CEO 코크핏

### 1.4 핵심 철학 (책에서 추출)
다음 메시지들은 본 카테고리의 모든 페이지·기능 설계의 변하지 않는 기준이다.

**키엔스 (시스템 차원)**
- *"기록하지 않으면 행동하지 않는 것이다."* ― 모든 영업 활동의 분 단위 기록 강제
- *"수주율이 아니라 활동량."* ― 결과보다 행동 KPI 우선
- *"외근 영업이 본사보다 빠르게 변한다."* ― 현장 인사이트가 본사보다 빠르게 의사결정
- *"부가가치 영업"* ― 단순 판매가 아닌 가치 창출. 디안의 "텍스처 큐레이션" 정체성과 직결
- *"새로운 정보를 얻는 영업사원"* ― 영업의 본질은 정보 수집과 가치 전달

**트레이시 (인간 차원)**
- *"자기 이미지가 영업 성과를 결정한다."* ― 영업의 시작은 자기 자신
- *"80/20 ― 상위 20%가 80% 매출."* ― 목표는 그 20% 안으로 들어가는 것
- *"목표를 상상만 하지 말고 행동하라."* ― 매일의 작은 행동이 쌓여 성과
- *"거절은 끝이 아니라 영업의 시작."* ― 거절을 학습 자산으로 전환

## 2. 핵심 원칙

1. **기록의 의무화**: 모든 영업 활동(미팅·샘플·통화·메일·DM)은 기록되어야 한다. 카톡 공유는 자동 임포트로 흡수.
2. **사람·AI 동등 운영**: 영업 담당자는 사람 또는 AI. 거래처 배정·활동 기록·KPI 추적이 동일하게 적용된다.
3. **세그먼트별 차별화**: 24셀 매트릭스의 각 셀은 다른 영업 시퀀스·KPI·핵심 메시지·평균 사이클을 갖는다.
4. **수주율보다 활동량**: KPI는 결과(매출·수주율)뿐 아니라 행동(미팅·샘플·컨택)을 동등 비중으로 추적.
5. **부가가치 영업**: 단순 판매가 아닌 큐레이션을 통해 디자이너의 가치를 높이는 솔루션 제공자로서의 영업.
6. **거절은 학습 자산**: 잃어버린 거래도 기록·분석하여 다음 시도에 적용.

## 3. 사용자 시나리오

### 3.1 페르소나

**페르소나 A: 인간 영업 담당자**
- 거래처 유형별로 배정된 영업 담당
- 매일 ① 활동 다이어리에 활동 기록
- 매주 WAM 전 본인 KPI 점검
- 월 1회 이상 ④ 니즈카드 등록

**페르소나 B: AI 영업 담당자**
- 특정 거래처 또는 전체에 보조로 배정
- 자동 활동 추천, 후속 알림, 문서 작성
- 거래처 패턴 학습 후 인간 영업에 인사이트 제공

**페르소나 C: 대표 (CEO)**
- 영업 KPI 대시보드 모니터링
- 핵심 거래처 직접 미팅 참여 (특히 럭셔리 라인)
- 영업 시스템의 패턴 분석

### 3.2 핵심 사용자 여정

**여정 1: 새로운 디자이너 컨택 (인간 영업 + AI 보조)**
1. 디자이너로부터 인스타 DM 또는 이메일로 첫 문의
2. ① 활동 다이어리에 신규 컨택 등록 (또는 카톡 공유 → 자동 임포트)
3. ③ 세그먼트 매트릭스에서 해당 디자이너의 직업군·제품 추정
4. AI가 해당 셀의 표준 영업 시퀀스 + 추천 카탈로그 + 첫 답신 초안 자동 생성
5. 인간 영업이 검토·수정 후 응답
6. 후속 활동 자동 알림 (3일 후 follow-up, 7일 후 샘플 발송 제안 등)

**여정 2: 거래처 미팅 후 (인간 영업)**
1. 미팅 종료 직후 ① 활동 다이어리에 미팅 기록 (음성 메모 또는 텍스트)
2. AI가 자동으로 ② 거래처 360 뷰 업데이트
3. 미팅에서 발견한 새 니즈가 있으면 ④ 니즈카드 등록
4. ⑤ 7단계 프로세스 트래커에서 해당 거래처의 단계 자동 업데이트
5. 다음 액션 추천 (샘플 발송 / 견적 작성 / 후속 미팅)

**여정 3: 주간 영업 회의 준비 (대표 + 영업 담당자)**
1. ⑥ KPI 대시보드에서 본인의 7개 행동지표 확인
2. ⑦ 자기경영 페이지에서 이번 주 자기 평가
3. 80/20 분석 ― 상위 20% 거래처에 시간을 충분히 썼는가?
4. WAM 미팅에서 활동량 vs 결과 점검 (#1 카테고리)

**여정 4: 분기말 거절 분석 (영업 담당자)**
1. 잃어버린 거래 목록 확인
2. 각 거래에 대해 트레이시의 거절 분류 (가격 / 타이밍 / 신뢰 / 니즈 불일치 / 경쟁사)
3. 패턴 분석 ― 가장 많이 잃은 단계는?
4. 학습 노트 작성 → ④ 니즈카드와 연계

## 4. 페이지 구조 (7개 페이지)

페이지는 네 그룹으로 나뉜다.

- **A. 활동 기록** (키엔스의 SFA): ①, ②
- **B. 세그먼트 운영** (디안의 24셀): ③, ④
- **C. 프로세스·성과** (트레이시 + 키엔스): ⑤, ⑥
- **D. 자기경영** (트레이시): ⑦

### 4.1 ① 활동 다이어리 + AI 어시스턴트

**목적**: 키엔스 SFA의 핵심을 디안에 이식. 모든 영업 활동을 기록 가능하게 만들고, AI가 기록을 보조하여 입력 부담을 최소화한다.

**주요 컴포넌트**:
- (상단) 빠른 입력 영역:
  - 활동 유형 선택: 미팅 / 샘플 발송 / 통화 / 이메일 / DM / 견적 작성 / 카탈로그 송부 / 기타
  - 거래처 선택 (자동 완성)
  - 활동 시간 (자동 또는 수동)
  - 결과·메모 (텍스트 또는 음성 → 텍스트 자동 변환)
- (중단) 카톡·이메일 자동 임포트:
  - 카톡 캡쳐 사진 업로드 → AI가 텍스트 추출 + 활동으로 자동 분류
  - 이메일 포워딩 → 자동 활동 등록
  - 캘린더 연동 → 미팅 자동 기록
- (중단) 오늘의 활동 타임라인:
  - 시간대별 활동 표시
  - 활동 사이의 빈 시간 표시 (책의 분 단위 시간 활용)
  - "타임차지" 자동 계산 (활동당 만든 부가가치)
- (중단) AI 어시스턴트 패널:
  - "이 거래처에 마지막 컨택 후 7일 ― 후속 추천"
  - "이번 주 미팅 N건 ― 목표까지 M건"
  - "유사 거래처 패턴: 첫 미팅 → 샘플 → 견적 → 평균 12일에 결정"
  - 다음 액션 자동 추천
- (하단) 일일 요약:
  - 오늘 활동 통계
  - 만든 가치 (예: 신규 컨택 2건, 견적 1건, 미팅 3건 → 추정 매출 기여)

**핵심 인터랙션**:
- 음성 입력 (미팅 직후 즉시 기록 ― 책의 외근 강조)
- 사진 업로드 → AI 자동 처리
- 활동 등록 시 자동으로 다른 페이지에 흘러감 (② 거래처 360, ⑤ 7단계, ⑥ KPI)

**시각 요소**:
- 타임라인 (오늘 활동)
- 활동 카드 (각 활동 클릭 시 상세)
- AI 추천 카드

**권한**:
- 본인: 본인 활동 전체 조회·편집
- 영업 임원·대표: 모든 활동 조회
- 다른 영업: 같은 거래처의 본인 활동만 조회 (다른 영업의 활동은 비공개)

### 4.2 ② 거래처 360도 뷰

**목적**: 한 거래처에 관한 모든 정보를 한 화면에서 본다. 키엔스 SFA의 핵심 기능 + 트레이시 7단계 프로세스 추적.

**주요 컴포넌트**:
- (상단) 거래처 헤더:
  - 이름·로고·세그먼트(직업군) 분류
  - 등급 (#3 ⑤ 고객 수익성과 연동: VIP/일반/소규모/성장가능/비효율)
  - 담당자 (사람 또는 AI)
  - 핵심 연락처 (주 디자이너·구매 담당)
- (중단) 좌측 ― 활동 타임라인:
  - 모든 컨택 이력 시간순
  - 활동 유형별 색상
  - 카카오톡·이메일·미팅·샘플 통합
- (중단) 우측 ― 거래 요약:
  - 12주 누적 거래액
  - 평균 마진율
  - 활동기준 원가 (ABC) ― 디안이 이 거래처에 들인 영업 시간·샘플비·접대비 합산
  - 진짜 마진 = 거래 마진 − 활동 원가
- (중단) 7단계 프로세스 위치:
  - 신뢰 구축 → 니즈 발견 → 솔루션 제시 → 반대 처리 → 클로징 → 추천·재구매 → 후속 관리
  - 현재 단계 자동 표시
  - 단계 전환 일자 + 다음 단계 추천
- (하단) AI 인사이트:
  - "이 거래처는 SS 시즌에 평균 매출 30% 증가 ― 미리 컨택 권장"
  - "지난 6개월간 신뢰 단계 → 니즈 발견 단계로 진입 못함 ― 영업 방식 검토 필요"
  - "유사 거래처 패턴: VIP 진입까지 평균 9개월"

**핵심 인터랙션**:
- 활동 클릭 → ① 활동 다이어리 상세
- 단계 전환 시 영업 시퀀스 자동 추천
- 등급 변경 시 #3 ⑤ 고객 수익성에서 자동 동기화
- 거래처 카드 출력·공유 (CEO 미팅 준비용)

**시각 요소**:
- 타임라인 (활동 이력)
- 7단계 프로세스 진행 표시줄
- ABC 원가 분해 차트
- AI 인사이트 카드

**권한**:
- 영업 담당자: 본인 담당 거래처 전체 조회·편집
- 영업 임원·대표: 모든 거래처
- 다른 영업: 본인 거래처가 아닌 경우 기본 정보만 조회 (활동 디테일 비공개)

### 4.3 ③ 세그먼트별 영업 매트릭스 (24셀)

**목적**: 디안의 6직업군 × 4제품군 = 24개 셀 각각의 영업 가이드를 명문화. 책의 일반론을 디안의 구체에 적용하는 핵심 도구.

**주요 컴포넌트**:
- (상단) 24셀 매트릭스:
  - 가로축: 4제품군 (소파원단 / 커튼원단 / 벽원단 / 소품원단)
  - 세로축: 6직업군 (인테리어 프로젝트 / 브랜드 가구 / 프로젝트 가구 / 업소용 / 커튼스타일링 / 디스플레이)
  - 각 셀에 핵심 메시지 + 매출 기여도 + 평균 사이클 타임
- (중단) 셀 클릭 시 상세:
  - **핵심 메시지**: 이 세그먼트에 어필할 1-2 줄 가치 제안
  - **이상적 영업 시퀀스**: 첫 컨택 → 어떤 활동들을 어떤 순서로
  - **평균 사이클 타임**: 첫 컨택부터 첫 거래까지 (학습되어 자동 업데이트)
  - **추천 카탈로그·샘플**: 이 셀에 가장 잘 맞는 디안 라인업
  - **핵심 KPI**: 이 셀에서 중점 추적할 행동지표
  - **성공·실패 사례**: 누적 학습 노트
- (중단) 셀별 거래처 리스트:
  - 해당 셀에 속한 거래처들 한눈에 보기
  - 각 거래처의 7단계 위치
- (하단) **셀 간 비교 분석**:
  - 어느 셀이 가장 활발한가
  - 어느 셀이 가장 마진이 높은가
  - 미개척 셀 (활동 없음) 식별

**예시 ― 디안의 24셀 일부 정의 (1차 초안)**:

| 직업군 | 제품군 | 핵심 메시지 | 영업 시퀀스 | 평균 사이클 |
|---|---|---|---|---|
| 인테리어 프로젝트 | 벽원단 | "공간의 텍스처 컨셉 파트너" | 컨셉 미팅 → 무드보드 → 샘플북 → 큐레이션 제안 | 4-8주 |
| 브랜드 가구 | 소파원단 | "지속가능 스펙 + 안정 공급" | 스펙 시트 송부 → 대량 샘플 → 단가 협상 → 연간 계약 | 8-16주 |
| 프로젝트 가구 | 소파원단 | "프로젝트 단위 맞춤 + 빠른 납기" | 견적 요청 응대 → 옵션 제시 → 납기 확약 | 1-3주 |
| 업소용 (천갈이) | 소파원단 | "내구성·가성비 + 상시 재고" | 카탈로그 → 즉시 단가 → 재구매 패턴 추적 | 1-2주 |
| 커튼스타일링 | 커튼원단 | "시즌 트렌드 큐레이션" | 시즌 컬렉션 발표 → 스타일리스트 미팅 → 패키지 | 2-4주 |
| 디스플레이 | 소품원단 | "단기 임팩트·다채로운 옵션" | 프로젝트 브리핑 → 다종 샘플 → 즉납 | 1-2주 |

*(전체 24셀은 시범 운영하면서 디안 데이터로 보강)*

**핵심 인터랙션**:
- 새 거래처 등록 시 자동으로 적합한 셀 추천
- 셀별 영업 시퀀스 변경 → 해당 셀 거래처 모두에게 알림
- AI가 셀별 성공 패턴 학습 → 자동 시퀀스 최적화

**시각 요소**:
- 6×4 매트릭스 그리드
- 셀별 카드 (호버 시 상세)
- 매트릭스 히트맵 (활성도 / 마진율)

**권한**:
- 영업 임원·대표: 매트릭스 정의·수정
- 영업 담당자: 본인 거래처가 속한 셀 조회·시퀀스 활용
- 전 직원: 매트릭스 구조 조회 (브랜드 일관성)

### 4.4 ④ 니즈 카드 / 디자이너 인사이트 보드

**목적**: 키엔스의 핵심 도구 ― 현장 영업이 발견한 디자이너·시장의 숨은 니즈를 시스템적으로 수집하여 큐레이션·신상품 결정의 원천으로 만든다.

**주요 컴포넌트**:
- (상단) 카드 등록 (월 1건 이상 의무):
  - 누가 (영업 담당자)
  - 어느 거래처에서
  - 어떤 니즈를 발견했는가 (자유 텍스트)
  - 어떻게 발견했는가 (미팅 / 샘플 피드백 / 통화 / 시장 관찰)
  - 7가지 니즈 분류:
    - 신제품·신소재 ("비건 가죽 대체재의 매트한 텍스처를 찾고 있음")
    - 컬러·트렌드 ("올해 SS 시즌 인기 컬러는 ...")
    - 기능·스펙 ("Martindale 50,000+ 요구가 늘어남")
    - 서비스·운영 ("당일 배송 옵션 요청 증가")
    - 가격·패키지 ("패키지 할인 요청")
    - 디지털·온라인 ("3D 시각화 도구 필요")
    - 기타
- (중단) 보드 형태 시각화:
  - 칸반 보드: 신규 등록 → 검토 중 → 채택 → 구현 중 → 완료
  - 분류·시간순·중요도 필터
  - 좋아요·댓글 기능 (다른 영업도 같은 니즈 보았다면 +1)
- (중단) AI 인사이트:
  - 유사 니즈 자동 클러스터링
  - 트렌드 추세 (최근 3개월 가장 많이 등장한 키워드)
  - 비즈니스 임팩트 추정 (이 니즈 충족 시 예상 매출)
- (하단) 액션 아이템:
  - 채택된 니즈 → 큐레이션·신상품·서비스 개선 계획
  - 책임자 + 마감일
  - 결과 추적 (이 니즈 충족 후 매출 변화)

**핵심 인터랙션**:
- 카드 등록 시 영업 KPI에 자동 반영 (월 1건 의무)
- 채택된 니즈 → #2b 마케팅·브랜딩 (콘텐츠 인풋), #4 의사결정 (가치 정의 인풋)
- 분기 회의 시 보드 모드 (큰 화면)
- 니즈 충족 후 결과 추적 → 책의 "측정 가능한 학습"

**시각 요소**:
- 카드 그리드 / 칸반 보드
- 워드 클라우드 (자주 등장하는 키워드)
- 트렌드 라인 (월별 카드 등록 추이)

**권한**:
- 영업 담당자: 등록·조회·댓글
- 마케팅·CEO: 조회·채택 결정
- 전 직원: 조회 (집단 지성)

### 4.5 ⑤ 7단계 영업 프로세스 트래커 (트레이시)

**목적**: 트레이시의 7단계 영업 프로세스를 디안의 모든 거래처에 적용하여, 어느 단계에서 가장 많이 막히는지 시각화하고 단계별 코칭 제공.

**7단계**:
1. **신뢰 구축** (Building Trust): 첫 컨택, 자기 소개, 디안 소개
2. **니즈 발견** (Needs Identification): 디자이너의 프로젝트·취향·예산 파악
3. **솔루션 제시** (Presentation): 큐레이션·샘플·견적
4. **반대 처리** (Handling Objections): 가격·납기·스펙 우려 해소
5. **클로징** (Closing): 거래 성사
6. **추천·재구매** (Resales/Referrals): 후속 거래 + 다른 디자이너 소개
7. **후속 관리** (Follow-up): 사용 후 만족도, 장기 관계

**주요 컴포넌트**:
- (상단) 회사 전체 단계 분포:
  - 우리 거래처들이 어느 단계에 가장 많이 분포되어 있나
  - 단계별 평균 머무는 기간
- (중단) 거래처별 단계 위치:
  - 모든 거래처를 7단계 위에 배치
  - 정체된 거래처 (한 단계에서 60일 이상) 알림
- (중단) **단계 전환률 분석**:
  - 신뢰 → 니즈 전환률
  - 니즈 → 솔루션 전환률
  - 솔루션 → 반대 처리 전환률
  - ...
  - 가장 낮은 전환률의 단계 = 디안 영업의 약점
- (중단) **단계별 코칭 노트** (트레이시 인사이트 기반):
  - 신뢰 구축: "첫 5초가 결정. 명함·자료·웃음·자신감"
  - 니즈 발견: "더 많이 듣고 더 적게 말하라. 80/20 ― 80% 듣기"
  - 솔루션 제시: "디자이너의 언어로. 스펙이 아니라 결과를 말하라"
  - 반대 처리: "거절은 정보 부족의 신호. 더 들어라"
  - 클로징: "결정의 단순화. 'A 또는 B?'"
  - 추천·재구매: "최고의 영업은 만족한 고객"
  - 후속 관리: "거래 끝이 관계 시작"
- (하단) 이번 주 액션:
  - 정체된 거래처 N개에 대한 단계 전환 시도 권장

**핵심 인터랙션**:
- 단계 자동 추정 (활동 이력 기반)
- 수동 단계 변경 가능
- 거절·실패 시 어느 단계에서 잃었는지 기록 → 학습 자산

**시각 요소**:
- 7단계 깔때기 (Funnel)
- 거래처 점들의 단계 분포
- 전환률 막대 차트

**권한**:
- 영업 담당자: 본인 거래처
- 영업 임원·대표: 전체 + 패턴 분석

### 4.6 ⑥ 영업 KPI 대시보드

**목적**: 키엔스의 7가지 행동지표를 디안 맞춤형으로 적용. 결과 KPI(매출·수주율)와 행동 KPI(미팅·샘플·컨택·견적)를 동등하게 추적.

**디안의 7가지 행동지표** (대표님 답변 + 키엔스 프레임 합성):
1. 매출 (결과)
2. 거래량 (거래 건수)
3. 신규 거래처 수
4. **미팅 건수** ← 디안 핵심
5. **샘플 발송 건수** ← 디안 핵심
6. **신규 컨택 건수** ← 디안 핵심 (인스타·DM·전화·소개)
7. **견적 작성 건수** ← 디안 핵심

**주요 컴포넌트**:
- (상단) 7개 KPI 카드 (이번 주 / 이번 달 / 12주):
  - 각 카드에 12주 목표 + 현재 진행률 + 80% 기준선
  - 사람 영업 vs AI 영업 분리 표시 가능
- (중단) **타임차지 (시간당 부가가치)**:
  - 영업이 1시간 일하면 디안에 얼마의 매출총이익 기여?
  - 책의 핵심 KPI ― 부가가치 영업의 측정
  - 사람·AI 비교 가능
- (중단) **수주율 vs 활동량 그래프**:
  - X축: 활동량 (총 활동 건수)
  - Y축: 수주율
  - 책의 메시지: *"수주율이 아니라 활동량"*
  - 활동량이 많은데 수주율이 낮다면 → 어느 단계에서 막히는지 ⑤로 이동
- (중단) **80/20 분석** (트레이시):
  - 상위 20% 거래처가 매출 N% 만든다
  - 그 20%에 시간을 충분히 쓰고 있는가
  - 활동 시간 분포 vs 매출 기여도 매트릭스
- (하단) 12주 영업 목표 트래커:
  - #1 목표·계획 카테고리에서 자동 가져옴
  - 진행률 + 예상 도달일

**핵심 인터랙션**:
- KPI 카드 클릭 → 해당 활동의 디테일 (① 활동 다이어리)
- 80/20 분석 클릭 → 상위 20% 거래처 리스트 (② 거래처 360)
- 사람 영업 vs AI 영업 비교 가능

**시각 요소**:
- KPI 카드 그리드
- 시간당 부가가치 라인 차트
- 80/20 파레토 차트
- 수주율 vs 활동량 산점도

**권한**:
- 영업 담당자: 본인 KPI
- 영업 임원·대표: 전체 + 직원별 비교
- 전 직원: 회사 전체 합계 (개별 직원 데이터 비공개)

### 4.7 ⑦ 영업 자기경영 (트레이시 차원)

**목적**: 키엔스 시스템 위에 트레이시의 인간 차원을 얹는다. 영업 직원 개개인의 자기 이미지·습관·심리를 관리.

**주요 컴포넌트**:
- (상단) 자기 이미지 일일 체크인:
  - "오늘 나는 디안의 영업 전문가로서 어떤 기분인가?" (5점 척도)
  - 자기 이미지 점수 추세
  - 책의 핵심: *"자기 이미지가 영업 성과를 결정"*
- (중단) **일일 영업 행동 계획**:
  - 매일 아침 입력 (또는 전날 밤): 오늘의 핵심 영업 활동 3개
  - 황금 시간 (가장 집중 잘 되는 시간) 표시
  - 그 황금 시간에 영업 활동을 배치하고 있는가
  - #1 목표·계획의 시간 블록과 연동
- (중단) **거절 처리 노트**:
  - 이번 주 받은 거절 (또는 진척 없음)
  - 거절 분류: 가격 / 타이밍 / 신뢰 / 니즈 불일치 / 경쟁사 / 기타
  - 한 줄 학습 노트 (책: *"거절은 끝이 아니라 영업의 시작"*)
  - 누적 학습 노트 → 패턴 자동 분석
- (중단) 80/20 자기 분석:
  - 본인은 디안 영업 상위 20% 안에 있는가?
  - 들어가기 위한 다음 행동 추천
- (하단) 트레이시 코칭 메시지 (일일 알림):
  - 매일 다른 영업 격언·인사이트
  - "오늘은 신뢰 구축 단계의 거래처에 시간을 더 써보세요"
  - 책의 11가지 인간 동기부여 요인 적용

**핵심 인터랙션**:
- 매일 아침 체크인 알림
- 거절 노트는 ⑤ 7단계 트래커에서 자동 추출
- 자기 이미지 점수가 낮을 때 임원과 1:1 미팅 자동 추천 (#1 ⑤ 1:1)

**시각 요소**:
- 자기 이미지 추세 라인
- 일일 행동 계획 카드
- 거절 패턴 분석 차트
- 트레이시 코칭 메시지 카드

**권한**:
- 본인만 (자기경영 데이터는 매우 개인적)
- 임원·대표: 본인 동의 시에만 (책의 신뢰·심리적 안전감 원칙)
- AI 영업 담당자의 경우: 자기경영 항목은 N/A 또는 시스템 메트릭으로 대체

## 5. 데이터 모델

### 5.1 핵심 엔티티

| 엔티티 | 핵심 필드 | 비고 |
|---|---|---|
| `SalesAgent` | id, type(human/ai), name, assignedSegments[], assignedClients[] | 사람·AI 동등 |
| `Activity` | id, agentId, clientId, type, datetime, duration, notes, valueGenerated | 모든 활동 |
| `ClientProfile` | id, name, segment(직업군), products[], tier, currentStage(7단계), assignedAgentId | 거래처 + 7단계 |
| `SegmentMatrix` | id, occupation, productType, coreMessage, salesSequence[], avgCycle, recommendedCatalog | 24셀 |
| `NeedCard` | id, agentId, clientId, category(7분류), description, discoveryMethod, status, votes | 니즈카드 |
| `StageTransition` | id, clientId, fromStage, toStage, transitionDate, daysInPreviousStage | 7단계 추적 |
| `ObjectionRecord` | id, agentId, clientId, lostStage, objectionType, learningNote | 거절 분석 |
| `KPISnapshot` | id, agentId, period, meetings, samples, contacts, quotes, sales, timeCharge | KPI 스냅샷 |
| `SelfManagement` | id, agentId, date, selfImageScore, dailyPlan[], goldenHours, reflection | 자기경영 |
| `AIRecommendation` | id, agentId, clientId, type, recommendation, rationale, status | AI 추천 |

### 5.2 핵심 관계

- 한 `SalesAgent` (사람 또는 AI)는 여러 `ClientProfile` 담당
- 모든 `Activity`는 `SalesAgent` + `ClientProfile`에 연결
- `ClientProfile`은 `SegmentMatrix`의 한 셀에 속함
- `Activity` 누적 → `KPISnapshot` 자동 집계
- `ObjectionRecord`는 `StageTransition`의 실패 사례

### 5.3 외부 연동

- **카톡 자동 임포트**: 사진 업로드 → OCR + AI 분류 → `Activity` 자동 생성
- **이메일 포워딩**: 특정 주소로 포워딩 → `Activity` 자동 생성
- **캘린더**: 미팅 일정 자동 동기화
- **인스타그램 DM**: 가능 시 자동 임포트 (#2b 마케팅과 연계)

## 6. 권한 위계

| 페이지 | 영업 담당자 | 영업 임원·대표 | 비고 |
|---|---|---|---|
| ① 활동 다이어리 | 본인 활동 전체 | 모든 활동 | 다른 영업 활동 비공개 (같은 거래처 제외) |
| ② 거래처 360 뷰 | 본인 담당 거래처 | 모든 거래처 | 본인 외 거래처는 기본 정보만 |
| ③ 세그먼트 매트릭스 | 조회·시퀀스 활용 | 정의·수정 | 매트릭스 구조는 전 직원 조회 |
| ④ 니즈카드 | 등록·조회·댓글 | 채택 결정 | 전 직원 조회 (집단 지성) |
| ⑤ 7단계 트래커 | 본인 거래처 | 전체 + 패턴 분석 | |
| ⑥ KPI 대시보드 | 본인 KPI | 전체 + 비교 | 회사 합계는 전 직원 조회 |
| ⑦ 자기경영 | 본인만 | 본인 동의 시 | 매우 민감 (트레이시 자기 이미지) |

### 6.1 권한 원칙

1. **영업 데이터는 보호**: 다른 영업의 거래처·활동 디테일은 노출 금지. 영업 간 신뢰·동기 부여 보호.
2. **자기경영은 더 민감**: ⑦ 페이지는 본인 외에는 본인 동의 시에만 접근.
3. **세그먼트·니즈는 투명**: ③, ④는 회사 차원의 자산이므로 가능한 한 많이 공유.
4. **AI 영업의 권한**: AI 영업도 `SalesAgent`의 한 형태로 동등 처리. 단, 자기경영은 N/A.

## 9. v1.0 마이그레이션 계획

### 9.1 v1.0과의 관계

v1.0에는 영업 활동 기록·세그먼트·자기경영 영역이 명시적으로 존재하지 않는다. 본 카테고리는 신규 추가다.

단, 다음 v1.0 자산은 본 카테고리의 데이터 소스로 활용된다:

| v1.0 메뉴 | 본 카테고리에서의 활용 |
|---|---|
| 거래처 관리 | ② 거래처 360 뷰의 마스터 데이터 |
| 거래 관리 | ⑥ KPI 대시보드의 매출 데이터 |
| 제품 관리 | ③ 세그먼트 매트릭스의 제품 분류 |

### 9.2 데이터 보존 원칙

- v1.0의 기존 거래처·거래 데이터는 **삭제하지 않는다**.
- 본 카테고리는 v1.0 데이터 위에 **활동 이력, 7단계 위치, 세그먼트 분류, 니즈카드, 자기경영 데이터**를 새로 얹는다.

### 9.3 마스터 데이터 초기 설정 (1회성)

본 카테고리가 작동하려면 다음 마스터 데이터의 1회성 분류 작업이 필요하다.

1. **24셀 매트릭스 정의**: 6직업군 × 4제품군 각 셀의 핵심 메시지·시퀀스·평균 사이클
2. **거래처 세그먼트 분류**: 모든 기존 거래처를 6직업군 중 하나에 매핑
3. **거래처 7단계 위치**: 모든 기존 거래처의 현재 단계 추정 (수동)
4. **영업 담당자 등록**: 사람 + AI 모두
5. **거래처 담당자 배정**: 거래처별 사람 또는 AI 매핑

이 분류는 1회 설정 후 신규 데이터에 자동 적용되며, 분기마다 검토·업데이트한다.
