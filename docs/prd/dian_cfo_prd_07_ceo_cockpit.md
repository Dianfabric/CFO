## 1. 개요

### 1.1 목적
본 카테고리는 **디안 대표가 매일 가장 먼저 진입하는 메인 페이지**이며, 단순한 대시보드가 아닌 **'AI 경영 파트너'**로서 능동적으로 작동한다. 다른 6개 카테고리에서 올라오는 모든 데이터를 통합하고, 4권의 경영 고전이 가르치는 프레임으로 분석하여, **매일·매주·매월 대표에게 컨설팅·코칭·보고**를 수행한다.

### 1.2 다른 카테고리와의 본질적 차이

| 다른 6개 카테고리 | #7 CEO 코크핏 |
|---|---|
| 데이터를 다루는 도구 | 대표와 매일 대화하는 AI 파트너 |
| 직원·임원·대표 공용 | 대표 전용 (일부 임원 공유) |
| 페이지 구조 = 기능 모음 | 페이지 구조 = 시간의 흐름 (아침→낮→저녁→회고) |
| 책에서 추출한 프레임 | 4권 통합 + AI 추론 + 데이터 종합 |

### 1.3 4권의 책 ― 4차원의 경영 시스템

본 카테고리는 4권의 책이 정확히 4가지 다른 차원을 담당함을 발견한 위에 설계된다.

**[1] 사업 차원 ― 드러커 『경영의 실제』**
- 핵심 메시지: *"기업의 목적은 고객 창조다."* 매출·이익이 아닌 고객 창조가 목적이고, 이를 만드는 것은 마케팅과 혁신뿐. 나머지는 모두 비용.
- 3가지 근본 질문: *"우리의 사업은 무엇인가? / 무엇이 되어야 하는가? / 우리의 고객은 누구이며 무엇을 가치로 여기는가?"*
- 핵심 인용: *"우리가 하는 사업은 생산자가 아니라 소비자가 결정한다."*
- MBO (목표에 의한 관리)의 원형 + 이익은 마케팅·혁신의 결과·기준이지 목표가 아님

**[2] 자기 차원 ― 드러커 『자기경영노트』**
- 효과적인 경영자의 5가지 습관:
  1. **시간 관리** ― 자신의 시간을 먼저 파악하라. 작은 단위로 쪼개지 말고 큰 단위로 묶어라
  2. **공헌 (Contribution)** ― *"내가 어떤 결과를 회사에 기여할 것인가"*를 먼저 묻기
  3. **강점 활용** ― 자신과 타인의 강점에 초점. *"약점을 줄이려는 사람은 약한 인간의 표본"*
  4. **우선순위** ― 한 번에 한 가지에 집중. *"중요한 일부터 하나씩"*
  5. **효과적인 의사결정** ― 견해의 충돌·반대 의견·경계 조건 명시

**[3] 조직 차원 ― 그로브 『하이 아웃풋 매니지먼트』**
- 핵심 등식: **매니저의 산출물 = 본인 산출물 + 본인이 영향을 미치는 조직의 산출물**
- **레버리지 (Leverage)** ― 시간당 영향력이 큰 활동 식별. 1:1 미팅이 최고의 레버리지
- **변동적 검사 (Variable Inspection)** ― 직원의 업무 숙련도(TRM)에 따라 모니터링 주기 조정
- **차이 분석 (Difference Analysis)** ― 계획 vs 실제 차이가 학습의 원천
- **6가지 의사결정 질문**: 어떤 결정을 / 언제 / 누가 결정 / 누가 의견 / 누가 승인 / 누가 알아야

**[4] 사람 차원 ― 캠벨 (에릭 슈미트, 1조 달러 코치)**
- **사람 우선 (People First)** ― 직원에 대한 진정성 있는 관심이 기법보다 먼저
- **신뢰는 화폐** ― *"약한 모습을 보여도 안전하다는 확신"*이 심리적 안전감
- **팀 퍼스트** ― 문제 분석 전에 *"적합한 사람·적합한 팀·필요한 지원이 있는가"* 먼저 점검
- **솔직함 + 친절의 공존** ― 경청하되 쓴소리는 주저하지 않음
- **합의가 아닌 최고의 아이디어** ― 모든 사람의 솔직한 의견 수집 + CEO의 결단
- **올바르게 이긴다 (Win the Right Way)** ― 헌신과 팀워크로

### 1.4 디안 적용의 출발점 (대표님 답변 기반)

**대표님의 현재 시간 사용**: 콘텐츠 제작 + 재무 검토 + 직원 1:1 + 전략 사고 + 전체 파악
- 드러커 자기경영 관점: 너무 많은 영역에 분산되어 있을 위험. **강점 집중과 위임**이 필요한 시점

**대표님의 핵심 화두**: 재무 구조 파악 + 전략 설계 + 마케팅
- 드러커 경영의 실제 관점: *"마케팅과 혁신이 결과를 만든다"* ― 정확히 같은 방향
- 본 카테고리의 P0 컨설팅 영역: 재무 구조 종합 분석 + 전략적 레버리지 식별 + 마케팅 ROI

## 2. 핵심 원칙

본 AI 파트너는 다음 7가지 원칙을 변하지 않는 기준으로 따른다.

1. **데이터 통합 우선**: 다른 6개 카테고리의 데이터를 종합적으로 보고 인사이트를 도출. 단일 데이터 포인트로 판단하지 않는다.
2. **드러커 3가지 질문 자동 점검**: 모든 의사결정·전략 검토 시 *"우리의 사업은 무엇인가 / 고객은 누구인가 / 가치로 여기는 것은?"* 자동 환기.
3. **레버리지 의식**: 대표의 시간 사용을 분석해 가장 큰 레버리지 활동을 추천. *"이 1시간을 어디 쓰면 회사 전체에 가장 큰 영향?"*
4. **신뢰의 보호**: 1:1 미팅 노트·자기경영 데이터 등 민감 정보는 어떤 분석에도 사용하지 않는다. 대표 본인만 접근 가능.
5. **솔직함 + 친절**: AI는 듣기 좋은 말이 아닌 진짜 인사이트를 전달. 단, 따뜻한 어조로.
6. **차이 분석**: 모든 계획에 대해 실제 결과와의 차이를 자동 분석하고, 그 차이가 학습이 되도록 정리.
7. **하루의 흐름에 맞춤**: 아침에는 우선순위, 낮에는 실시간 코칭, 저녁에는 회고, 주말에는 패턴 분석. 자연스러운 시간 리듬에 맞춰 작동.

## 3. AI 파트너의 작동 원리

### 3.1 입력 (다른 카테고리에서 자동 수집)

| 데이터 | 출처 카테고리 | 활용 |
|---|---|---|
| 12주 사이클 진행률, 비전, 사후 검토 | #1 목표·계획 | 전략 정합성 점검 |
| 매출·공헌이익·결과의 질·BSC | #3 측정·분해 | 재무 건강 진단 |
| 가격 결정 이력·포지셔닝·차별화 | #4 의사결정 | 전략 의사결정 컨설팅 |
| 영업 활동·니즈카드·7단계·KPI | #2a 영업 전략 | 영업 트렌드 분석 |
| 콘텐츠 ROI·드림 100·캠페인 | #2b 마케팅 | 마케팅 효율성 |
| 거래·재고·샘플·운영 KPI | #2c 운영 실행 | 일일 운영 상태 |

추가로 대표가 직접 입력하는 데이터:
- 일일 메모 (음성 또는 텍스트)
- 1:1 미팅 노트 (대표 본인만 접근)
- 의사결정 일지
- 외부 활동 기록 (외부 미팅·세미나·읽은 자료)

### 3.2 처리 (4권의 책 프레임으로 분석)

AI는 입력된 데이터를 다음 네 가지 렌즈로 동시에 분석한다.

**렌즈 1 ― 사업의 본질** (드러커 경영의 실제)
- 디안의 활동이 *고객 창조*에 기여하고 있는가?
- 마케팅과 혁신이 충분한 자원을 받고 있는가?
- 매출 추구가 이익(고객 창조의 결과)을 가리고 있지 않은가?

**렌즈 2 ― 자기경영의 효율** (드러커 자기경영노트)
- 대표의 시간이 강점·우선순위에 정렬되어 있는가?
- *"이번 주 가장 중요한 한 가지"*에 충분한 시간을 썼는가?
- 약점에 시간을 쓰고 있지는 않은가?

**렌즈 3 ― 조직의 레버리지** (그로브)
- 대표의 활동 중 가장 큰 레버리지는 무엇인가?
- 직원별 업무 숙련도(TRM)에 따른 모니터링이 적절한가?
- 계획 vs 실제 차이는 무엇이고 어떤 학습으로 이어지는가?

**렌즈 4 ― 사람과 신뢰** (캠벨)
- 직원과의 신뢰 상태는? (1:1 미팅 빈도·질)
- 팀이 *"올바르게 이기고 있는가"*?
- 어려운 결정 앞에서 캠벨이라면 어떻게 했을까?

### 3.3 출력 (대표에게 전달)

AI는 다음 4가지 형태로 출력한다.

**A. 모닝 브리핑** (매일 아침 자동) → ① 페이지
**B. 실시간 컨설팅** (대화 중 능동적) → ② 페이지
**C. 이브닝 노트** (매일 저녁 자동) → ③ 페이지
**D. 주간·월간·분기 회고** (자동) → ④ 페이지

추가로 모든 출력은 **텔레그램 봇**으로 동기화 가능 (⑧).

### 4.1 ① 모닝 브리핑 (매일 아침 첫 진입)

**목적**: 대표가 매일 아침 진입하는 메인 페이지. 어제 데이터 분석 → 오늘 신경 써야 할 것 3-5개를 명확히 제시.

**작동 시점**: 매일 아침 자동 생성 (예: 7:00 ― 시간 설정 가능). 텔레그램 동시 발송.

**주요 컴포넌트**:

**(상단) 어제의 핵심 변화 (3개 카드, 자동 추출)**:
- AI가 어제 데이터에서 가장 중요한 변화 3개 자동 선정
- 예시: *"매출 +15% 급증 (○○스튜디오 대량 주문)"* / *"인스타 도달 -30% (지난 발행 공백 영향)"* / *"신규 거래처 2개 컨택 (드림 100 중 2명)"*
- 클릭 시 해당 카테고리로 드릴다운

**(상단) 오늘의 우선순위 (드러커 5가지 습관 적용)**:
- 오늘 반드시 해야 할 일 1순위 (가장 중요한 한 가지)
- 2-3순위
- 위임 가능한 일
- 거절·지연해야 할 일
- *"이번 주 마지막 12주 목표 점검 ― D-X일"*

**(중단) 오늘의 일정 + 1:1 미팅 알림**:
- 오늘의 캘린더 통합 표시
- 1:1 미팅이 있으면 → ⑥ 사람 관리에서 컨텍스트 자동 호출
- 회의 준비 자료 자동 정리

**(중단) 위기 신호 + 기회 신호**:
- AI가 6개 카테고리 데이터에서 종합 점검:
  - 재무 위기 신호 (#3): 공헌이익률 급락 / 미수금 증가 / 손익분기 도달 위험
  - 영업 신호 (#2a): 핵심 거래처 활동 정체 / 니즈카드의 새 트렌드
  - 마케팅 신호 (#2b): 콘텐츠 발행 공백 / 드림 100 응답
  - 운영 신호 (#2c): 재고 임계 / 납기 지연 / 죽은 재고
- 각 신호별 추천 액션 + 관련 카테고리로 1클릭 이동

**(중단) 드러커 3가지 질문 (주 1회 환기)**:
- 매주 월요일 아침에 자동 표시
- *"이번 주, 우리의 사업은 여전히 같은 정의인가?"*
- *"우리의 고객이 가치로 여기는 것이 변하지 않았나?"*
- *"이번 주 마케팅과 혁신에 충분한 시간을 쓰고 있는가?"*

**(하단) 일일 코칭 메시지 (캠벨 + 4권 통합)**:
- AI가 오늘의 상황에 맞는 책의 한 구절 + 디안 적용 제안
- 예시: *"빌 캠벨이라면 ○○ 상황에서 무엇을 물었을까?"*
- *"드러커는 이런 결정 앞에서 '경계 조건이 무엇인가'를 먼저 물었다"*

**핵심 인터랙션**:
- 모든 카드는 클릭하여 해당 카테고리로 즉시 이동
- 우선순위 항목 체크 시 자동으로 ⑤ 시간·강점에 시간 블록 추천
- 음성 명령: *"오늘 ○○에 집중하겠다"* → 자동 우선순위 재정렬

**시각 요소**:
- 카드 그리드 (3개 핵심 변화)
- 우선순위 리스트 (드래그 가능)
- 위기·기회 신호등
- 일일 코칭 메시지 카드

**권한**:
- 대표 전용 (개인 시간·판단 데이터)
- 임원: 일부 카드만 공유 가능 (대표 동의 시)

### 4.2 ② 라이브 컨설팅 (대화하며 사용)

**목적**: 대표가 의사결정·회의 준비·전략 사고 중에 AI에게 직접 묻고, **AI가 빠진 것·놓친 것을 짚어주는** 능동적 파트너 페이지.

**작동 방식**: 채팅 인터페이스 + 음성 입력. 대표가 자유롭게 질문하면, AI가 6개 카테고리 데이터를 종합해 답변.

**주요 인터랙션 패턴**:

**패턴 A ― 의사결정 코칭 (캠벨 + 그로브)**

대표 입력: *"○○스튜디오와 가격 협상 중인데 5% 깎아줄까?"*

AI 응답 패턴:
1. 데이터 자동 호출:
   - 해당 거래처의 #3 ⑤ 고객 수익성 (마진율·활동기준 원가)
   - #4 가격 결정 이력에서 유사 결정의 결과
   - #2a 거래처 360 뷰의 7단계 위치
2. 그로브 6가지 의사결정 질문 자동 점검:
   - 어떤 결정을 / 언제까지 / 누가 결정 / 누가 의견 / 누가 승인 / 누가 알아야
3. 캠벨식 코칭 질문:
   - *"이 결정으로 ○○스튜디오와의 신뢰가 어떻게 변할까?"*
   - *"비슷한 거래처에 같은 정책을 적용해야 한다면 회사 전체에 미치는 영향은?"*
   - *"가격이 아니라 '가치'를 더 명확히 전달하는 방법은 없을까?"* (드러커 적용)
4. 추천: *"즉답하지 않고 24시간 검토 후 답변할 것을 권장. 그동안 #4 가격-이익 시뮬레이션을 돌려볼까요?"*

**패턴 B ― 회의 준비**

대표 입력: *"내일 마케팅 담당자와 미팅인데 뭐 이야기할까?"*

AI 응답:
- #2b 마케팅 카테고리에서 최근 데이터 자동 종합
- 이번 12주 마케팅 KPI 진행률
- 발행 공백·콘텐츠 ROI 트렌드
- 드림 100 진행 상황
- 추천 어젠다 3-5개 (우선순위 정렬)
- 캠벨 1:1 5가지 질문 자동 적용:
  1. 어떻게 지내고 있는가?
  2. 무엇을 했는가?
  3. 무엇을 할 것인가?
  4. 어떤 도움이 필요한가?
  5. 무엇을 배웠는가?

**패턴 C ― 빠진 것·놓친 것 (능동적 환기)**

AI가 능동적으로 끼어드는 경우:
- 대표가 "신상품 출시 일정"을 논의 중인데 #4 ① 포지셔닝 매트릭스에 등록되지 않은 상태 → *"잠깐만요. 이 신상품의 가격 티어가 아직 정의되지 않았습니다. 출시 전에 ① 포지셔닝부터 정리할 것을 권장합니다."*
- 대표가 1:1 미팅 일정을 잡았는데, 그 직원의 12주 KPI를 한참 안 봤음 → *"이 1:1 전에 ⑤ 직원 KPI를 검토하시면 좋겠습니다. 지난 1:1 액션 아이템 3개 중 2개가 미완료입니다."*

**패턴 D ― 전략 사고 도움**

대표 입력: *"럭셔리 라인 정말 가야 할까?"*

AI 응답:
- 드러커 3가지 질문 자동 적용:
  - *"럭셔리 라인이 우리의 사업 정의를 어떻게 확장하는가?"*
  - *"럭셔리 고객은 우리의 기존 고객과 같은 사람인가?"*
  - *"그들이 가치로 여기는 것은?"*
- #4 카테고리에서 럭셔리 운영의 책임/조건 자료 자동 호출
- 핑크펭귄·지몬 분석 자동 종합 (이전 카테고리 PRD 활용)
- 시나리오 분석 (#3·#4 시뮬레이션 자동 실행)
- 결정을 강요하지 않고 대표가 결정할 수 있는 컨디션 정리

**핵심 인터랙션**:
- 자유 텍스트 + 음성 입력
- AI는 항상 데이터 근거 제시 (어느 카테고리에서 가져왔는지)
- 결정을 대신하지 않음 ― 대표가 결정하도록 도움
- 대화 내용은 자동으로 ③ 이브닝 노트에 정리

**시각 요소**:
- 채팅 UI (메시지 흐름)
- AI 답변에 데이터 근거 카드 첨부
- 캠벨/드러커/그로브 인용 표시

**권한**:
- 대표 전용
- 모든 대화는 비공개 (감사·코칭 데이터)

### 4.3 ③ 이브닝 노트 (하루 마감 자동 정리)

**목적**: 매일 저녁 그날의 활동·의사결정·인사이트를 자동 정리하고, **그로브의 차이 분석 + 드러커의 자기경영 점검**을 통해 학습 자산화.

**작동 시점**: 매일 저녁 자동 생성 (예: 22:00 ― 시간 설정 가능). 텔레그램 동시 발송.

**주요 컴포넌트**:

**(상단) 오늘의 요약**:
- AI가 자동 작성한 하루 요약 (3-5문장)
- 어떤 의사결정을 했는가
- 누구와 만났는가 (1:1 포함)
- 어떤 활동에 시간을 썼는가 (시간 블록 자동 분석)
- 가장 큰 성과 / 가장 큰 미해결

**(중단) 차이 분석 (그로브)**:
- 오늘 아침 ① 모닝 브리핑의 우선순위 vs 실제 한 일
- 일치: 잘 따라간 항목
- 차이: 못 한 항목 + 사유
- 학습 노트: *"왜 이렇게 됐고 다음에 어떻게 할 것인가"*

**(중단) 드러커 자기경영 5가지 점검**:
1. **시간**: 오늘 큰 단위로 시간을 묶어 썼는가, 잘게 쪼개졌는가
2. **공헌**: 오늘의 활동이 회사에 어떤 결과를 만들었는가
3. **강점**: 오늘 강점에 시간을 썼는가, 약점에 매달렸는가
4. **우선순위**: 1순위 일에 충분한 시간을 썼는가
5. **의사결정**: 오늘 결정에서 반대 의견을 충분히 들었는가

**(중단) 의사결정 일지**:
- 오늘 한 결정 자동 정리 (① 모닝·② 라이브 컨설팅에서 추출)
- 각 결정의 *경계 조건* (드러커) 자동 표시
- 90일 후 자동 검증 알림 (#4 ⑧ 가격 결정 이력과 동일 메커니즘)

**(중단) 1:1 미팅 노트 (있을 경우)**:
- 오늘 1:1 미팅 회고 (캠벨)
- 약속한 액션 아이템
- 직원의 신뢰·심리적 안전감 점검
- *내일 이 사람에게 이메일 한 통 보내볼까* 같은 사소한 추천

**(중단) AI의 솔직한 피드백 (캠벨 ― 솔직함 + 친절)**:
- AI가 오늘의 패턴을 보고 솔직하게 짚는 한두 가지
- 예시: *"오늘 콘텐츠 작업에 4시간을 썼는데, 이건 위임 가능한 영역 같습니다. 대표님의 강점은 전략·의사결정에 있다고 데이터가 보여줍니다."*
- 부드럽지만 명확하게

**(하단) 내일 인풋**:
- 오늘 미해결 → 내일로 자동 이전
- 내일 일정 미리보기
- 내일 ① 모닝 브리핑에 반영될 항목

**핵심 인터랙션**:
- AI 자동 작성 → 대표가 검토·수정·승인
- 음성 메모 추가 가능 (오늘의 느낌·인사이트)
- 노트는 ④ 회고 + #1 사후 검토에 자동 누적

**시각 요소**:
- 하루 요약 카드
- 차이 분석 매트릭스 (계획 vs 실제)
- 5가지 자기경영 신호등
- AI 피드백 카드

**권한**:
- 대표 전용 (자기경영 데이터)

### 4.4 ④ 주간·월간·분기 회고

**목적**: 일일 노트가 누적되어 만드는 패턴 분석. 드러커의 자기경영 + 그로브의 차이 분석을 시간 단위로 확장.

**자동 활성화**:
- 매주 일요일 저녁 → 주간 회고
- 매월 말일 → 월간 회고
- 12주 사이클 종료 시 → 분기 회고 (#1 사후 검토와 통합)

**주요 컴포넌트**:

**파트 A ― 시간 사용 분석 (드러커)**:
- 한 주 동안 대표의 시간이 어디에 갔는가 (자동 분석)
- 카테고리별 시간 비중: 콘텐츠 / 재무 / 1:1 / 전략 / 외부 미팅 / 기타
- 12주 추세
- 강점 활동 vs 약점 활동 시간 비율
- 권장 조정: *"이번 주 콘텐츠에 12시간 썼습니다. 평균보다 +40%. 위임 검토 권장."*

**파트 B ― 의사결정 회고**:
- 한 주 한 모든 의사결정 리스트
- 결과가 나온 결정: 검증 (예측 vs 실제)
- 90일 검증 도래한 결정: 학습 노트
- 패턴 분석: *"가격 결정에서 5번 중 3번이 시간 부족으로 즉답. 4단계 워크플로우 사용률 75%."*

**파트 C ― 1:1 미팅 회고 (캠벨 + 그로브)**:
- 이번 주 1:1 미팅 횟수 + 빈도
- 직원별 신뢰 상태 (대표가 자가 평가)
- 액션 아이템 완료율 (그로브 차이 분석)
- *"○○ 직원과 3주 동안 1:1 못함. 이번 주 우선 일정 잡기 권장."*

**파트 D ― 4가지 차원 종합 점수**:
- 사업 차원 (드러커 경영의 실제): 고객 창조에 집중했는가
- 자기 차원 (드러커 자기경영): 강점에 시간 썼는가
- 조직 차원 (그로브): 레버리지 활동을 했는가
- 사람 차원 (캠벨): 신뢰를 쌓았는가
- 4점 척도 + 추세

**파트 E ― 드러커 3가지 질문 분기 점검 (분기 회고에서)**:
- 12주 동안 디안의 사업 정의가 변했는가
- 고객의 가치 인식이 변했는가
- 마케팅과 혁신에 충분히 투자했는가
- 다음 12주 비전 인풋 → #1 사후 검토에 자동 송출

**파트 F ― 학습 자산 누적**:
- 한 주 동안 새로 깨달은 것
- 다음 주에 적용할 것
- 분기 끝에 누적되어 *디안 경영 위키*로 자산화

**핵심 인터랙션**:
- AI가 자동 작성 → 대표가 검토·수정·승인
- 분기 회고는 #1 ⑦ 사후 검토와 자동 통합
- 학습 자산은 검색 가능한 라이브러리

**시각 요소**:
- 시간 사용 도넛 차트
- 의사결정 타임라인
- 1:1 미팅 히트맵
- 4차원 레이더 차트

**권한**:
- 대표 전용
- 임원과 일부 공유 가능 (대표 결정)

### 4.5 ⑤ 시간·강점·우선순위 (드러커 자기경영)

**목적**: 드러커의 자기경영 5가지 습관을 일상에서 트래킹할 수 있는 페이지.

**주요 컴포넌트**:

**파트 A ― 시간 추적**:
- 시간 블록 시스템 (#1 카테고리와 연동)
- 큰 단위로 묶인 집중 시간 (전략·콘텐츠) vs 잘게 쪼개진 시간 (메일·잡무)
- AI가 캘린더 자동 분석 → 시간 사용 패턴 시각화
- 추천: *"전략 사고에 90분 이상 연속 시간이 이번 주 0건입니다. 다음 주 화·목 오전 보호 권장."*

**파트 B ― 강점 매트릭스**:
- 대표 본인의 강점 자기 인식 + 데이터 기반 객관 평가
- 직원별 강점 매트릭스 (그로브 TRM과 연동)
- *"강점 활용도 vs 약점 보완 시간"* 비율
- 위임 추천 자동 생성: *"이 일은 ○○ 직원의 강점에 더 맞습니다."*

**파트 C ― 우선순위 매트릭스**:
- 중요도 × 긴급도 매트릭스 (4분면)
- 대표의 활동을 4분면에 자동 배치
- 드러커 인용: *"중요한 일부터 한 번에 한 가지"*
- 1사분면 (중요+긴급)이 너무 많으면 경고 ― 위기 모드 대신 사전 계획 필요

**파트 D ― 공헌 (Contribution) 정의**:
- 대표가 회사에 기여하고자 하는 결과 명문화
- 12주 단위 갱신 (#1과 연동)
- *"내가 어떤 결과를 만들면 회사가 가장 좋아질까?"*

**파트 E ― 의사결정 패턴 분석**:
- 최근 의사결정에서 반대 의견을 들었는가
- 경계 조건을 명시했는가
- 즉답 vs 검토 후 답변 비율

**핵심 인터랙션**:
- 시간 블록은 #1 ⑥ 개인 KPI와 연동
- 강점 매트릭스 변경 시 ⑥ 사람 관리에 알림
- 우선순위 매트릭스는 ① 모닝 브리핑의 인풋

**시각 요소**:
- 시간 블록 캘린더 뷰
- 강점 레이더 차트
- 4분면 매트릭스
- 의사결정 패턴 차트

**권한**:
- 대표 전용

### 4.6 ⑥ 사람 관리 (캠벨 + 그로브 1:1)

**목적**: 직원과의 신뢰·1:1 미팅·팀 빌딩을 시스템화. 캠벨의 사람 우선 + 그로브의 1:1 + 변동적 검사 통합.

**주요 컴포넌트**:

**파트 A ― 직원별 360도 뷰 (대표 관점)**:
- 직원 카드 (각 직원당 1개):
  - 이름 + 역할
  - 12주 KPI 진행률 (#1 카테고리)
  - 마지막 1:1 미팅 날짜
  - 신뢰 상태 (대표 자가 평가, 1-5)
  - 업무 숙련도 TRM (그로브, 1-5) ― 이에 따라 모니터링 주기 자동 추천
  - 강점 + 성장 영역
  - 최근 30일 발언·기여 요약 (#2a WAM·다른 카테고리에서 자동)

**파트 B ― 1:1 미팅 트래커 (캠벨 + 그로브)**:
- 모든 직원과의 1:1 일정 캘린더
- 권장 빈도 자동 계산 (TRM 기반):
  - 신입·낮은 TRM: 매주
  - 중간: 격주
  - 높은 TRM: 월 1회
- 미팅 전 자동 컨텍스트 호출 (#1 ⑤ 1:1 페이지와 동일)
- 캠벨 5가지 질문 + 그로브 차이 분석 자동 포함

**파트 C ― 팀 빌딩 점검**:
- 캠벨의 팀 퍼스트 원칙 자동 점검:
  - 모든 핵심 역할에 적합한 사람이 배치되어 있는가
  - 팀 크기·다양성 적절한가
  - 팀 내 미해결 갈등이 있는가
  - *"올바르게 이기고 있는가"*
- 위기 신호: *"○○ 팀에서 1:1 빈도 감소 + WAM 발언 감소 ― 신뢰 저하 가능성"*

**파트 D ― 코칭 가이드**:
- 어려운 상황별 캠벨식 접근:
  - 직원 성과 부진 시: 진단 → 지원 → 솔직한 대화
  - 갈등 발생 시: 양측 경청 → 사실 vs 감정 분리
  - 떠나보낼 때: 관대하게 + 성과 인정
- 그로브의 변동적 검사:
  - TRM에 따라 위임 vs 점검 비율 추천

**파트 E ― 신뢰 점검 (캠벨)**:
- *"신뢰는 화폐"* ― 직원별 신뢰 수준 추세
- 약한 모습을 보여줘도 안전하다는 확신이 있는가
- AI가 패턴 분석: 1:1 빈도·발언량·액션 아이템 완료율 등으로 신뢰 추정

**핵심 인터랙션**:
- 직원 카드 → 1:1 일정 잡기 / 직원 KPI 보기 / 강점 매트릭스 갱신
- 1:1 노트는 절대 외부 노출 안 됨 (대표 본인만)
- 팀 빌딩 점검은 분기마다 자동 활성화

**시각 요소**:
- 직원 카드 그리드
- 1:1 빈도 히트맵
- 신뢰 추세 라인
- 팀 구성 다이어그램

**권한**:
- 대표 전용
- 1:1 노트는 데이터베이스 레벨에서 보호

### 4.7 ⑦ 통합 인사이트 대시보드

**목적**: 7대 카테고리의 모든 핵심 KPI를 한 화면에 집약. 대표가 *"전체를 파악"*하고 싶을 때 진입.

**주요 컴포넌트**:

**(상단) 7대 영역 핵심 카드 그리드**:
- 각 카테고리당 1-2개 핵심 KPI
- #1 목표·계획: 12주 진행률
- #2a 영업: 7가지 행동지표 + 시간당 부가가치
- #2b 마케팅: 채널별 도달 + 일관성 점수
- #2c 운영: 일일 매출 + 운영 KPI
- #3 측정·분해: 공헌이익률 + 손익분기 안전 마진
- #4 의사결정: 가격 결정 워크플로우 진행 상황 + 결과의 질
- #7 (자기): 시간 사용 + 신뢰 상태

**(중단) 드러커 3가지 질문 자동 점검 패널**:
- *"우리의 사업은 무엇인가?"* ― 현재 정의 + 변화 신호
- *"우리의 고객은 누구인가?"* ― 거래처 분포 + 새로운 세그먼트 등장
- *"가치로 여기는 것은?"* ― 니즈카드·콘텐츠 ROI에서 추출한 신호

**(중단) 패턴·이상 신호 (AI 자동)**:
- 7대 카테고리 데이터를 종합한 패턴 발견:
  - *"이번 12주 콘텐츠 ROI 상위 5개 모두 디자이너 변화 여정 유형. 다음 12주 이 카테고리에 더 집중 권장"*
  - *"가격 결정 4단계 워크플로우 사용률 80% 도달. 그러나 90일 검증 미작성 60%. 검증 의무화 권장"*
- 정상 vs 이상 자동 분류

**(중단) 4차원 종합 점수 (4권의 책)**:
- 사업·자기·조직·사람 4차원 레이더 차트
- 12주 추세
- 가장 약한 차원 추천 액션

**(하단) 자유 분석**:
- 대표가 직접 질문하는 영역 → ② 라이브 컨설팅으로 연결
- *"이번 분기 가장 큰 성장 동력은?"*
- *"가장 큰 위험은?"*

**핵심 인터랙션**:
- 모든 카드 → 해당 카테고리로 드릴다운
- 패턴 신호 → 추천 액션 즉시 실행
- 4차원 레이더에서 약점 클릭 → 해당 차원의 페이지로

**시각 요소**:
- 7대 카드 그리드
- 3가지 질문 패널 (드러커)
- AI 인사이트 카드 스트림
- 4차원 레이더 차트

**권한**:
- 대표 전용
- 임원: 일부 카드 공유 가능 (대표 동의)

### 4.8 ⑧ 텔레그램 봇 통합 (모바일 외부 연결)

**목적**: 대표가 사무실 밖 / 이동 중 / 외부 미팅 중에도 AI 파트너와 연결되어 있도록 텔레그램 봇으로 핵심 기능 제공.

**주요 기능**:

**A. 자동 발송**:
- ① 모닝 브리핑 매일 아침 (설정 시간)
- ③ 이브닝 노트 매일 저녁
- ④ 주간 회고 일요일 저녁
- 위기 신호 즉시 알림

**B. 음성 메모**:
- 대표가 텔레그램에 음성 메모 → 자동 텍스트 변환 → 적절한 카테고리 등록
- 예: *"방금 ○○스튜디오 미팅 끝. 신규 프로젝트 가능성. 다음주 샘플 발송 약속"* → 자동으로 #2a 활동 다이어리 등록 + 다음 주 작업 알림

**C. 라이브 컨설팅 모바일**:
- 텔레그램 채팅에서 AI에게 질문 → ② 라이브 컨설팅과 동일 작동
- 음성 입력 가능

**D. 알림 설정**:
- 카테고리별 / 임계값별 알림 on·off
- 방해 금지 시간 설정
- 긴급 알림 (위기 신호) 별도 정책

**E. 외부 미팅 빠른 등록**:
- 미팅 직후 텔레그램에 한 줄 입력 → 자동 활동 등록 + 후속 알림
- 명함 사진 업로드 → 신규 거래처 자동 등록 (#2a)

**구현 단계 (Phase)**:
- **Phase 1 (1차)**: 모닝/이브닝 자동 발송만
- **Phase 2 (2차)**: 음성 메모 + 텍스트 컨설팅
- **Phase 3 (3차)**: 명함 인식 + 외부 시스템 통합

**기술 고려사항**:
- 텔레그램 Bot API 사용
- 대표 본인 인증 (다른 사람이 대표 봇 사용 차단)
- 모든 메시지는 ⑦ 대시보드에서 검토 가능 (감사 trail)

**권한**:
- 대표 전용
- 텔레그램 계정 1개와 연동

4. **감사 trail**: 모든 AI 응답은 데이터 근거 표시 (블랙박스 금지)

## 8. 시각·UX 가이드라인

### 8.1 핵심 시각 요소

- **시간의 흐름**: 페이지 구조가 아침→낮→저녁→회고 순으로 흘러감
- **AI 인사이트 카드**: AI가 능동적으로 짚어주는 메시지는 별도 카드 디자인
- **데이터 근거**: AI 응답은 항상 출처 카테고리 카드 첨부
- **4차원 레이더**: 사업·자기·조직·사람 균형 시각화
- **시간 블록 캘린더**: 드러커 시간 추적
- **신뢰 추세 라인**: 캠벨 신뢰 점검

### 8.2 톤 & 보이스 (AI의 어조)
- 솔직하되 따뜻한 (캠벨)
- 데이터 근거를 항상 명시 (그로브)
- 결정을 강요하지 않고 질문으로 유도 (캠벨 코칭)
- 간결하되 충분 (드러커 효율)

### 8.3 디안 브랜드 가이드
*추후 결정. 본 카테고리는 대표 개인 공간이므로 디안 브랜드와 다른 톤 가능 (예: 더 사적·따뜻한 톤)*

## 9. v1.0 마이그레이션 계획

### 9.1 v1.0과의 관계

v1.0에는 본 카테고리에 해당하는 영역이 없다. 단, **v1.0의 AI CFO 자문 메뉴**는 본 카테고리의 ② 라이브 컨설팅으로 진화한다.

| v1.0 메뉴 | 본 카테고리에서의 활용 |
|---|---|
| **AI CFO 자문** | ② 라이브 컨설팅 (확장) ― v1.0보다 훨씬 풍부한 컨텍스트 + 4권의 책 프레임 |

### 9.2 데이터 보존 원칙

- v1.0 AI CFO 자문 대화 이력은 ② 라이브 컨설팅 히스토리에 임포트 (선택)
- 새 카테고리는 신규 데이터부터 시작

### 9.3 마스터 데이터 초기 설정

본 카테고리가 작동하려면 다음 1회성 작업이 필요하다.

1. **AI 모델 선택 + API 키 설정** (Claude·GPT·Gemini 등)
2. **대표 일정 캘린더 연동** (Google Calendar 등)
3. **텔레그램 봇 등록** (BotFather에서 토큰 발급)
4. **본인 강점 자기 인식 입력** (직접)
5. **직원 강점 매트릭스 1차 입력** (대표 평가 + 직원 자가 평가)
6. **드러커 3가지 질문에 대한 디안의 첫 답변 작성**
7. **모닝/이브닝 발송 시간 설정**

## 10. 구현 우선순위 (참고)

| Phase | 페이지 | 비고 |
|---|---|---|
| **P0 (1차)** | ① 모닝 브리핑, ③ 이브닝 노트, ② 라이브 컨설팅 | 매일 사용되는 핵심 |
| **P1 (2차)** | ⑦ 통합 인사이트, ④ 주간·월간 회고 | 패턴 분석 |
| **P2 (3차)** | ⑤ 시간·강점, ⑥ 사람 관리, ⑧ 텔레그램 봇 | 정교화 |

**P0 우선순위 근거**:
- ① ③이 매일 자동 작동해야 시스템이 진짜 파트너로 느껴짐
- ② 라이브 컨설팅이 작동하면 대표가 일상에서 AI에게 의지하기 시작
- 이 셋이 작동하면 다른 페이지들은 자연스럽게 채워짐

**P1 근거**:
- 일일 노트 누적 후 패턴 분석 가능
- 통합 인사이트는 다른 카테고리들이 모두 작동한 후에야 의미 있음

**P2 근거**:
- 시간·강점·사람 관리는 시스템 정착 후 정교화
- 텔레그램 봇은 외부 인프라 구축 필요 (단계적 도입)

### 11.4 가장 중요한 의사결정 ― 4권의 첫 적용

본 카테고리가 작동하기 위해 가장 중요한 것은 **드러커 3가지 질문에 대한 디안의 첫 답변**이다. 이 답변이 모든 AI 분석의 기준점이 된다. 별도 시간(약 2-3시간)을 확보해 작성을 권장한다.

**질문 1: 디안의 사업은 무엇인가?**
- 단순한 원단 유통이 아닌, 디안의 본질
- 답변 예시 ― 디안의 빅 아이디어(#2b ①)와 정합

**질문 2: 디안의 고객은 누구인가?**
- 24셀 매트릭스의 어느 셀에 가장 집중할 것인가
- 럭셔리 라인 도입 시 고객 정의 변화

**질문 3: 고객이 가치로 여기는 것은?**
- #2a 니즈카드와 #2b 가치 정의(#4 ②)에서 종합

이 답변들은 매 분기 갱신되며, 본 카테고리의 모든 분석은 이 답변에 정렬된다.
