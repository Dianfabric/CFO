## 1. 개요

### 1.1 목적
본 카테고리는 **디안의 마케팅을 "뭘 올려야 할지 모르는 막연함"에서 "시스템적으로 반복가능한 콘텐츠 엔진"으로 전환**한다. 5권의 마케팅 책을 WHY-WHAT-HOW의 세 축으로 통합하여, 디안의 차별화(핑크펭귄)에서 출발해 스토리(맥키·픽사)를 거쳐 디지털 실행(러셀 4부작)으로 이어지는 일관된 시스템을 구축한다.

### 1.2 배경
**디안의 현재 상태 (대표님 자기 진단)**:
- 채널 운영: 인스타 ~7,500 팔로워, 유튜브·블로그는 시작 단계
- 인력: 담당자 1명 + 대표, AI 도구 적극 활용 중
- 드림 100 (러셀 트래픽 설계자의 핵심 도구): **아직 정리 안 됨**
- **가장 큰 페인포인트**: 꾸준한 업로드가 어렵다

**책의 핵심 진단**:
- 핑크펭귄: *"고객은 검은 펭귄을 기억하지 않는다. 핑크 펭귄이 되어야 보인다."*
- 맥키·픽사: *"끼어들기 광고의 시대는 끝났다. 자체 플랫폼에서 스토리를 생산하라."*
- 러셀 (트래픽): *"드림 100 ― 잠재 고객이 이미 모여있는 100개의 영향력에 스며들어라."*
- 러셀 (마케팅): *"한 채널에서 1년 일관된 퍼블리싱이 알고리즘보다 강력하다."*
- 러셀 (카피): *"바디 카피보다 헤드라인을 읽는 사람이 평균 5배 더 많다."*

**핵심 시사점**: 디안의 마케팅 페인포인트(꾸준한 업로드)와 책의 핵심 메시지(일관성 + 시스템화)가 정확히 맞물린다. 본 PRD는 **콘텐츠 생산을 반복가능·자동화 가능한 엔진으로 만드는 것**을 P0 사명으로 한다.

### 1.3 카테고리의 위치
본 카테고리는 디안 대시보드 7대 영역 중 **#2b 영역**이며, 다음과 같은 흐름의 중심에 있다.

- **입력**: #4 의사결정의 가치 정의·포지셔닝 + #2a 영업의 디자이너 인사이트(니즈카드) + #1 목표·계획의 12주 마케팅 목표
- **출력**: 콘텐츠 자원·캠페인 ROI → #3 측정·분해 (자원 인수분해의 한 축) / 인스타 팔로워·콘텐츠 발행 수 → #1 선행지표 / 드림 100 컨택 → #2a 영업 (신규 거래처 인풋) / 핵심 마케팅 인사이트 → #7 CEO 코크핏

### 1.4 핵심 철학 (5권의 책에서 추출)

**WHY ― 핑크펭귄 (비숍)**
- *"고객의 눈으로 세상 보기 → 빅 아이디어 → 패키징 → 셀링"*의 3단계
- 모든 마케팅은 차별화에서 시작된다

**WHAT ― 스토리노믹스 + 픽사**
- *"데이터는 사실의 목록, 스토리는 인과관계."* 디안은 사실이 아닌 변화의 여정을 말한다
- *"8초 안에 후크하지 못하면 청중을 잃는다."*
- *"공감할 수 있는 캐릭터 + 명확한 욕망 + 변화의 여정."* 픽사 단편 한 편에 4년이 걸리는 이유

**HOW ― 러셀 4부작**
- *"꿈의 고객 + 드림 100"*: 잠재 고객이 모인 100개 채널·인플루언서·매거진에 스며들기
- *"후크-스토리-제안"*: 모든 광고·포스트의 3요소
- *"가치 사다리"*: 무료 리드 → 저가 언박싱 → 고가 프레젠테이션 → 컨설팅
- *"PLF (제품 출시 공식)"*: 프리-프리런칭 → 프리런칭 → 오픈카트 → 포스트런칭
- *"헤드라인이 본문보다 5배 중요"*: 카피의 80%는 헤드라인에 투자

**전체 통합 메시지**: 5권은 모두 **"일관된 정체성으로, 반복 가능한 시스템을 통해, 진짜 인간적 이야기를 전한다"**는 한 점으로 수렴한다. 디안의 마케팅이 가야 할 방향이 바로 여기다.

## 2. 핵심 원칙

1. **차별화 우선**: 모든 콘텐츠는 핑크펭귄 빅 아이디어에서 출발한다. 검은 펭귄(다른 원단상과 똑같은 콘텐츠)이 되지 않도록 자동 차별화 점검.
2. **8초 후크의 의무화**: 모든 콘텐츠는 8초 안에 청중을 사로잡는 후크로 시작한다. 후크 없는 콘텐츠는 발행 차단.
3. **AI 파이프라인 + 사람 큐레이션**: AI는 초안·반복 작업을 담당, 사람은 차별화·승인·승부수에 집중.
4. **일관성 > 빈도**: *"한 채널에서 1년 일관된 퍼블리싱"*. 채널 분산보다 한 채널의 깊이를 우선.
5. **드림 100 시스템화**: 막연한 마케팅이 아니라 명확한 100개 타겟에 집중.
6. **재사용 자산화**: 모든 콘텐츠는 라이브러리화되어 재활용·재패키징·다채널 변환된다 (꾸준한 업로드의 핵심).
7. **헤드라인이 80%**: 콘텐츠 제작 시간의 80%를 헤드라인·후크에 투자.

## 3. 사용자 시나리오

### 3.1 페르소나

**페르소나 A: 마케팅 담당자**
- 매일 콘텐츠 캘린더 확인 + 발행
- AI 파이프라인으로 초안 생성 → 큐레이션·발행
- 드림 100 컨택 활동 (러셀 핵심)
- 채널별 KPI 모니터링

**페르소나 B: 대표 (CEO)**
- 빅 아이디어·브랜드 정체성 결정
- 핵심 콘텐츠 승인
- 캠페인 ROI 검토
- 드림 100 핵심 인플루언서 직접 컨택

**페르소나 C: AI 어시스턴트**
- 콘텐츠 초안 자동 생성
- 헤드라인·캡션·후크 변형 제안
- 발행 일정 자동 예약
- 성과 분석 리포트 자동 작성

### 3.2 핵심 사용자 여정

**여정 1: 12주 콘텐츠 캘린더 시작 (대표 + 마케팅 담당자)**
1. ① 빅 아이디어 워크북 검토 (필요 시 갱신)
2. ④ 콘텐츠 캘린더에서 12주 콘텐츠 테마 설정 (#1 목표·계획 KPI와 연동)
3. ⑥ 드림 100 트래커에서 이번 12주 컨택할 20-30개 타겟 선정
4. ④ 캘린더에 채널별 발행 일정 자동 분배

**여정 2: 매일 콘텐츠 발행 (담당자 + AI)**
1. ④ 콘텐츠 캘린더에서 오늘 발행할 콘텐츠 항목 확인
2. ⑤ AI 파이프라인이 초안 자동 생성 (스왑파일·헤드라인 템플릿 활용)
3. 담당자가 검토·수정·차별화 점검
4. 발행 → ⑦ 채널별 KPI 자동 추적 시작

**여정 3: 드림 100 컨택 (대표 + 담당자)**
1. ⑥ 드림 100 트래커에서 컨택 단계 확인
2. 인스타 DM, 이메일, 협업 제안 기록
3. 응답 시 자동으로 ② 거래처 360 (#2a 영업)으로 전환 가능
4. 매주 드림 100 컨택 KPI 모니터링

**여정 4: 캠페인 출시 (PLF 적용)**
1. ⑥ 가치 사다리·PLF 페이지에서 새 캠페인 시작
2. 4단계 진행: 프리-프리런칭 → 프리런칭 → 오픈카트 → 포스트런칭
3. 각 단계별 콘텐츠 자동 분배
4. 캠페인 종료 후 ⑦ ROI 분석 자동 생성

**여정 5: 분기 회고 (대표)**
1. ⑦ 콘텐츠 ROI 분석에서 이번 12주 성과 검토
2. 어떤 콘텐츠가 거래로 이어졌나 추적 (#2a 영업 데이터와 연결)
3. 다음 12주 빅 아이디어·콘텐츠 테마 조정
4. 학습 노트 → #1 사후 검토에 자동 첨부

## 4. 페이지 구조 (8개 페이지)

페이지는 다섯 그룹으로 나뉜다.

- **A. 차별화·정체성** (Why ― 핑크펭귄): ①, ②
- **B. 스토리·서사** (What ― 맥키·픽사): ③
- **C. 콘텐츠 생산** (How ― 일상 운영): ④, ⑤
- **D. 트래픽·전환** (How ― 시스템): ⑥
- **E. 측정·학습**: ⑦, ⑧

---

### 4.1 ① 핑크펭귄 빅 아이디어 워크북

**목적**: 디안의 차별화 정체성을 명문화한다. 검은 펭귄(평범한 원단상)이 아닌 핑크 펭귄으로서 디안의 빅 아이디어를 정의.

**주요 컴포넌트**:
- (상단) 비숍의 3단계 워크플로우:

  **Step 1 — 고객의 눈으로 세상 보기**
  - 디안의 핵심 고객(인테리어 디자이너·스튜디오·가구사·스타일리스트)이 진짜 무엇을 원하는가?
  - 그들이 매일 마주치는 문제 + 좌절 + 기쁨 (#2a 니즈카드와 연동 자동 표시)
  - 그들의 일에서 가장 큰 미해결 통증
  - 디안 자기 인식 vs 고객 실제 인식의 갭 (자가점검)

  **Step 2 — 빅 아이디어 창출**
  - 디안만의 차별화된 한 줄 약속
  - "디안은 단순한 원단상이 아니라 ___이다"
  - 경쟁사가 못 따라하는 것
  - 자가점검: "이 빅 아이디어가 핑크펭귄인가, 그냥 또 하나의 검은 펭귄인가?"

  **Step 3 — 패키징·셀링**
  - 빅 아이디어를 어떤 프로그램·서비스·콘텐츠·경험으로 포장할 것인가
  - 어떻게 시장에 내놓을 것인가 (채널·메시지·가격)

- (중단) **차별화 점검 도구**:
  - 디안의 콘텐츠와 경쟁사 콘텐츠 비교
  - 위험 신호 ― "최근 발행 콘텐츠 중 차별화 점수 낮은 것 자동 알림"
  - 핑크펭귄 자가점검 체크리스트

- (하단) 빅 아이디어 변경 이력 + 검토 알림 (분기마다)

**핵심 인터랙션**:
- Step 1·2·3 진행 진척도 표시
- 작성 완료 시 모든 다른 페이지(②~⑧)에 자동 송출 (전 채널 일관성)
- 분기마다 빅 아이디어 검토 알림

**시각 요소**:
- 3단계 워크플로우 카드
- 차별화 점검 신호등
- 빅 아이디어 한 줄 명문 (대형 디스플레이)

**권한**:
- 대표·마케팅 임원: 작성·수정
- 전 직원: 조회 (브랜드 일관성을 위해 모두 알아야 함)

**미해결 사항** (대표님 결정 대기):
- 디안의 빅 아이디어 한 줄: *비워둠 — 워크북 작성 통해 결정*

### 4.2 ② 브랜드 페르소나 정의 (러셀 브랜드 설계자)

**목적**: 러셀의 *"매력적인 캐릭터(Attractive Character)"* 개념 적용. 디안이 시장에서 가지는 인격·목소리·세계관을 명문화.

**주요 컴포넌트**:
- (상단) 매력적인 캐릭터 4요소 (러셀):
  - **백스토리 (Backstory)**: 디안이 왜 시작되었는가, 어떤 여정을 거쳐 왔는가
  - **단점·약점 (Flaws & Vulnerability)**: 완벽한 척하지 않는 솔직함 (맥키 *"진심, 부족한 모습을 숨기지 마라"*와 일치)
  - **양극화 (Polarity)**: 명확한 입장·의견 (모두를 만족시키려 하지 않음)
  - **이야기 가치(Story Value)**: 디안의 세계관·메시지

- (중단) 디안의 목소리 (Voice & Tone):
  - 전문적 vs 친근, 격조 vs 위트, 권위 vs 동료 등 5-7개 축에서 디안의 위치
  - 자주 쓰는 단어·표현, 절대 안 쓰는 표현
  - 채널별 톤 변형 (인스타 vs 유튜브 vs 블로그)

- (중단) 시각 정체성 (Visual Identity):
  - 컬러 팔레트 (디안 브랜드 컬러)
  - 폰트
  - 사진·이미지 스타일 (필름 vs 디지털 / 따뜻함 vs 차가움 / 가까이 vs 멀리)
  - 그래픽 요소

- (하단) 캐릭터 스토리 라이브러리 (러셀):
  - "내가 용감했던 순간" "참패했던 순간" "팀워크의 진가를 처음 느낀 순간" (이미지 4 자료 직접 인용)
  - 디안 대표·팀의 진짜 이야기 누적

**핵심 인터랙션**:
- 모든 콘텐츠 발행 시 페르소나 정합성 자동 검증
- 새 직원·외주에게 페르소나 가이드 자동 공유
- 캐릭터 스토리는 ③ 스토리 라이브러리에 자동 연결

**시각 요소**:
- 4요소 카드
- 음성 톤 매트릭스
- 시각 정체성 패널 (디자인 토큰)

**권한**:
- 대표·마케팅 임원: 작성·수정
- 전 직원: 조회

**미해결 사항**:
- 디안 시각 정체성: *추후 결정 (#1 카테고리에서 미결 항목)*

### 4.3 ③ 디안 스토리 라이브러리

**목적**: 맥키·픽사·러셀의 스토리 프레임을 통합하여 디안의 핵심 스토리들을 자산화. **"꾸준한 업로드의 가장 큰 적은 매번 새로 시작하는 것"** ― 라이브러리가 있으면 재패키징·재구성으로 콘텐츠가 무한히 만들어진다.

**주요 컴포넌트**:
- (상단) 스토리 6단계 프레임 (맥키 + 픽사 통합):
  - **도입**: 누가 주인공인가, 무엇을 원하는가, 왜 그것을 원하는가
  - **사건 촉발**: 변화가 시작되는 계기
  - **점진적 갈등 조성**: 그래서 → 그래서 → 그래서
  - **위기**: 가장 큰 시련
  - **절정**: 결정적 순간
  - **결말**: 변화 후의 새로운 모습

- (중단) **스토리 카테고리** (디안 맞춤):
  
  **유형 1: 디자이너 클라이언트의 변화 여정** (가장 강력)
  - 어떤 공간 고민을 가진 디자이너 → 디안과의 만남 → 함께 만든 솔루션 → 완성된 공간
  - 픽사 공식: 공감 캐릭터 + 명확한 욕망 + 변화의 여정
  
  **유형 2: 디안의 백스토리·창업 이야기**
  - 왜 디안을 시작했는가
  - 가장 어려웠던 순간
  - 핵심 가치가 형성된 사건
  
  **유형 3: 원단의 비하인드**
  - 한 원단이 만들어지는 과정
  - 소재·장인·역사
  - 디안만이 아는 디테일
  
  **유형 4: 트렌드·시즌 스토리**
  - SS·FW 시즌 트렌드 큐레이션
  - 글로벌 인테리어 트렌드 해석
  - 디안 시각의 미래 예측

- (중단) **8초 후크 라이브러리** (맥키):
  - 강력한 첫 8초를 만드는 후크 패턴 누적
  - 이미지 4 자료 직접 인용: *"훅이 없으면 그저 통계자료와 정보를 위에 쌓아 놓은 위에 어떤 것이 숨어 있는지 연구결과에 따르면 사람의 집중력이 지속되는 시간은 평균적으로 8초"*
  - 후크 유형 라이브러리: 질문·통계·논쟁·약속·놀라움·갈등

- (중단) **6가지 보편 주제** (이미지 4):
  - 사랑과 소속감 / 안전과 안정 / 자유와 자발성 / 권력과 책임 / 즐거움과 재미 / 인식과 이해
  - 디안 콘텐츠가 어느 주제에 집중되어 있는지 시각화 (균형 점검)

- (하단) **약점·취약성 라이브러리** (맥키 ― 진심):
  - "내가 부족했던 순간"
  - "실패한 프로젝트와 배운 점"
  - 가짜 강함이 아닌 진짜 인간미를 드러내는 자산

**핵심 인터랙션**:
- 새 스토리 등록 시 6단계 프레임에 따라 작성 가이드
- ④ 콘텐츠 캘린더에서 스토리 라이브러리 호출하여 재패키징
- AI가 한 스토리를 다채널 변형 (인스타 릴스·유튜브 쇼츠·블로그 장문)

**시각 요소**:
- 스토리 카드 그리드 (4가지 유형 색상 분류)
- 6단계 프레임 진행 표시
- 8초 후크 패턴 라이브러리

**권한**:
- 대표·마케팅 임원: 작성·수정
- 영업 담당자: 디자이너 변화 여정 등록 가능 (현장에서 발견한 스토리)
- 전 직원: 조회

### 4.4 ④ 콘텐츠 캘린더 + 채널 운영

**목적**: 12주 단위 콘텐츠 발행 계획을 시각화하고, 채널별 일관성을 유지한다. **"꾸준한 업로드"의 핵심 도구.**

**주요 컴포넌트**:

  - 각 셀: 발행 예정 콘텐츠 카드
  - 색상: 콘텐츠 유형 (스토리·정보·홍보·재포스팅)

- (중단) **러셀의 후크-스토리-제안 분류** (모든 콘텐츠):
  - 후크: 8초 안에 시선을 끄는 것
  - 스토리: 변화·여정·캐릭터
  - 제안: 다음 액션 (팔로우·DM·웹사이트 방문·샘플 신청)

- (중단) **채널별 운영 가이드**:

  **인스타그램 (현재 ~7,500 팔로워, 주력 채널)**:
  - 주력 콘텐츠 유형: 비주얼 + 짧은 스토리
  - 권장 발행 빈도: 주 5-7회 (피드) + 주 2-3회 (릴스) + 주 1-2회 (스토리)

  **유튜브 (시작 단계)**:
  - 주력 콘텐츠 유형: 디자이너 변화 여정 (5-10분), 원단 비하인드 (3-5분), 큐레이션 가이드 (10-15분)
  - 권장 발행 빈도: 주 1회 (일관성 우선)
  - 핵심 KPI: 시청 시간·구독·CTR
  - 러셀 메시지: *"한 채널에서 1년 일관된 퍼블리싱"*
  
  **블로그 (시작 단계)**:
  - 주력 콘텐츠 유형: SEO 최적화 가이드, 트렌드 분석, 케이스 스터디
  - 권장 발행 빈도: 주 1-2회 (SEO 누적 효과)
  - 핵심 KPI: 검색 유입·체류 시간·전환

- (중단) **이메일 리스트** (러셀 마케팅 설계자의 핵심):
  - 이미지 3 자료 직접 인용: *"소셜미디어 + 이메일 리스트 = 성공을 향한 필수 조합"*

  - 리드마그넷: 무료 컬러 가이드 PDF / 큐레이션 샘플북 / 시즌 트렌드 리포트
  - 이메일 시퀀스 자동 발송

- (하단) **재사용 시스템**:
  - 한 콘텐츠 → 4-6개 채널 변형 자동 생성
  - 과거 인기 콘텐츠 재패키징 추천
  - "이 스토리는 6개월 후 재사용 가능" 자동 알림

**핵심 인터랙션**:

- ⑤ AI 파이프라인 호출하여 즉시 초안 생성

### 4.5 ⑤ AI 콘텐츠 생산 파이프라인

**목적**: **꾸준한 업로드의 결정적 도구.** AI가 초안·변형·반복 작업을 담당하고, 사람은 차별화·승인·승부수에 집중하는 구조를 시스템화.

**주요 컴포넌트**:
- (상단) **콘텐츠 생산 워크플로우**:

  **Step 1 — 인풋 수집**:
  - ① 빅 아이디어 + ② 페르소나 + ③ 스토리 라이브러리 자동 호출
  - #2a 영업의 니즈카드 / #4 가치 정의 / 시즌·트렌드 자동 참고

  **Step 2 — AI 초안 생성**:
  - 콘텐츠 유형 선택 (인스타 캡션·릴스 대본·유튜브 스크립트·블로그 글·이메일)
  - AI가 다중 후보 생성 (3-5개 변형)
  - 디안 페르소나 자동 적용

  **Step 3 — 헤드라인·후크 최적화**:
  - 러셀 카피 공식 자동 적용 (이미지 2 자료 활용)
  - 헤드라인 템플릿 5종 제안:
    - "X하는 법" (고통 회피·즐거움 추구)
    - "X일 안에 X하는 법" (기간 명시)
    - "X 사람도 X하는 법" (장애 요소)
    - "누구나 X하는 법" (보편성)
    - 디안 맞춤 추가 패턴

  **Step 4 — 차별화 점검**:
  - ① 핑크펭귄 워크북에 따라 자동 체크
  - "이 콘텐츠는 검은 펭귄인가, 핑크 펭귄인가?" 자동 판정
  - 평범하면 차별화 추천

  **Step 5 — 사람 큐레이션**:
  - 담당자가 검토·수정·결정
  - 대표 승인 (필요 시)

  **Step 6 — 발행·자동 변형**:
  - 한 콘텐츠 → 4-6개 채널 변형 (인스타 캡션·릴스·유튜브 쇼츠·블로그 요약·이메일·트위터 등)
  - 자동 일정 예약

- (중단) **스왑파일** (러셀 카피라이팅 설계자, 이미지 2):
  - 이미지 2 직접 인용: *"당신이 좋아하는 광고와 '우와, 내가 활용해볼 만한 멋진 문구네' 싶은 헤드라인을 모아 놓은 파일"*
  - 인테리어 디자인·라이프스타일·럭셔리 광고에서 영감을 받은 후크·헤드라인·카피 모음
  - 카테고리별 분류
  - AI가 새 콘텐츠 작성 시 자동 참조

- (중단) **불릿 공식** (러셀):
  - 강력한 불릿 포인트 작성 공식
  - 디안 콘텐츠에서 자주 사용되는 불릿 패턴 라이브러리

- (하단) **AI 자원 사용 추적**:
  - 이번 달 AI 도구 사용 비용·시간
  - AI가 절약한 시간 추정
  - #3 측정·분해의 자원 인수분해와 연동

**핵심 인터랙션**:
- ④ 콘텐츠 캘린더에서 직접 호출
- 생성된 초안은 ③ 스토리 라이브러리에 자동 등록
- 사용 결과 → AI 학습 (디안 페르소나 정밀화)

**시각 요소**:
- 6단계 워크플로우 진행 표시
- AI 변형 카드 (3-5개 비교)
- 차별화 점검 신호등

**권한**:
- 마케팅 담당자: 작성·발행
- 대표: 승인 + AI 학습 데이터 검토
- AI는 도구 ― 데이터 보호 정책 적용

### 4.6 ⑥ 드림 100 트래커 + 가치 사다리·PLF

**목적**: 러셀 트래픽 설계자의 핵심 도구 ― **드림 100**을 시스템화. 그리고 러셀 마케팅 설계자의 PLF (제품 출시 공식) 적용.

  - 단계 전환 활동 기록 (DM·이메일·미팅·콘텐츠 멘션)

- (중단) **컨택 활동 기록**:

- (하단) 드림 100 KPI:
  - 이번 12주 컨택 목표 vs 실적
  - 단계 전환률
  - 팬으로 전환된 타겟의 매출 기여도

**파트 B: 가치 사다리 + PLF**

**주요 컴포넌트**:
- (중단) **가치 사다리** (러셀 마케팅 설계자):

  **단계 1 — 무료 리드** (최상단, 가장 많은 사람 접근):
  - 무료 컬러 가이드 PDF
  - 시즌 트렌드 리포트
  - 무료 큐레이션 샘플북
  - 인스타·블로그 무료 콘텐츠

  **단계 2 — 저가 언박싱**:
  - 미니 샘플 키트 (저가)
  - 1회성 컨설팅 콜
  - 단발 프로젝트 견적

  **단계 3 — 핵심 제품**:
  - 정규 원단 거래
  - 프로젝트 단위 큐레이션

  **단계 4 — 고가 프리미엄**:
  - 럭셔리 라인 거래 (#4 카테고리와 연동)
  - 연간 파트너십 계약
  - 1:1 텍스처 컨설팅

- (중단) **PLF (Product Launch Formula)** (이미지 3 자료 활용):
  - 이미지 3 직접 인용: *"PLF는 당신의 표적시장이 당신의 제품을 너무나도 필요로 한다는 점을 인식시켜 그 표적시장이 당신에게 제품의 판매를 요청하도록 만드는 시스템"*
  
  **PLF 4단계**:
  1. **프리-프리런칭**: 제품에 대한 기대감 심기 (부족 활성화)
  2. **프리런칭**: 가치 콘텐츠 시리즈 (4-7일)
     - PLC 1: 기회
     - PLC 2: 변화
     - PLC 3: 사용자 경험
     - PLC 4 (오픈카트): 구매
  3. **오픈카트**: 가격 인상 예정·부가 혜택 사라짐·런칭 후 판매 중단
  4. **포스트런칭**: 마무리·고객 확보

- (하단) PLF 캠페인 트래커:
  - 진행 중인 캠페인 일정
  - 각 단계별 콘텐츠 예약
  - 이메일 리스트 반응
  - 매출 전환

**핵심 인터랙션**:
- 드림 100의 팬 단계 진입 시 → #2a 영업으로 자동 전환 (거래처 등록)
- PLF 시작 시 ④ 콘텐츠 캘린더에 자동 일정 분배
- 가치 사다리의 각 단계는 #4 가격 결정과 연동

**시각 요소**:
- 드림 100 매트릭스 (영향력 × 단계)
- 가치 사다리 다이어그램
- PLF 4단계 진행 표시

**권한**:
- 대표·마케팅 임원: 드림 100 정의·PLF 캠페인 시작
- 마케팅 담당자: 컨택 활동 기록
- 영업 담당자: 팬 전환 시 거래처로 인수

**미해결 사항**:
- 디안의 드림 100: *비워둠 — 별도 워크숍으로 작성 권장 (대표 + 마케팅 담당자 1일 워크숍)*

### 4.7 ⑦ 채널별 KPI 대시보드

**목적**: 인스타·유튜브·블로그·이메일 등 채널별 성과를 한눈에 모니터링. #1 선행지표의 데이터 소스.

**주요 컴포넌트**:
- (상단) 채널별 통합 카드:

  **인스타그램**:
  - 팔로워 수 (현재 ~7,500 → 12주 목표)
  - 도달·노출
  - 저장·공유
  - 프로필 방문 → 웹사이트 클릭 → DM·문의
  - 콘텐츠 발행 수 (피드·릴스·스토리)

  **유튜브**:
  - 구독자
  - 시청 시간 (총합)
  - 평균 시청 지속률
  - CTR (썸네일 클릭률)
  - 콘텐츠 발행 수

  **블로그**:
  - 검색 유입 (오가닉)
  - 페이지뷰
  - 평균 체류 시간
  - 전환 (이메일 구독·문의)
  - 발행 수 + 누적 SEO 효과

  **이메일**:
  - 구독자 수
  - 오픈율
  - 클릭률
  - 구매·문의 전환

- (중단) **일관성 점수** (러셀 핵심):
  - 책의 메시지 *"한 채널에서 1년 일관된 퍼블리싱이 알고리즘보다 강력하다"*
  - 디안의 일관성 점수: 발행 빈도 안정성 + 톤·메시지 일관성
  - 80% 기준선 표시 (#1 카테고리와 일관)

- (중단) **드림 100 효과**:
  - 드림 100 컨택 후 신규 팔로워·구독자 추적
  - 영향력 있는 멘션·협업의 ROI

- (하단) **채널별 성과 비교**:
  - 시간당 부가가치 (어느 채널이 가장 효율적인가)
  - 12주 추세
  - 추천 액션

**핵심 인터랙션**:
- 각 채널 클릭 → 상세 분석
- 일관성 점수 < 80% 시 자동 알림
- 드림 100 ROI는 ⑥ 트래커와 양방향 연결

**시각 요소**:
- 채널별 KPI 카드 그리드
- 일관성 게이지
- 시계열 트렌드 라인

**권한**:
- 마케팅 담당자: 본인 운영 채널 전체
- 대표·임원: 전체 + 비교 분석
- 전 직원: 회사 마케팅 합계 (절대값 일부 제한)

### 4.8 ⑧ 콘텐츠 ROI 분석

**목적**: **"어떤 콘텐츠가 실제 거래로 이어졌는가?"** 마케팅의 가장 어려운 질문에 답하는 페이지. #2a 영업·#3 측정과 연계해 진짜 ROI 측정.

**주요 컴포넌트**:
- (상단) 콘텐츠별 매출 기여 매트릭스:
  - 가로축: 콘텐츠 (시간순)
  - 세로축: 채널
  - 색상: 추정 매출 기여도
  - 클릭하면 어떤 거래처가 이 콘텐츠 후 컨택했는지 표시

- (중단) **거래처 발견 경로 분석**:
  - 신규 거래처가 디안을 어떻게 찾았는가 (#2a 영업과 연동)
  - 인스타 → 거래 / 블로그 → 거래 / 드림 100 협업 → 거래 등
  - 채널별 LTV (Lifetime Value)

- (중단) **콘텐츠 카테고리별 ROI**:
  - 디자이너 변화 여정 vs 백스토리 vs 원단 비하인드 vs 트렌드 분석
  - 어느 카테고리가 가장 거래로 이어지는가
  - 후크 유형별 ROI (질문·통계·논쟁·약속·놀라움)

- (중단) **자원 인수분해** (#3 카테고리 연계):
  - 콘텐츠 1편 제작에 들인 시간·인건비·외주비·AI 비용
  - 콘텐츠당 시간당 부가가치
  - 전체 마케팅 자원 vs 산출 매출 ROI

- (하단) **학습 노트**:
  - 12주마다 자동 활성화
  - 잘 된 콘텐츠 패턴 / 실패 패턴
  - 다음 12주 콘텐츠 전략 인풋
  - #1 사후 검토에 자동 첨부

**핵심 인터랙션**:
- 거래처 클릭 → ② 거래처 360 (#2a)으로 이동
- 콘텐츠 클릭 → ④ 콘텐츠 캘린더의 해당 항목으로 이동
- 학습 노트는 ① 빅 아이디어 워크북 갱신에 인풋

**시각 요소**:
- ROI 매트릭스 (히트맵)
- Sankey 차트 (콘텐츠 → 거래처 흐름)
- 자원 vs 산출 비교

**권한**:
- 대표·임원: 전체 분석
- 마케팅 담당자: 본인 콘텐츠 ROI

## 9. v1.0 마이그레이션 계획

### 9.1 v1.0과의 관계

v1.0에는 마케팅·콘텐츠·드림 100·PLF 영역이 존재하지 않는다. 본 카테고리는 신규 추가다.

### 9.2 데이터 보존 원칙

- 디안의 기존 인스타·블로그·유튜브 콘텐츠는 ④ 콘텐츠 캘린더에 임포트 (선택적)
- 기존 팔로워·구독자 데이터는 ⑦ 채널 KPI의 시작점으로 사용
- 기존 콘텐츠는 ③ 스토리 라이브러리에 분류·태깅하여 재사용 가능 자산화

### 9.3 마스터 데이터 초기 설정 (1회성)

본 카테고리가 작동하려면 다음 마스터 데이터의 1회성 작업이 필요하다.

1. **빅 아이디어 워크북 작성** (대표 + 마케팅 담당자 워크숍, 약 1-2일)
2. **브랜드 페르소나 정의** (워크숍, 약 1일)
3. **드림 100 리스트 작성** (워크숍, 약 1일 ― **가장 시급**)
4. **기존 콘텐츠 라이브러리 임포트** (선택)
5. **채널 API 연결** (인스타·유튜브·블로그·이메일)
6. **AI 도구 API 키 설정**

## 10. 구현 우선순위 (참고)

| Phase | 페이지 | 비고 |
|---|---|---|
| **P0 (1차)** | ④ 콘텐츠 캘린더, ⑤ AI 파이프라인, ⑦ 채널 KPI | "꾸준한 업로드" 페인포인트 직접 해결 |
| **P1 (2차)** | ① 빅 아이디어, ② 페르소나, ③ 스토리 라이브러리 | 차별화·정체성 명문화 |
| **P2 (3차)** | ⑥ 드림 100 + PLF, ⑧ ROI 분석 | 시스템 정착 후 고도화 |

**P0 우선순위 근거**:
- 디안의 가장 큰 페인포인트가 "꾸준한 업로드"이므로, 이를 직접 푸는 도구가 최우선
- AI 파이프라인이 작동하기 시작하면 즉시 일상 운영 효율화
- 채널 KPI는 발행 결과를 바로 보여주어 동기 부여

**P1·P2 근거**:
- 빅 아이디어·페르소나·스토리는 차별화의 기반이지만, 일단 운영이 시작되어야 검증 가능
- 드림 100·PLF는 시스템이 어느 정도 자리잡은 후 고도화 단계

## 13. 부록: PRD 2a 보완 사항 (트레이시 자료 추가 받음)

대표님이 본 메시지에서 추가로 트레이시 마인드맵 자료(이미지 1)를 올려주셨다. 이 자료를 기반으로 **PRD 2a 영업 전략 카테고리**의 ⑦ 자기경영 페이지를 보완할 수 있다.

### 보완할 내용:
- **자기 이미지 (Self-Image)** 명시: 디안 영업이 매일 체크하는 자기 이미지 점수 + "최고가 되라" 자아상 형성
- **소득 감지 장치**: 트레이시의 "안전지대를 바꿔라" 개념 — 영업이 자신의 잠재 소득 한계를 인식·재설정
- **현실적 목표 + 100가지 목표**: 트레이시의 목표 설정법 적용 — 구체적·측정가능·100개의 풍부한 목표 리스트
- **거절에 대한 두려움**: 자료에 명시된 "성공적 판매를 위한 장애물 — 실패에 대한 두려움 + 거절에 대한 공포" — 거절 처리 노트의 심리적 차원 강화
- **상위 20% 안에 들겠다는 결심**: 트레이시 자료 직접 인용 *"오늘, 자기분야에서 상위 20퍼센트 안에 들겠다고 결심하라. 나보다 똑똑한 사람도, 더 나은 사람도 없음을 명심하라"* — ⑦ 자기경영 페이지의 일일 체크인 메시지에 통합

**보완 적용 시점**: 본 PRD(2b) 검토·승인 후 PRD 2a v0.2 업데이트로 반영
