# 디안 CFO 대시보드 PRD
## 카테고리 1: 목표·계획 (Goals & Planning)

**문서 버전**: v0.1 (1차 초안)  
**기준 일자**: 2026년 5월 4일  
**카테고리 위치**: 디안 대시보드 7대 영역 중 #1 ― 목표·계획  
**참고 도서**: 브라이언 P. 모런·마이클 레닝턴 『위대한 12주』

---

## 1. 개요

### 1.1 목적
본 카테고리는 디안의 **12주 단위 목표 설정·실행·검증·개선 사이클을 디지털화**하여, 회사 전체와 개인이 동일한 목표 위계 안에서 일관되게 움직이도록 하는 것을 목적으로 한다.

### 1.2 배경
디안은 이미 12주 사이클과 매주 월요일 WAM(주간 책임 모임)을 운영하고 있으며, 매출·신규 거래처·인스타그램 팔로워·콘텐츠 발행 수 등 후행지표와 선행지표를 종합적으로 추적하고 있다.

본 카테고리의 목표는 **새로운 시스템을 도입하는 것이 아니라**, 이미 잘 작동하는 운영을 디지털 인프라로 옮기고, 책의 미실천 영역(비전 위계 명문화, 시간 블록, 80% 기준선, 형식화된 사후검토, 1:1 미팅)을 자연스럽게 보강하는 것이다.

### 1.3 카테고리의 위치
본 카테고리는 디안 대시보드 7대 영역 중 **#1 영역**이며, 모든 KPI의 **발원지** 역할을 한다. 여기서 정한 12주 목표가 다른 6개 카테고리(영업, 마케팅, 운영, 측정, 의사결정, CEO 코크핏)에 흘러가 추적된다.

## 2. 핵심 원칙

다음 다섯 가지 원칙은 본 카테고리의 모든 페이지·기능 설계에서 변하지 않는 기준이다.

1. **80% 달성 = 성공**: 모든 진행률 게이지에 80% 기준선을 명시적으로 표시한다. 100%만이 성공이라는 인식을 제거하고, 80%를 의미 있는 성취로 인정한다.
2. **단순화의 강제**: 12주 목표는 3~5개를 권장하며, 5개 초과 입력 시 시스템이 경고한다.
3. **WAM 중심 운영**: 모든 데이터 흐름은 매주 월요일 미팅이 효율적으로 진행되도록 설계된다.
4. **선행지표 우선**: 후행지표(결과)뿐 아니라 선행지표(활동)를 동등한 비중으로 추적한다.
5. **익숙한 흐름 보존**: 디안 직원들이 기존에 해오던 월요일 미팅과 보고 흐름을 디지털 안에서 그대로 재현한다.

## 3. 사용자 시나리오

### 3.1 페르소나

**페르소나 A: 대표 (CEO)**
- 매일 아침 대시보드 메인 페이지로 진입해 회사 전체 진행률 확인
- 매주 월요일 WAM 진행 → 주간 패턴 검토
- 12주 사이클 종료 시점에 사후 검토 작성
- 직원들과 정기적인 1:1 미팅 진행

**페르소나 B: 임원**
- 대표와 동일한 권한, 부서 단위 KPI 집중 모니터링
- 본인 팀원들과 1:1 미팅 진행

**페르소나 C: 팀원/직원**
- 매주 월요일 WAM 참석 → 본인 진행 사항 보고
- 본인 KPI 페이지에서 개인 목표 추적
- 시간 블록 시범 사용
- 대표 또는 직속 임원과 정기적 1:1 미팅

### 3.2 핵심 사용자 여정

**여정 1: 12주 사이클 시작 (D-7 ~ D+0)**
1. 대표가 ② 비전·목표 설정 페이지에 진입
2. 장기/3년 비전 검토 (수정 필요 시)
3. 다음 12주 회사 목표 3~5개 작성 (책임자, 80% 기준, 100% 목표 명시)
4. 직원 개인별 KPI 작성 또는 직원 본인이 작성
5. 첫 WAM에서 모든 목표 공유

**여정 2: 매주 월요일 WAM (반복)**
1. 직원들이 미팅 전 본인 페이지에서 지난주 결과 자동 표시 확인
2. 미팅 시작 ― 대시보드를 큰 화면에 띄움(회의실 모드)
3. 한 사람씩 지난주 계획 vs 실적, 이번 주 핵심 활동 발표
4. 도움 요청 / 장애물 공유
5. 미팅 종료 시 자동 회의록 생성, 다음 주 아젠다 초안

**여정 3: 1:1 미팅 (주기적)**
1. 대표 또는 임원이 ⑤ 1:1 페이지에 진입, 직원 선택
2. 자동으로 해당 직원의 KPI 진행률, 지난 1:1 액션 아이템, 최근 WAM 발언 표시
3. 미팅 진행, 노트 입력, 액션 아이템 도출
4. 직원 본인의 12주 목표 수정이 필요하면 그 자리에서 수정

**여정 4: 사이클 종료 (Week 11 ~ Week 12)**
1. Week 11 시작 시점에 ⑦ 사후 검토 페이지 자동 활성화
2. 사후 검토 미팅 일정 설정
3. 회사 전체 목표 결과 검토 ― 80% 이상 달성 / 미만 / 미시작
4. 책의 회고 질문에 답변
5. 다음 12주 비전·목표 설정 페이지로 자동 연결

## 4. 페이지 구조 (7개 페이지)

### 4.1 ① 12주 사이클 대시보드 (메인 진입)

**목적**: 매일 아침 회사 전체 진행 상황을 한눈에 확인.

**주요 컴포넌트**:
- (상단) 카운터: "Week N / 12" + 사이클 종료일 / 다음 WAM 카운트다운
- (중단) 회사 12주 목표 카드:
  - 각 목표마다 진행률 게이지
  - 80% 기준선 명시
  - 책임자 표시
  - 마지막 업데이트 시각
- (중단) 후행지표 패널:
  - 매출 (12주 시작 대비 변화량 + 추세선)
  - 신규 거래처 수
  - 인스타 팔로워 수
  - 마진율
- (중단) 선행지표 패널:
  - 콘텐츠 발행 수 (이번 주 누적 + 지난 주 대비)
  - 디자이너 컨택 수
  - 샘플 발송 수
  - 미팅 수
- (하단) "이번 주 WAM" 알림 카드 (다음 월요일까지 D-day, 안건 미리보기)

**핵심 인터랙션**:
- 각 목표 카드 클릭 → 해당 목표의 상세 페이지(③ 지표 트래커 또는 다른 카테고리)로 드릴다운
- 후행지표 항목 클릭 → 측정·분해 카테고리로 이동
- 선행지표 항목 클릭 → 영업·마케팅 카테고리로 이동

**모드**:
- 일반 모드: 데스크톱·모바일에서 일상 조회
- 회의실 모드: WAM 진행 시 큰 화면 최적화 (큰 글씨, 단순화된 레이아웃)

**권한**:
- 전 직원: 회사 전체 진행률 조회
- 임원·대표: + 직원별 기여도 분석

---

### 4.2 ② 비전·12주 목표 설정

**목적**: 장기 비전과 12주 목표를 설정하고 명문화한다.

**주요 컴포넌트**:
- 장기 비전 (5년+) 입력 영역 ― 자유 텍스트 + 핵심 키워드 태그
- 3년 비전 입력 영역 ― 자유 텍스트 + 측정 가능한 마일스톤 3~5개
- 12주 목표 입력 영역 (3~5개 권장):
  - 목표 제목
  - 책임자 지정 (대표·임원·팀원)
  - 측정 단위 (예: 원, 명, 개, %)
  - 80% 기준 수치
  - 100% 목표 수치
  - 목표 설명 / 배경
  - 연결되는 카테고리 (영업·마케팅·운영·측정·의사결정 중 선택)
- 비전 정합성 자체 점검 체크리스트:
  - "이 목표가 3년 비전과 정렬되는가?"
  - "이 목표가 자신/팀에게 매우 중요한가?"
  - "80% 달성으로 충분히 의미 있는가?"
  - "측정 가능한가? 누가, 언제, 어떻게 측정하는가?"

**핵심 인터랙션**:
- 목표 5개 초과 입력 시 경고 메시지: "위대한 12주는 단순화를 권장합니다"
- 비전 수정 시 변경 이력 자동 저장
- 목표 작성 완료 시 "공유" 버튼 → 전 직원에게 알림

**권한**:
- 전 직원: 조회만 가능
- 임원·대표: 작성·수정·이력 조회

**미해결 사항** (대표님 결정 후 입력):
- 디안의 장기 비전: *비워둠*
- 디안의 3년 비전: *비워둠*

---

### 4.3 ③ 선·후행 지표 트래커

**목적**: 12주 목표 달성을 위한 선행지표(활동)와 후행지표(결과)를 추적한다.

**주요 컴포넌트**:
- (좌측) 후행지표 섹션:
  - 매출 (일/주/월/12주 단위)
  - 신규 거래처 수 (총수 + 인스타 유입 분리 표시)
  - 마진율
  - 인스타 팔로워 수
  - 직군별·제품별 매출 분해 차트 (디안의 종합 판단 디지털화)
- (우측) 선행지표 섹션:
  - 콘텐츠 발행 수 (인스타·블로그·유튜브 채널별 분리)
  - 디자이너 컨택 수 (전화·메일·DM·미팅 분류)
  - 샘플 발송 수
  - 미팅 수 (영업 활동)
- 각 지표마다 12주 시작점 대비 변화량 + 80% 기준선
- 선행 → 후행 상관관계 시각화 (예: "콘텐츠 발행이 늘어난 주에 신규 거래처가 늘어나는가?")

**핵심 인터랙션**:
- 지표 클릭 → 원본 카테고리로 이동 (영업·마케팅·측정 등)
- 기간 필터: 일/주/월/12주
- 직군별·제품별 필터

**데이터 흐름**:
- 본 페이지의 데이터는 **자동 수집**된다. 직접 입력하지 않는다.
- 후행지표: 측정·분해 카테고리에서 자동 동기화
- 선행지표: 영업·마케팅 카테고리에서 자동 동기화
- 인스타 팔로워: 마케팅 카테고리의 채널 KPI에서 자동 동기화

**권한**:
- 전 직원: 회사 전체 지표 조회 (요약)
- 임원·대표: + 드릴다운 + 직원별 기여도 분석

---

### 4.4 ④ 주간 계획 · WAM (월요일 미팅)

**목적**: 매주 월요일 아침의 책임 미팅이 디지털 환경 안에서 효율적으로 진행되도록 한다.

**주요 컴포넌트**:
- (상단) 미팅 정보: 일시, 참석자, 진행자
- (중단) 직원별 카드 (자동 생성):
  - 지난주 계획 (책의 표현 그대로)
  - 지난주 실적 (선행지표 자동 표시)
  - 이번 주 핵심 활동 입력 (12주 목표 중 어느 목표와 연결되는지 선택)
  - 도움 요청 / 장애물
- (하단) 미팅 회의록 자동 초안:
  - 참석자
  - 핵심 발언 정리
  - 결정사항
  - 액션 아이템 (담당자 + 마감)

**핵심 인터랙션**:
- 미팅 모드 진입 → 큰 화면 최적화
- 발표자 순서 자동 진행 (한 명씩 페이지 자동 전환)
- 미팅 종료 시 자동 회의록 + 다음 주 아젠다 초안
- 액션 아이템은 자동으로 다음 주 WAM 카드의 "지난주 계획"에 반영

**권한**:
- 전 직원: 본인이 참여한 미팅 조회·편집
- 임원·대표: 모든 미팅 + 패턴 분석 (참석률, 액션 아이템 완료율 등)

---

### 4.5 ⑤ 원온원 (1:1) 미팅

**목적**: 대표 또는 매니저가 직원과 정기적인 1:1 미팅을 통해 개인 목표를 점검·수정·코칭한다.

**주요 컴포넌트**:
- (상단) 직원 선택 + 미팅 일정 (정기적·임시적 구분)
- (중단) 컨텍스트 자동 표시:
  - 해당 직원의 12주 KPI 진행률
  - 지난 1:1 미팅 액션 아이템 (완료 여부)
  - 최근 4주간 WAM 발언 요약
  - 본인이 보고한 장애물·도움 요청 이력
- (중단) 미팅 노트 입력 영역
- (하단) 액션 아이템 도출 + 다음 1:1 일정 설정

**핵심 인터랙션**:
- 미팅 중 직원의 12주 목표 수정 가능 (수정 이력 자동 기록)
- 액션 아이템은 직원의 개인 KPI 페이지에 자동 반영
- 코칭 질문 템플릿 제공 (빌 캠벨 + 그로브 프레임에서 추출, 추후 CEO 코크핏 카테고리에서 보강)

**권한**:
- 미팅 참여자만 조회·편집 가능 (대표 ↔ 직원, 임원 ↔ 팀원)
- 대표: 모든 1:1 미팅 패턴 분석 가능 (단, **노트 본문은 제외** ― 신뢰의 기본)

**비고**:
- 본 페이지는 7대 카테고리 중 #7 (CEO 코크핏)의 "자기·팀 경영" 영역과 깊이 연계된다.
- 1:1 미팅 주기는 시범 운영 후 결정 (월 1회 / 격주 / 매주 옵션)

---

### 4.6 ⑥ 개인 KPI · 시간 블록

**목적**: 직원 개개인이 본인의 12주 목표를 추적하고 시간 사용을 관리한다.

**주요 컴포넌트**:
- (상단) 본인의 12주 목표 카드 (각 목표 진행률 + 80% 기준선)
- (중단) 시간 블록 시스템 *(시범 운영)*:
  - 전략 블록: 집중 작업 시간 (방해 차단)
  - 버퍼 블록: 메일·잡무·즉답 처리
  - 브레이크 블록: 보상·휴식
  - 일주일 시간표 위에 색상으로 표시
- (중단) 주간 자기평가:
  - 5점 척도 (목표 진척, 시간 사용 만족도, 에너지 수준)
  - 한 줄 메모
- (하단) 4주 누적 추세

**핵심 인터랙션**:
- 시간 블록 드래그&드롭으로 일주일 계획 작성
- 자기평가는 매주 일요일 저녁 알림 (다음 WAM 준비)

**권한**:
- 본인: 전체 조회·편집
- 임원·대표: 모든 직원 조회 (단, "한 줄 메모"는 본인 동의 시에만 ― 심리적 안전감)

**비고**:
- 시간 블록은 책의 핵심 개념이지만 디안에서는 **시범 운영**으로 시작 (직원 적응 기간 필요)
- 사용률 낮을 시 단순화 또는 제거 옵션 검토

---

### 4.7 ⑦ 사후 검토 (Cycle Review)

**목적**: 12주 사이클이 끝나는 시점에 회사 전체와 개인의 성과를 회고하고, 다음 사이클의 인풋을 정리한다.

**활성화 시점**: Week 11 시작 시점에 자동으로 활성화 (대시보드에 알림 표시)

**주요 컴포넌트**:
- (상단) 사이클 요약 자동 표시:
  - 회사 12주 목표별 달성률 (80% 이상 / 80% 미만 / 미시작 분류)
  - 후행지표 12주 변화량
  - 선행지표 12주 변화량
- (중단) 회고 질문 (책의 마인드맵에서 추출):
  - "비전과 실행이 정렬되었는가?"
  - "선행지표가 후행지표로 이어졌는가?"
  - "WAM이 효과적이었는가?"
  - "장애물은 무엇이었고 어떻게 극복했나?"
  - "다음 12주에 가져갈 학습 3가지는?"
- (중단) 직원별 기여도 정리 (대표·임원만 조회)
- (하단) 다음 12주 인풋 ― 비전·목표 설정 페이지로 자동 연결

**핵심 인터랙션**:
- 사후 검토 미팅 일정 설정 (전 직원 참여)
- 미팅 중 큰 화면 모드
- 검토 완료 후 "다음 사이클 시작" 버튼 → ② 비전·목표 설정 페이지로 자동 이동

**권한**:
- 전 직원: 조회 + 본인 부분 코멘트
- 임원·대표: 작성·수정 + 직원별 기여도 분석

## 5. 데이터 모델

### 5.1 핵심 엔티티

| 엔티티 | 핵심 필드 | 관계 |
|---|---|---|
| `Vision` | id, type(장기/3년), content, lastUpdated, updatedBy | 1:N → Goal12W |
| `Cycle` | id, cycleNumber, startDate, endDate, status | 1:N → Goal12W, 1:1 → CycleReview |
| `Goal12W` | id, cycleId, title, ownerId, targetType, threshold80, target100, unit, linkedCategory, status | N:1 → Cycle, 1:N → WeeklyPlan |
| `WeeklyPlan` | id, cycleId, weekNumber, userId, goalId, plannedActivities, actualActivities, status | N:1 → Goal12W |
| `Indicator` | id, type(선행/후행), name, value, date, sourceCategory, goalId | N:1 → Goal12W |
| `WAMRecord` | id, cycleId, weekNumber, attendees[], minutes, actionItems[], createdAt | 1:N → ActionItem |
| `OneOnOneRecord` | id, managerId, employeeId, scheduledAt, notes, actionItems[], status | 1:N → ActionItem |
| `TimeBlock` | id, userId, type(전략/버퍼/브레이크), startAt, durationMin, memo | - |
| `WeeklySelfReview` | id, userId, weekNumber, scoreProgress, scoreTime, scoreEnergy, oneLineMemo | - |
| `CycleReview` | id, cycleId, summary, retrospectiveAnswers, employeeContributions, learnings | 1:1 → Cycle |
| `ActionItem` | id, sourceType(WAM/1:1), sourceId, ownerId, title, dueDate, status | - |

### 5.2 핵심 관계

- 한 `Cycle`에 여러 `Goal12W`가 속함
- 각 `Goal12W`는 한 명의 `User`가 책임
- 각 `Goal12W`는 여러 `WeeklyPlan`과 `Indicator`로 추적됨
- `Indicator`는 다른 카테고리(영업·마케팅·측정)에서 자동 수집됨
- `OneOnOneRecord.notes`는 데이터베이스 레벨에서 미팅 참여자 외에는 접근 불가하도록 권한 분리

## 6. 권한 위계

| 페이지 | 전 직원 | 임원·대표 | 비고 |
|---|---|---|---|
| ① 대시보드 | 회사 전체 진행률 조회 | + 직원별 기여도 분석 | |
| ② 비전·목표 | 조회 | 작성·수정·이력 조회 | 작성은 대표만 권한 |
| ③ 지표 트래커 | 요약 조회 | + 드릴다운 + 직원별 분석 | |
| ④ WAM | 본인 참여 미팅 | + 모든 미팅, 패턴 분석 | |
| ⑤ 1:1 | 본인 참여 미팅만 | + 1:1 패턴 (노트 제외) | 신뢰 보호 핵심 |
| ⑥ 개인 KPI | 본인만 (메모는 동의 시 공개) | 모든 직원 조회 | |
| ⑦ 사후 검토 | 조회 + 본인 코멘트 | 작성·수정 | |

### 6.1 권한 원칙

1. **1:1 미팅 노트 본문은 대표라도 직접 조회하지 않는다** ― 빌 캠벨 코칭 원칙의 신뢰 기반.
2. **개인의 자기평가 한 줄 메모는 본인 동의가 있을 때만 임원·대표가 조회** ― 심리적 안전감.
3. 그 외 모든 운영 데이터는 투명하게 공유한다.

## 7. 다른 카테고리와의 연계

본 카테고리는 모든 KPI의 발원지다. 12주 목표가 정해지면 해당 KPI는 자동으로 다른 카테고리에 흘러가 추적된다.

| 디안의 12주 목표 예시 | 자동 추적 카테고리 |
|---|---|
| 신규 거래처 50개 확보 | #2a 영업 전략 (활동 다이어리·니즈카드) |
| 인스타 팔로워 1만 도달 | #2b 마케팅·브랜딩 (채널 KPI) |
| 콘텐츠 발행 60건 | #2b 마케팅·브랜딩 (콘텐츠 자원) |
| 마진율 35% 달성 | #3 측정·분해 (인수분해 뷰) |
| 시간당 부가가치 50만원 | #2a 영업 전략 (타임차지) |
| 가격 인상 5% | #4 의사결정 (가격·이익 시뮬레이션) |

### 7.1 데이터 흐름 방향

- **목표·계획 → 다른 카테고리**: KPI 정의 송출 (예: "신규 거래처 50개" 목표를 영업 카테고리에 등록)
- **다른 카테고리 → 목표·계획**: 실시간 측정값 수신 (③ 지표 트래커가 자동으로 받음)

## 8. 시각·UX 가이드라인

### 8.1 핵심 시각 요소

- **80% 기준선**: 모든 진행률 게이지에 점선으로 명시.
  - 80% 이상 = 디안 브랜드 메인 컬러 (성공)
  - 60~80% = 주의 색상
  - 60% 미만 = 경고 색상
- **Week N / 12 카운터**: 모든 페이지 상단 우측에 prominent. 사이클 종료까지 D-day 표시.
- **회의실 모드**: WAM·사후검토 미팅 시 큰 화면 최적화 옵션 (글자 크기·여백 확대).

### 8.2 반응형 요구사항

- 데스크톱: 메인 사용 환경
- 태블릿·큰 화면(회의실): 회의실 모드
- 모바일: 핵심 기능 사용 가능 (특히 WAM 참여, 개인 KPI 입력, 1:1 메모)

## 9. v1.0 마이그레이션 계획

### 9.1 v1.0과의 관계

v1.0에는 **목표·계획 영역이 존재하지 않으므로**, 본 카테고리는 신규 추가다. 단, 다음 v1.0 자산은 본 카테고리의 데이터 소스로 활용된다.

| v1.0 메뉴 | 본 카테고리에서의 활용 |
|---|---|
| 거래 관리 | 후행지표 "매출"의 데이터 소스 |
| 거래처 관리 | 후행지표 "신규 거래처"의 데이터 소스 |
| 분석/시뮬레이션 | 후행지표 추세 분석 |

### 9.2 데이터 보존 원칙

- v1.0의 기존 데이터는 **삭제하지 않는다**.
- 본 카테고리 추가는 v1.0 데이터 위에 새로운 레이어를 얹는 방식.
- 사용자는 v1.0 메뉴에 그대로 접근 가능 (전환 기간 동안).
