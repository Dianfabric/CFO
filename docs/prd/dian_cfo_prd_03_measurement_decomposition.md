# 디안 CFO 대시보드 PRD
## 카테고리 3: 측정·분해 (Measurement & Decomposition)

**문서 버전**: v0.1 (1차 초안)  
**기준 일자**: 2026년 5월 4일  
**카테고리 위치**: 디안 대시보드 7대 영역 중 #3 ― 측정·분해  
**참고 도서**: 김성호·송승훈 『진짜 매출을 부르는 회계감각』

---

## 1. 개요

### 1.1 목적
본 카테고리는 **회계의 언어로 디안을 읽고, 인수분해를 통해 의사결정 가능한 수준까지 숫자를 쪼개는 것**을 목적으로 한다. 단순히 재무제표를 보여주는 것이 아니라, **이익을 만들려면 무엇을 해야 하는가**라는 질문에 답할 수 있는 분석 레이어를 제공한다.

### 1.2 배경
디안은 외부 세무사·회계법인을 활용하여 재무제표를 작성하고 있으며, v1.0의 다섯 메뉴(일일결산·거래·거래처·미수금·비용·분석/시뮬레이션)를 모두 사용하고 있다. 본 카테고리의 PRD는 v1.0을 **데이터 그릇**으로 보존하고, 그 위에 **인수분해·공헌이익·손익분기점·수익성 분석·BSC·결과 검증**의 분석 레이어를 얹는 방향으로 설계된다.

### 1.3 카테고리의 위치
본 카테고리는 디안 대시보드 7대 영역 중 **#3 영역**이며, 다른 모든 카테고리에서 발생한 활동의 **재무적 결과를 측정하고 분해**하는 곳이다. 여기서 산출된 핵심 재무 지표 5개는 다시 #1 목표·계획의 후행지표로, #7 CEO 코크핏의 핵심 KPI로 송출된다.

### 1.4 핵심 철학 (책에서 추출)
다음 메시지들은 본 카테고리의 모든 페이지·기능 설계의 변하지 않는 기준이다.

- **"비용을 자원으로 바꿔 부르는 것은 매우 의식적인 선택이다."** ― 본 카테고리에서 "비용"이라는 단어 대신 가능한 한 "자원"이라는 표현을 사용한다. 마케팅비는 "비용"이 아니라 "미래 고객을 창출하기 위한 자원"으로 표시한다.
- **"관리회계의 완성은 분해된 숫자들을 이익으로 연결하는 것이다."** ― 모든 인수분해 뷰는 마지막에 "그래서 이익에 어떤 영향을 미쳤는가?"로 귀결되어야 한다.
- **"우리는 프리미엄 브랜드라고 말하는데 정작 매출총이익은 25%밖에 안 된다면? 그것은 자기기만이다."** ― 디안의 자기 인식과 실제 숫자의 정합성을 자동 점검한다.
- **"투명성은 단순히 숫자를 공개하는 것이 아니라, 그 숫자가 의미하는 바를 직원들이 이해하고 행동으로 옮기게 만드는 과정이다."** ― 권한 위계는 책의 "소통" 원칙을 반영해 직원에게 가능한 한 많이 공개한다.

## 2. 핵심 원칙

1. **인수분해 우선**: 모든 숫자는 **사업부·채널·제품·시즌·거래처·시간** 6개 차원으로 슬라이싱 가능해야 한다.
2. **공헌이익 = 매출 − 변동비**: 이 공식이 디안의 가장 중요한 단일 숫자다. 모든 페이지에서 즉시 확인 가능해야 한다.
3. **자원 관점 용어**: "비용 관리"라는 표현 대신 "자원 인수분해"로 통일. 마케팅·R&D·영업 활동은 "투자된 자원"으로 분류.
4. **자동 수집, 최소 입력**: v1.0의 거래·거래처·제품·비용 데이터를 자동으로 끌어와 분석한다. 직접 입력은 최소화한다.
5. **외부 세무사 결과의 임포트 가능**: 월말 재무제표는 세무사로부터 받아 임포트하거나, v1.0 데이터로 자동 추정 후 세무사 결과로 보정한다.

## 3. 사용자 시나리오

### 3.1 페르소나

**페르소나 A: 대표 (CEO)**
- 매일 아침 ① 재무 메인 대시보드로 진입해 일별 P&L 확인
- 주 단위로 매출·자원 인수분해 뷰에서 트렌드 파악
- 월말에 결과의 질 검증 + 예산 차이 분석
- 분기별 고객 수익성 분석 + BSC 검토

**페르소나 B: 임원**
- 부서 단위 매출·자원 분해 집중 모니터링
- 본인 부서의 BSC 관점 KPI 추적

**페르소나 C: 영업·마케팅 팀원**
- 본인이 만든 매출의 분해 뷰 조회 (자기 부서 제품/거래처)
- 본인 활동이 만든 자원 투자 효과 확인

### 3.2 핵심 사용자 여정

**여정 1: 매일 아침 P&L 확인 (대표)**
1. ① 재무 메인 대시보드 진입
2. 어제 매출 / 누적 월 매출 / 공헌이익 / 영업이익 한눈에 확인
3. 핵심 5개 재무 지표의 12주 시작 대비 변화량 확인
4. 위기 신호(공헌이익률 급락, 미수금 증가, 손익분기점 도달 위험 등) 알림 확인

**여정 2: 매출이 줄어든 주 (대표)**
1. ① 메인에서 매출 감소 알림 확인
2. ② 매출 인수분해로 이동 ― 어느 사업부/채널/제품/거래처에서 줄었는지 드릴다운
3. ④ 공헌이익·손익분기점에서 이대로 가면 손익분기점에 도달하는지 시뮬레이션
4. 의사결정 ― #4 의사결정 카테고리(가격·이익 시뮬레이션)로 이동

**여정 3: 분기 고객 수익성 검토**
1. ⑤ 고객 수익성 분석 진입
2. 거래처별 매출 × 마진 매트릭스에서 VIP·일반·소규모 자동 분류 확인
3. "활동기준 원가" 적용 ― 해당 거래처에 들인 영업 시간·샘플 발송·미팅 횟수를 원가로 환산
4. 자원 재배분 의사결정 ― VIP에 자원 집중, 비효율 고객 정책 검토

**여정 4: 사이클 종료 시 결과 검증**
1. ⑦ 결과의 질 검증 페이지 진입
2. 4가지 질문 자동 답변 확인:
   - 이번 분기 이익이 현금을 동반했는가?
   - 이 이익은 다음 분기에도 반복 가능한가?
   - 이 이익이 고객 기반을 강화했는가?
   - 미래 자원을 잠식하지 않았는가?
3. ⑧ 예산 vs 실적 차이 분석
4. 학습 노트 작성 → #1 목표·계획의 사후 검토에 자동 연결

## 4. 페이지 구조 (9개 페이지)

페이지는 세 그룹으로 자연스럽게 나뉜다.

- **A. 현황 파악** (회계는 언어·관찰이다): ①, ②, ③
- **B. 분석·전략** (회계는 관리·전략이다): ④, ⑤, ⑥
- **C. 관리·검증** (회계는 결과·예방이다): ⑦, ⑧, ⑨

---

### 4.1 ① 재무 메인 대시보드 (메인 진입)

**목적**: CEO가 매일 아침 회사의 재무 건강 상태를 한눈에 파악한다.

**주요 컴포넌트**:
- (상단) 핵심 5개 재무 지표 카드:
  - 매출 (일/월/12주)
  - 매출총이익률
  - **공헌이익률** (디안의 가장 중요한 단일 지표)
  - 영업이익률
  - 자기자본이익률 (ROE)
  - *각 카드는 12주 시작 대비 변화량 + 업계 벤치마크 비교 표시*
- (중단) 워터폴 차트 (당월):
  - 매출 → 변동비 차감 → **공헌이익** → 고정비 차감 → 영업이익 → 영업외 → 순이익
  - 책의 핵심 메시지인 "분해된 숫자를 이익으로 연결"의 시각화
- (중단) 일별 매출 추세 차트 (이번 달):
  - 일별 매출 막대 + 일별 누적 라인
  - 손익분기점 라인 표시
- (하단) 위기 신호 알림 영역:
  - 공헌이익률 급락 경고
  - 미수금 증가 경고
  - 변동비율 상승 경고
  - 특정 거래처 매출 급감 경고

**핵심 인터랙션**:
- 5개 지표 카드 클릭 → 해당 지표의 인수분해 페이지로 이동
- 워터폴 차트의 각 단계 클릭 → 자원 인수분해(③)로 드릴다운
- 위기 신호 클릭 → 관련 분석 페이지로 이동

**시각 요소**:
- 워터폴 차트 (P&L 흐름)
- 카드형 KPI (5개)
- 막대+라인 콤보 차트 (일별 매출)

**권한**:
- 전 직원: 매출·핵심 지표 요약 (단, 영업이익·순이익 절대 금액은 임원·대표만)
- 임원·대표: 전체 조회 + 위기 신호 알림 수신

---

### 4.2 ② 매출 인수분해

**목적**: 디안의 매출을 의미 있는 차원으로 쪼개어, "어디서 돈이 나오고 어디서 빠지는지" 즉각 보여준다.

**6가지 분해 차원**:
- **사업부별**: 가구용 / 벽면용 / 소품용 / 윈도우 트리트먼트
- **채널별**: 직영 / 대리점 / 온라인 / 디자이너 직거래
- **제품별** (개별 SKU)
- **거래처별** (디자이너·스튜디오·가구사)
- **시즌별**: SS / FW (인테리어 트렌드 사이클)
- **시간별**: 일/주/월/분기/12주

**주요 컴포넌트**:
- (상단) 분해 차원 선택 탭 ― 한 번에 한 차원 또는 두 차원 교차 분석
- (좌측) 트리맵 / 선버스트:
  - 매출 비중을 면적으로 시각화
  - 색상으로 마진율 표시 (진할수록 고마진)
- (우측) 시즌별·월별 매출 변동 패턴:
  - 히트맵 (가로축: 월, 세로축: 사업부 또는 제품)
  - 디안의 SS/FW 사이클 자동 인식
- (하단) 매출 변화 분석:
  - 전년 대비 / 전월 대비 / 전주 대비
  - 어느 차원에서 어떻게 변했는지 자동 해설 (예: "벽면용 사업부의 △△스튜디오 거래 증가가 이번 달 매출의 주요 동력")

**핵심 인터랙션**:
- 차원 교차 (예: 사업부 × 시즌, 채널 × 거래처) ― 두 차원을 동시에 보고 패턴 발견
- 드릴다운: 사업부 → 제품 → 거래처
- 시간 필터 + 비교 모드 (전년/전월/전주)
- 거래처별 클릭 시 ⑤ 고객 수익성 분석으로 이동

**시각 요소**:
- 트리맵 (매출 비중 + 마진율 색상)
- 선버스트 (계층적 분해)
- 히트맵 (시즌·월별 패턴)
- Sankey 차트 옵션 (거래처 → 사업부 → 제품 흐름)

**데이터 흐름**:
- 자동 수집: v1.0의 거래 관리·거래처 관리·제품 관리에서 자동 동기화
- 수동 보강: 거래처를 디자이너/스튜디오/가구사로 분류하는 마스터 데이터 (1회성 설정)

**권한**:
- 전 직원: 회사 전체 매출 분해 (절대 금액은 권한별 차이)
- 영업·마케팅 팀원: 본인 부서 거래처 디테일
- 임원·대표: 전체 + 거래처별 마진 디테일

---

### 4.3 ③ 자원 인수분해 (비용을 자원으로)

**목적**: 디안이 투입한 자원을 분해하여, 어떤 자원이 어떤 매출/이익으로 연결되는지 보여준다.

**4가지 분해 차원**:
- **자원 성격별**: 인건비 / 광고·마케팅 자원 / 원단 매입 원가 / 임차료 / 운영비
- **변동성별**: 변동비 (원단 매입, 수수료, 배송비) vs 고정비 (임차료, 인건비)
- **재량성별**: 재량적 자원 (마케팅·교육·R&D ― 줄일 수 있는) vs 비재량적 (필수 운영)
- **팀·조직별**: 영업 / 마케팅 / 디자인 / 운영 / 백오피스

**주요 컴포넌트**:
- (상단) 자원 구성 도넛 차트:
  - 변동비 vs 고정비 비율
  - 각 구간 호버 시 상세 분류
- (중단) 변동비 상세:
  - 원단 매입 원가율 (매출 대비)
  - 수수료 / 배송비 / 샘플 발송비
  - 추세선 (월별)
- (중단) 고정비 상세:
  - 임차료 / 인건비 (정규직·계약직 분리) / 시설 유지
  - 12주 누적 + 다음 12주 예상
- (중단) **재량적 자원 (투자) 영역**:
  - 마케팅 자원 (인스타·블로그·유튜브·광고)
  - 영업 활동 자원 (샘플·미팅·접대)
  - 교육·R&D 자원
  - 각 자원에 대해 **"이 자원 투입이 유의미한 이익 증분으로 연결되었는가?"** 자동 분석
- (하단) 자원 → 이익 연결 매트릭스:
  - 가로축: 자원 카테고리
  - 세로축: 이번 12주 ROI (해당 자원 투입 대비 매출/이익 증가)

**핵심 인터랙션**:
- 변동비/고정비 비율 변경 시뮬레이션 ― ④ 공헌이익·손익분기로 자동 연결
- 재량적 자원 클릭 → 해당 카테고리의 활동 디테일로 이동 (마케팅 → #2b 카테고리, 영업 → #2a)
- "이 자원이 만든 매출은?" 역추적 기능

**시각 요소**:
- 도넛 차트 (변동/고정 비율)
- 영역 차트 (자원별 추세)
- 산점도 (자원 투입 vs 이익 증분)

**데이터 흐름**:
- 자동 수집: v1.0의 비용 관리에서
- 마스터 데이터 설정: 비용 항목별 변동/고정 분류, 재량/비재량 분류 (초기 1회 + 주기적 검토)

**권한**:
- 전 직원: 자원 구성 비율 (백분율만)
- 임원·대표: 전체 절대 금액 + ROI 분석

---

### 4.4 ④ 공헌이익 & 손익분기점

**목적**: 디안의 가장 중요한 공식인 **공헌이익 = 매출 − 변동비**를 자동 계산하고, 매출이 얼마나 줄어도 버틸 수 있는지 시뮬레이션한다.

**주요 컴포넌트**:
- (상단) 공헌이익 카드:
  - 이번 달 공헌이익 절대값
  - 공헌이익률 (% of 매출)
  - 12주 추세
  - **목표 공헌이익률** (대표님이 설정)
- (중단) 손익분기점 자동 계산:
  - 월 고정비 / 공헌이익률 = 손익분기 매출
  - 현재 매출 vs 손익분기 매출 게이지
  - "이번 달 손익분기 도달 D-day" 표시
- (중단) **매출 감소 시뮬레이션**:
  - 매출 −10% / −20% / −30% / −40% 시나리오
  - 각 시나리오에서 공헌이익·영업이익·순이익 변화
  - "어느 지점에서 적자 전환되는가?" 자동 표시
- (중단) **변동비율 시나리오**:
  - 원단 매입가 +5% / +10% / +15% 시나리오
  - 각 시나리오에서 손익분기점 변화
- (하단) 안전 마진 (Safety Margin):
  - (현재 매출 − 손익분기 매출) / 현재 매출 = 안전 마진율
  - 디안이 매출 X% 줄어도 흑자 유지 가능

**핵심 인터랙션**:
- 시나리오 슬라이더 (매출 변동, 변동비율 변동)
- "내가 가격 5% 인상하면?" 시뮬레이션 → #4 의사결정 카테고리로 자동 연결
- 위험 알림: 손익분기점 도달까지 안전 마진 < 20%일 때 경고

**시각 요소**:
- 게이지 (현재 매출 vs 손익분기점)
- 라인 차트 + 손익분기점 마커
- 시나리오 매트릭스 (감소율 × 변동비율 = 손익 영향)

**권한**:
- 임원·대표 전용 (이 페이지는 회사 생존 정보를 다루므로 신중)
- 직원에게는 ① 메인 대시보드의 요약 형태로만 노출

---

### 4.5 ⑤ 고객 수익성 분석

**목적**: "모든 고객이 평등하지 않다." 책의 메시지대로, 디안의 거래처를 수익성 관점에서 분류하고 자원 재배분 결정을 돕는다.

**주요 컴포넌트**:
- (상단) 거래처 산점도:
  - X축: 거래처별 매출
  - Y축: 거래처별 마진율
  - 점 크기: 거래 빈도
  - 색상: 활동기준 원가 (디안이 이 거래처에 들인 영업 시간·샘플·미팅 비용)
- (중단) 자동 분류:
  - **VIP**: 매출 高 + 마진 高 → 자원 집중
  - **일반**: 매출 中 + 마진 中 → 유지
  - **소규모**: 매출 低 + 마진 低 → 효율화 또는 정리
  - **성장 가능**: 매출은 낮으나 마진 높음 → 성장 투자
  - **비효율 고객**: 매출은 높으나 마진 낮음 또는 활동 원가 과다 → 가격 재협상
- (중단) **활동기준 원가 (ABC) 분석**:
  - 책의 핵심 도구: "숨겨진 원가"
  - 거래처별 영업 시간 (#2a 영업 카테고리에서 자동 수집)
  - 샘플 발송 횟수·금액
  - 미팅 횟수
  - 이를 모두 원가로 환산 → 진짜 마진 계산
- (하단) 추천 액션:
  - "이 거래처는 VIP로 승격되었습니다 ― 전담 영업 배정 검토"
  - "이 거래처는 거래액은 크지만 활동 원가 대비 마진이 낮습니다 ― 가격 재협상 필요"
  - 책의 사례: "VIP고객에게는 전담 어카운트 매니저 배정, 맞춤형 재고 관리 서비스, VIP 전용 온라인 플랫폼" 같은 실행 옵션

**핵심 인터랙션**:
- 분류 기준 슬라이더 (VIP 기준 매출/마진 임계값 조정)
- 거래처 클릭 → 해당 거래처의 12주 활동 히스토리 (#2a로 이동)
- 시간별 변화 ― "이 거래처가 6개월 전엔 일반, 지금은 VIP" 같은 추세

**시각 요소**:
- 산점도 (4분면 매트릭스)
- 색상 코딩 (활동 원가)
- 거래처 카드 (각 거래처 클릭 시)

**권한**:
- 임원·대표: 전체 분석
- 영업 팀원: 본인 담당 거래처만 (다른 영업의 거래처 노출 안 함)

### 4.6 ⑥ 균형성과표 (BSC)

**목적**: 책의 균형성과표 4가지 관점을 디안의 KPI 추적에 적용한다. 재무 KPI에만 집착하지 않고 균형 잡힌 시야를 제공.

**4가지 관점**:

**(1) 재무 관점** ― 주주에게 어떤 재무적 성과를 보일 것인가?
- 영업이익률
- 매출 성장률
- ROE (자기자본이익률)
- 공헌이익률

**(2) 고객 관점** ― 고객에게 어떤 만족을 제공할 것인가?
- 디자이너 만족도 (간단한 NPS 설문)
- 시장점유율 (인테리어 원단 시장 중)
- 재구매율 (디자이너별 12주 누적)
- 신규 거래처 획득률

**(3) 내부 프로세스 관점** ― 어떤 프로세스를 탁월하게 만들 것인가?
- 주문 처리 사이클 타임 (주문 → 출하)
- 샘플 발송 응답 속도
- 신제품 라인 출시 속도 (시즌당)
- 불량률 / 반품률

**(4) 학습과 성장 관점** ― 어떻게 변화하고 개선할 것인가?
- 직원 교육 시간 (분기당)
- 혁신 제안 건수 (니즈카드 #2a 카테고리 연계)
- 정보 시스템 활용도 (대시보드 사용률)
- 직원 만족도

**주요 컴포넌트**:
- (상단) 4관점 레이더 차트 ― 한눈에 균형 상태 확인
- (중단) 각 관점별 KPI 카드:
  - 현재 값
  - 12주 시작 대비 변화
  - 80% 기준선 (목표)
  - 트렌드 차트
- (하단) 관점 간 인과 관계 시각화:
  - 학습·성장 → 내부 프로세스 → 고객 만족 → 재무 성과
  - 디안에서 실제 나타난 인과 관계 (예: "직원 교육 시간 증가 → 샘플 발송 속도 개선 → 디자이너 만족도 상승 → 재구매율 증가")

**핵심 인터랙션**:
- 각 KPI는 #1 목표·계획의 12주 목표와 연동
- 관점 간 인과 분석 ― 머신러닝 기반 상관관계 탐지
- 분기별 BSC 검토 회의 모드 (회의실 모드)

**시각 요소**:
- 레이더 차트 (4관점)
- KPI 카드 그리드
- 인과 관계 다이어그램

**권한**:
- 전 직원: 회사 전체 BSC 조회 (재무 관점 절대값은 임원·대표만)
- 임원·대표: 전체 + 분기별 BSC 검토 작성

---

### 4.7 ⑦ 결과의 질 검증

**목적**: 매출이나 이익의 절대 수치가 아니라 **그 이익의 질**을 검증한다. 책의 4가지 질문을 자동 답변한다.

**4가지 질문 자동 답변**:

**(1) 이익은 현금을 동반했는가?**
- 이번 분기 영업이익 vs 영업현금흐름 비교
- 미수금 증가가 이익 증가를 가린 경우 경고
- 자동 분석: "영업이익은 +20%이지만 영업현금흐름은 +5% ― 미수금 증가가 주요 원인"

**(2) 이 이익은 내년에도 반복 가능한가?**
- 일회성 매출/이익 자동 분류 (특별 프로젝트, 자산 매각 등)
- 사업 본질에서 나온 이익 vs 일회성 이익 분리
- 반복 가능성 점수 (Recurring Revenue Quality)

**(3) 이 이익은 고객 기반을 강화했는가?**
- 신규 거래처 수 증가 / 기존 거래처 재구매율 / 거래처 이탈률
- 매출은 늘었지만 거래처 수가 줄었다면 → 위험 신호
- 거래 집중도 (상위 10% 거래처가 전체 매출의 몇 %인지)

**(4) 미래의 자원을 잠식하지 않았는가?**
- R&D 자원 추세 ― 신제품 개발 투자 줄지 않았는지
- 마케팅 자원 추세
- 인력 (특히 핵심 인재 이탈률)
- 단기 이익을 위해 미래를 희생했는지 자동 점검

**주요 컴포넌트**:
- (상단) 이익 품질 종합 점수 (4가지 질문의 가중 평균)
- (중단) 4개 질문 카드 (각각 자동 답변 + 근거 데이터)
- (하단) 분기별 이익 품질 추세

**핵심 인터랙션**:
- 각 질문 클릭 → 상세 분석 페이지
- 이익 품질 저하 시 자동 알림
- 분기 마감 시 결과의 질 검증 리포트 자동 생성 → #1 사후 검토에 자동 첨부

**시각 요소**:
- 게이지 (이익 품질 종합 점수)
- 4개 질문 카드 + 상태 표시 (✓ / ⚠ / ✗)
- 시계열 차트 (이익 품질 추세)

**권한**:
- 임원·대표 전용

---

### 4.8 ⑧ 예산 vs 실적

**목적**: 책의 "회계는 예산이라는 그릇에 담긴다"는 메시지대로, 12주 단위 재무 예산을 수립하고 실적과 차이를 분석한다.

**주요 컴포넌트**:
- (상단) 12주 예산 수립 영역:
  - 매출 예산 (사업부·채널별)
  - 변동비 예산
  - 고정비 예산
  - 자원(투자) 예산: 마케팅·영업 활동·R&D
  - **예산 가정**: 매출, 원가, 시장 변동률 등의 가정 명시 (책의 "가정의 명확성" 원칙)
- (중단) 예산 vs 실적 비교 (월/주 단위):
  - 차이 자동 계산 (절대값 + %)
  - 차이 사유 분석:
    - 가격 차이 (Price Variance)
    - 수량 차이 (Volume Variance)
    - 원가 차이 (Cost Variance)
- (중단) **차이 분석 학습 노트**:
  - 책의 "차이와 분석의 학습구조" 원칙
  - 예산을 벗어난 사유에 대해 팀이 작성한 학습 노트 누적
  - 다음 사이클 예산 수립 시 자동 참고
- (하단) **롤링 예측**:
  - 책의 "유연성: 롤링 예측 구조 병행" 원칙
  - 매월 다음 12주 예측 업데이트
  - 시즌·트렌드 변화 반영

**핵심 인터랙션**:
- 예산 수립 시 #1 목표·계획의 12주 목표와 자동 연동
- 차이 분석 학습 노트는 사후 검토(#1)에 자동 첨부
- 롤링 예측은 시뮬레이션 기능 (#4 의사결정 카테고리와 연동)

**시각 요소**:
- 막대 차트 (예산 vs 실적)
- 폭포 차트 (차이 분해: 가격·수량·원가)
- 라인 차트 (롤링 예측)

**권한**:
- 임원·대표: 작성·수정
- 전 직원: 본인 부서 예산 vs 실적 조회 (책의 "투명성" 원칙)
- 차이 분석 학습 노트는 전 직원 작성 가능 (집단 지성)

---

### 4.9 ⑨ 미수금 관리 *(추후 상세 설계)*

**목적**: 책의 "이익은 현금을 동반해야 한다" 원칙을 위해 미수금을 추적·관리한다.

**1차 PRD 범위**:
- v1.0의 미수금 관리 메뉴를 그대로 보존
- 본 카테고리에서는 ① 메인 대시보드의 위기 신호 영역에 미수금 증가 알림만 통합

**추후 상세 설계 (사용자 요청)**:
- 거래처별 미수금 에이징 분석 (30일/60일/90일/120일+)
- 미수금 회수 우선순위 자동 추천
- 자동 알림·독촉 워크플로우
- 미수금 → 영업현금흐름 연결 분석
- *별도 PRD 보강 필요 ― 본 문서에는 자리만 표시*

**현재 사용 가능한 v1.0 기능**:
- 거래처별 미수금 조회
- 미수금 입금 기록
- 미수금 잔액 추적

### 5.2 핵심 관계

- `Transaction` → `Client`, `Product`, `Division`, `Channel` (다차원 분해의 기반)
- `Resource` → 변동/고정 + 재량/비재량 분류 (인수분해의 기반)
- `MonthlyPL`은 `Transaction` + `Resource`에서 자동 집계
- `ABCActivity`는 #2a 영업 카테고리의 활동 다이어리에서 자동 수집
- `BSCRecord`의 KPI는 다른 카테고리에서 자동 수집

### 5.3 외부 데이터 연동

- **외부 세무사 재무제표**: 월말 손익계산서·재무상태표·현금흐름표를 임포트 (수동 업로드 또는 이메일 연동)
- 임포트된 재무제표가 v1.0 자동 추정값과 다를 경우 → 차이 분석 + 마스터 데이터 보정

## 6. 권한 위계

| 페이지 | 전 직원 | 임원·대표 | 비고 |
|---|---|---|---|
| ① 재무 메인 대시보드 | 매출·핵심 지표 요약 | + 절대 금액 + 위기 신호 | 영업이익·순이익 절대값 제한 |
| ② 매출 인수분해 | 본인 부서 디테일, 회사 전체 비율 | 전체 + 거래처별 마진 디테일 | |
| ③ 자원 인수분해 | 자원 구성 비율 (% 만) | 전체 절대 금액 + ROI | |
| ④ 공헌이익·손익분기 | (제한) ① 메인 대시보드 요약만 | 전체 시뮬레이션 | 회사 생존 정보 |
| ⑤ 고객 수익성 분석 | 본인 담당 거래처만 | 전체 거래처 분석 | 영업 데이터 보호 |
| ⑥ BSC | 회사 전체 (재무 절대값 제외) | 전체 | 책의 "투명성" 원칙 |
| ⑦ 결과의 질 검증 | 조회 불가 | 작성·조회 | |
| ⑧ 예산 vs 실적 | 본인 부서 차이 분석 + 학습 노트 작성 | 작성·수정 | 책의 "투명성·집단 지성" |
| ⑨ 미수금 관리 | (역할별 차이) | 전체 | 추후 상세 |

### 6.1 권한 원칙

1. **"투명성은 행동을 만든다"** ― 책의 메시지대로, 가능한 한 직원에게 많이 공개한다.
2. **회사 생존 정보는 신중**: 손익분기점·결과의 질 검증은 임원·대표 전용. 잘못 해석되면 동요를 일으킬 수 있음.
3. **영업 데이터는 보호**: 다른 영업의 거래처 디테일은 노출하지 않음.

| **거래처 관리** | ⑤ 고객 수익성 분석의 데이터 소스 | 거래처별 type·tier 필드 추가 |
| **미수금 관리** | ⑨ 미수금 관리 페이지 | 1차에서는 그대로 보존, 추후 상세 설계 |

| **분석/시뮬레이션** | ④ 공헌이익·손익분기점으로 진화 | 시뮬레이션 기능 강화 |

### 9.2 데이터 보존 원칙

- v1.0의 모든 기존 데이터는 **삭제하지 않는다**.
- 본 카테고리는 v1.0 데이터 위에 **분류 메타데이터**(거래처 tier, 비용 변동/고정 분류)를 추가하는 방식으로 작동.
- 사용자는 v1.0 메뉴에 그대로 접근 가능 (전환 기간 동안).

### 9.3 마스터 데이터 초기 설정 (1회성)

본 카테고리가 작동하려면 다음 마스터 데이터의 1회성 분류 작업이 필요하다.

1. **거래처 분류**: 디자이너 / 스튜디오 / 가구사 / 기타 (각 거래처에 매핑)
2. **제품 사업부 분류**: 가구용 / 벽면용 / 소품용 / 윈도우 (각 제품에 매핑)
3. **채널 분류**: 직영 / 대리점 / 온라인 / 디자이너 직거래
4. **비용 변동성 분류**: 변동 / 고정
5. **비용 재량성 분류**: 재량 / 비재량

이 분류는 1회 설정 후 신규 데이터에 자동 적용되며, 분기마다 검토·업데이트한다.

## 11. 미해결 사항 / 추후 결정 필요

### 11.1 대표님 결정 대기

- 디안 거래처를 **디자이너 / 스튜디오 / 가구사 / 기타**로 분류하는 기준 (마스터 데이터 초기 설정)
- 디안 제품을 **가구용 / 벽면용 / 소품용 / 윈도우** 외에 추가 사업부 분류 필요 여부
- VIP 거래처 분류 기준 (매출 기준? 마진 기준? 둘 다?)
- 외부 세무사로부터 재무제표를 받는 주기·형식 (월말? 분기말?)

### 11.2 시범 운영 후 재검토

- 활동기준 원가 (ABC) 계산의 정확도 ― 영업 활동 데이터의 질에 의존
- 결과의 질 4가지 질문 자동 답변의 신뢰도 ― 일회성 매출 자동 분류 정확도
- BSC 4관점의 KPI 선정 ― 운영하면서 디안에 맞는 KPI로 진화

### 11.3 다른 카테고리에서 결정될 사항

- ABC 원가의 인풋이 되는 영업 활동 데이터 정의 → #2a 영업 전략 PRD
- 마케팅 자원의 ROI 계산 방식 → #2b 마케팅·브랜딩 PRD
- 가격 인상 시뮬레이션의 디테일 → #4 의사결정 PRD

### 11.4 ⑨ 미수금 관리 별도 PRD 필요

- 사용자 요청에 따라 미수금 관리는 본 PRD에서는 자리만 잡고, **별도 보강 PRD를 추후 작성**
