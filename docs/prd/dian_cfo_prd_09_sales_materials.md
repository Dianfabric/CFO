**버전**: v0.1

**카테고리**: #2a 영업 전략 하위 (영업 보조 도구)
**관련 PRD**: #2a (영업), #2b (마케팅·브랜딩 — 빅 아이디어/페르소나/시각 정체성), #2c (운영 — 샘플), #4 (포지셔닝·티어)

---

## 0. 한 줄 정리

> **신제품·기획제품을 거래처에 보낼 때, 우리 자료(국내·해외 레퍼런스 포함)를
> 디안 톤 + 심리·인지과학 프레임워크로 재가공해 PPT + 영상 스크립트를 5분 안에 자동 생성한다.**

---

## 1. 왜 만드는가 (CFO·영업 관점의 레버리지)

### 1.1 디안의 영업 약점

- **원단은 만져봐야 안다** → 샘플 발송 전 단계에서 결정이 늦다
- 직원 1명 + 대표가 모든 영업자료를 수작업 → **자료 만들기에 시간이 다 빠짐**
- 해외 레퍼런스(이태리·프랑스 직조사 카탈로그)는 좋지만 그대로 쓸 수 없음 → **재가공의 부담**
- 4티어가 분리되어 있는데 자료가 한 가지 톤으로만 나감 → **럭셔리 라인이 저가처럼 보이는 사고**

### 1.2 자동화로 얻는 효과

| 지표 | 현재 | 목표 |
|---|---|---|
| 자료 1건 제작 시간 | 2~4시간 (PPT 수작업) | **5~10분 (위저드 + 검수)** |
| 월 발송 자료 수 | 5~10건 | **30~50건** |
| 톤·정체성 일관성 | 직원 재량 | **자동 디안 톤** |
| 4티어 메시지 분리 | 안 됨 | **자동 (티어별 톤) ** |
| 심리·인지과학 적용 | 없음 | **프레임워크 자동 선택** |

### 1.3 핵심 가설

> "원단의 시각·정서적 매력을 자료 단계에서 끌어올리면 **샘플 청구 → 첫 거래 전환율**이 올라간다."

→ 이 가설은 #3 측정·분해 카테고리의 영업 깔때기에서 검증한다.

## 2. 디안 비즈니스 매핑

### 2.1 24셀 직업군별 어필 포인트

| 직업군 | 어필 포인트 (자료 생성 시 자동 반영) |
|---|---|
| 인테리어 프로젝트 | 공간 완성도 · 클라이언트 만족 · 시공 사례 |
| 브랜드 가구 | 디자인 일관성 · 양산 안정성 · 브랜드 톤 |
| 프로젝트 가구 | 납기 · 단가 · 품질 인증 |
| 업소용 천갈이 | 내구성 · 청소 · 화재 인증 |
| 커튼 스타일링 | 광원·드레이프·계절감 |
| 디스플레이 | 임팩트 · 단기 효과 · 회수 가능성 |

→ 거래처 24셀이 자동 매핑되어 있으니 **자료 생성 시 직업군에 맞는 포인트를 AI가 자동 강조**

### 2.2 4티어별 메시지 톤

| 티어 | 자료 톤 | 가격 표현 |
|---|---|---|
| value | 기능 · 혜택 · 절약 · 9.99 같은 문턱가격 | **표시·강조** |
| mid | 가성비 · 합리적 선택 · 비교 우위 | 표시·할인 가능 |
| premium | 가치 · 경험 · 디자이너 사례 · 디테일 | 표시·할인 회피 |
| luxury | 스토리 · 장인성 · 한정성 · 여백 · 비주얼 | **숨김 ("Price upon request")** |

→ 같은 신제품도 4티어 중 어느 라인이냐에 따라 **자료 톤이 자동 분리**

### 2.3 시즌 + 컬렉션 매핑

- SS·FW 시즌과 디안 컬렉션(연 4~6회) → 자료 상단에 자동 표기
- 시즌 트렌드 컬러·소재 키워드는 #2b 마케팅에서 끌어옴

## 3. 페이지 구조 (5개 + 사이드바 1)

```
/finance/sales/materials              ← 허브 (생성 이력 + 새로 만들기 + 검색)

/finance/sales/materials/[id]         ← 결과 보기 (PPT 다운로드, 영상 스크립트, 재생성)

```

## 4. 위저드 (5단계 — 직원이 5분 안에)

### Step 1: 대상 선택
- 거래처 검색 (옵션) → 자동 24셀 + 4티어 매핑 표시
- 또는 미지정 (일반 발송용)
- **출력**: target_segment, target_tier, target_persona

### Step 2: 제품 선택
- 기존 제품 라인에서 선택 (신제품 / 기획 / 정규)
- 또는 신규 입력 (이름, 소재, 컬러군, 추정 단가, 카테고리)
- **출력**: product 정보

### Step 3: 프레임워크 선택
- AI가 24셀 + 티어 기반으로 **추천 프레임워크 1~2개 자동 제시**
- 직원이 수정·추가 가능 (다중 선택)
- **출력**: framework_ids[]

### Step 4: 소스 자료 입력
- 이미지 업로드 (드래그 앤 드롭, 다중 가능)
- URL 붙여넣기 (해외 직조사 사이트 등)
- 텍스트 붙여넣기 (해외 기사 본문, 인터뷰 등)
- 기존 라이브러리에서 선택
- **출력**: asset_ids[], external_urls[], external_text

### Step 5: 생성 옵션 + 실행
- 슬라이드 수 (5 / 7 / 10)
- 영상 길이 (15s / 30s / 60s — 다중 선택 가능)
- 톤 미세 조정 (감성 ↔ 정보, 고급 ↔ 친근)
- ▶ **생성 시작** (Claude API 호출 → 5~30초 대기)
- **출력**: 생성된 material 객체

## 5. 결과 페이지 (`/[id]`)

### 5.1 표시 영역
- 메타 정보: 대상·제품·프레임워크·생성 시각
- **PPT 미리보기** (슬라이드별 텍스트 + 이미지 자리표시자)
- **PPT 다운로드 버튼** → `.pptx` 파일 즉시 다운로드
- **영상 스크립트 3종** (15s / 30s / 60s) — 컷별 (시간·텍스트·이미지 추천·자막·BGM 무드)
- **재생성 버튼** (프레임워크 변경, 톤 조정 후 재실행)
- **버전 히스토리** (이전 생성 결과 보기)
- **공유 링크** (옵션, 직원이 거래처에 보내기 전 대표 검토)

### 5.2 PPT 슬라이드 구조 (10슬라이드 예시 — premium 티어)

| # | 슬라이드 | 내용 (AI 자동) |
|---|---|---|
| 1 | 표지 | 빅 비주얼 + 제품명 + 디안 로고 (peak-end 첫 절정) |
| 2 | 후크 | 디자이너의 문제 정의 (스토리브랜드: 영웅의 문제) |
| 3 | 빅 아이디어 | 한 문장 가치 제안 (러셀 Hook) |
| 4 | 소재 디테일 | 마크로샷 + 촉감 묘사 (감각통합) |
| 5 | 컬러 팔레트 | 시즌 컬러 + 어울리는 인테리어 톤 |
| 6 | 시공 사례 | 다른 디자이너 사용 모습 (거울뉴런·사회적 증거) |
| 7 | 비교 | Before/After 또는 경쟁 소재 비교 (인지적 용이성) |
| 8 | 가치 제안 | 상세 사양 + 디안의 보장 (권위) |
| 9 | 한정성 | 입고 일정 · 재고 (희소성) |
| 10 | CTA | 샘플 신청 · 미팅 예약 · 연락처 (peak-end 마지막 절정) |

→ 슬라이드 수·구성은 티어·프레임워크에 따라 가변

### 5.3 영상 스크립트 예시 (15초 — luxury 라인)

```
[0-3초] 마크로샷, 원단 결이 흐르는 슬로우. 자막: "장인의 손이 짠 침묵"
[3-7초] 어두운 인테리어, 한 줄기 빛이 원단에 닿는다. 자막: "공간이 입을 옷"
[7-12초] 디자이너의 손이 원단을 펼친다. 자막: "디안 [컬렉션명]"
[12-15초] 로고 + "Price upon request"
BGM 무드: 미니멀 피아노, 절제된 텐션
컷 추천: 마크로 → 미디엄 → 풀
```

## 8. AI 생성 로직 (`src/lib/v11-sales-materials/generator.ts`)

### 8.1 모델
- Anthropic Claude Sonnet 4.5 (이미 통합됨)
- max_tokens 4096, temperature 0.7

### 8.2 시스템 프롬프트 (요약)

```
당신은 디안의 시니어 영업·브랜드 디렉터입니다.
디안은 B2B 프리미엄 인테리어 원단 큐레이터로 4티어(저가~럭셔리)를 운영합니다.

# 원칙
- 디안 톤: 세련된 전문가, 격조 있고 신뢰감 있게.
- 절대 과장·할인 압박 금지 (특히 premium·luxury).
- 한국어 영업자료. 디자이너·스튜디오·가구사가 받는다고 가정.

# 출력 형식
JSON only. 다음 스키마:
{
  "title": "...",
  "slides": [{ "kind": "cover|hook|big_idea|...", "headline": "...", "body": "...", "image_brief": "..." }, ...],
  "video_scripts": [{ "duration_sec": 15, "cuts": [{ "time_range": "0-3", "voiceover": "...", "subtitle": "...", "image_brief": "...", "bgm_mood": "..." }] }, ...]
}
```

### 8.3 사용자 프롬프트 (입력 컨텍스트)

- 대상 거래처 24셀·티어·페르소나
- 제품 정보 (이름·소재·컬러·단가)
- 선택된 프레임워크 (1~2개)의 핵심 원리
- 소스 자료 텍스트 (해외 기사 본문 등)
- 톤 조정 슬라이더 값

### 8.4 후처리

- JSON 파싱 → DB 저장
- 이미지 자리표시자(image_brief)는 stage 1에서는 텍스트 설명만 (실제 이미지 생성은 v0.2)

## 9. PPT 익스포트 (`pptxgenjs`)

### 9.1 라이브러리
- `npm install pptxgenjs` (4.x)
- 서버 액션에서 호출 → Buffer 생성 → Storage 업로드 → 다운로드 URL 반환
- 또는 클라이언트에서 직접 생성·다운로드 (간단한 경우)

### 9.2 슬라이드 디자인 (디안 시각 정체성 자동 적용)

- **주 컬러** (`brand_identity.visual_primary_color`)
- **보조·강조 컬러** (자동 적용)
- **헤딩 폰트 / 본문 폰트** (`visual_font_heading`, `visual_font_body`)
- **로고** (`visual_logo_url` — 좌하단 작게)
- **티어별 레이아웃**:
  - luxury: 검정·여백·세리프·이미지 90%·텍스트 10%
  - premium: 베이지·미디엄 여백·산세리프·이미지 60%
  - mid: 화이트·균형·정보 위주·이미지 40%
  - value: 컬러·강조·가격·이미지 30%
