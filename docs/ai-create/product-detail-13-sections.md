# 상세페이지 13개 섹션 — 기본 구조

> Apple 미니멀 톤 (`docs/design-system/apple-spec.md`) + 한국 이커머스 표준 (네이버·쿠팡) + 디안 4티어 차등.
> 이 문서는 모든 상세페이지 생성의 **고정 골격**. 에이전트들은 이 13개 섹션을 채우기만 한다.

---

## 0. 설계 원칙

1. **Photography-first → Tactile-first** — 원단의 시각·촉감이 주연. UI 는 사라짐.
2. **Alternating tile rhythm** — light → dark → light → parchment 의 Apple 시그니처 리듬.
3. **단일 액션 컬러** — Action Blue (#0066cc) 만 사용. 위험 신호는 alert-red dot.
4. **단일 product-shadow** — 원단 사진 (제품) 에만 그림자. UI 카드엔 shadow 절대 금지.
5. **타이포 위계 고정** — Hero 56-72px / Display-lg 40-56px / Body 17px / Caption 14px.
6. **8개 심리·인지과학 프레임워크 분산 배치** — 각 섹션이 1-2개 프레임워크에 대응.
7. **4티어 차등** — luxury 는 섹션 일부 생략·여백 60%↑, value 는 가격·비교 강조.

## 2. 각 섹션 상세 사양

### 01. Cover (커버) — Peak-End 첫 절정

```
┌─────────────────────────────────────┐
│                                     │
│         [ 빅 비주얼 — 풀폭 ]         │  ← 16:9 또는 4:3
│                                     │
│         디안 SS26                    │  ← eyebrow 12px / 0.12em
│         리넨 워시드 컬렉션            │  ← display-xl 64-72px tight
│                                     │
│    빛에 가장 가까운 결.              │  ← lead 24-28px weight 300
│                                     │
│    [ 샘플 보기 ]  [ 컬렉션 ]         │  ← pill CTAs (Action Blue)
│                                     │
└─────────────────────────────────────┘
```
- **Padding**: section-pad (`clamp(80px, 12vw, 192px)` 상하)
- **Image**: 풀-블리드, product-shadow 적용
- **Copy 길이**: headline 12자 이내, lead 25자 이내
- **luxury 변형**: 검정 tile + 텍스트 흰색, 가격 미노출
- **value 변형**: 라이트 tile + 가격 prominent

### 02. Big Idea (빅 아이디어) — 한 문장의 임팩트

```
┌─────────────────────────────────────┐
│                                     │
│                                     │  ← 위 80px+ air
│                                     │
│     공간이 입을 수 있는              │  ← display-xl 56-72px
│     가장 부드러운 옷.                │  ← Apple-tight -0.028em
│                                     │
│                                     │  ← 아래 80px+ air
│                                     │
└─────────────────────────────────────┘
```
- **표면**: dark tile (#272729) — Apple alternating 핵심
- **Padding**: section-pad-sm (`clamp(64px, 8vw, 128px)`)
- **Copy**: 한 문장. 16-30자. 마침표.
- **No image, no CTA** — 텍스트 자체가 주연
- **luxury 변형**: 폰트 weight 300 으로 떨어트려 더 절제

### 03. Material (소재) — 감각통합

```
┌─────────────────────────────────────┐
│  [ 마크로샷 PNG ]   소재             │  ← 좌 이미지 / 우 텍스트
│   결이 보이는 큼     ────             │
│   극도의 디테일      100% 워시드 리넨  │  ← display-md 32-40px
│                     ────             │
│                     부드럽고 서늘한    │  ← lead 22-24px
│                     결, 손끝에 머무는  │
│                     무게감.           │
│                                      │
│                     · 생활 직조        │  ← bullets 14px
│                     · 자연 워싱        │
│                     · 통기성           │
└─────────────────────────────────────┘
```
- **Layout**: 2-column desktop / 1-column mobile (이미지 위·텍스트 아래)
- **Image aspect**: 4:3 마크로샷, 손이 만지는 모습 권장 (거울뉴런 보너스)
- **Copy**: 촉감 단어 필수 ("부드럽다", "서늘하다", "무게감")
- **Bullets**: 3개. 사실 위주.

### 04. Color (컬러) — 인지적 용이성

```
┌─────────────────────────────────────┐
│           컬러                       │  ← display-md
│           ────                       │
│           4가지의 자연.               │  ← lead
│                                      │
│   ┌────┐  ┌────┐  ┌────┐  ┌────┐    │  ← 컬러칩 그리드
│   │아이│  │그레│  │모스│  │인디│    │
│   │보리│  │이지│  │    │  │고  │    │
│   └────┘  └────┘  └────┘  └────┘    │
│   여명     안개     숲     심해       │  ← 컬러 스토리
└─────────────────────────────────────┘
```
- **Layout**: 4 컬러칩 그리드 (2-col mobile / 4-col desktop)
- **Color chip**: 정사각 (180×180), 1px hairline border
- **Copy**: 각 컬러 한 단어 스토리 ("여명", "안개", "숲", "심해")
- **Optional**: 호버 시 결 macro 미리보기

### 05. Size & Specs (스펙) — 권위

```
┌─────────────────────────────────────┐
│           스펙                        │
│           ────                        │
│                                      │
│   폭         150 cm                   │  ← caption-strong + tabular-nums
│   ──────────────────────              │  ← hairline 1px
│   중량       280 g/m²                 │
│   ──────────────────────              │
│   소재       워시드 리넨 100%          │
│   ──────────────────────              │
│   세탁       찬물 손세탁               │
│   ──────────────────────              │
│   원산지     벨기에                    │
└─────────────────────────────────────┘
```
- **Layout**: 단순 표 (명시적 그리드 안 씀, hairline divider)
- **Typography**: 14px / 600 라벨 + 17px / 400 값 (tabular-nums)
- **Padding**: section-pad-sm
- **Copy**: 5-7행. 더 길면 "더 보기" collapse

### 06. Use Case (시공 사례) — 사회적 증거 + 거울뉴런

```
┌─────────────────────────────────────┐
│           시공 사례                   │
│           ────                       │
│           디자이너의 손이 닿은 공간.   │
│                                      │
│   ┌──────────┐   ┌──────────┐        │  ← 2-column 시공 사진
│   │ [SHOT 1] │   │ [SHOT 2] │        │
│   └──────────┘   └──────────┘        │
│   하나인테리어    럭셔리리빙           │  ← caption (디자이너명)
│   거실 커튼       마스터 베드룸        │
└─────────────────────────────────────┘
```
- **Image**: 2개 (또는 3-4개 carousel). 사람·손·공간의 흔적 우선
- **Caption**: 디자이너·스튜디오명 + 공간 종류
- **Aspect**: 4:3 또는 3:4
- **Apple 톤**: 사진은 가장 큰 자산. Cropping 절제.

### 07. Designer Voice (디자이너 인용) — 거울뉴런 / 권위

```
┌─────────────────────────────────────┐  ← dark tile
│                                      │
│     "이 결이 빛을                     │  ← display-lg 40-48px
│      덜어낸다."                       │  ← Apple 인용 톤
│                                      │
│     김 OO  ·  하나인테리어            │  ← caption white 60%
│     수석 디자이너                      │
│                                      │
└─────────────────────────────────────┘
```
- **표면**: dark tile (#272729) + 흰 텍스트
- **Layout**: 단일 인용 (가운데 정렬). 한 명만.
- **Copy**: 인용 1-2문장 (12-24자). 따옴표 한국어 "  "
- **Image**: 옵션 — 디자이너 작업실 분위기 풀-블리드 배경 + 텍스트 오버레이
- **권위**: 실명 + 직책 (가능한 경우)

### 08. Compare (비교) — 인지적 용이성

```
┌─────────────────────────────────────┐
│         비교                         │
│         ────                         │
│         일반 소재 vs 디안 워시드 리넨  │
│                                      │
│   ┌──────────┐   ┌──────────┐        │
│   │ 일반     │   │ 디안     │        │  ← Before / After
│   │ [SHOT]   │   │ [SHOT]   │        │
│   │ 빳빳함   │   │ 부드러움 │        │  ← caption-strong
│   │ 광택     │   │ 무광     │        │
│   └──────────┘   └──────────┘        │
└─────────────────────────────────────┘
```
- **Layout**: Before/After 좌우 분할 (모바일 상하)
- **Copy**: 각 항목 1-2 단어 (대조)
- **value 티어**: 가격 비교까지 추가 가능
- **luxury 티어**: 이 섹션 생략

### 09. Lifestyle (라이프스타일) — peak

```
┌─────────────────────────────────────┐
│    [ 풀-블리드 인테리어 완성샷 ]      │  ← 풀-블리드 (16:9 또는 21:9)
│                                      │
│           아침의 무게.                │  ← 좌하단 또는 가운데 caption
│                                      │
└─────────────────────────────────────┘
```
- **Image**: 풀-블리드. 아침 빛·정오·황혼 중 하나의 mood
- **Copy**: 시적 한 줄 (10자 이내)
- **No CTA** — 분위기만
- **luxury 시그니처 섹션**

### 10. Craftsmanship (장인성) — 스토리브랜드

```
┌─────────────────────────────────────┐  ← dark tile
│      장인의 결                        │  ← display-md white
│      ────                            │
│                                      │
│  [ 손·직기·공장 사진 ]                │  ← 16:9
│                                      │
│  벨기에 직조사 Libeco. 1858년부터    │  ← body 흰 70%
│  같은 손으로 짠 침묵의 결.            │
│                                      │
└─────────────────────────────────────┘
```
- **표면**: dark tile (alternating rhythm)
- **Image**: 손·직기·공장. **사람의 손이 핵심** (거울뉴런)
- **Copy**: 2-4문장. 역사·장소·연도·이름
- **Apple 톤**: 그림자·필터 없음. 자연광.
- **luxury 시그니처**

### 11. Authority (인증·보증) — Cialdini 권위

```
┌─────────────────────────────────────┐
│      인증·보증                       │
│      ────                            │
│                                      │
│   [icon] OEKO-TEX 100                │  ← 4-column 아이콘 + 짧은 라벨
│   인증     화재 인증     디안 보증     │
│                                      │
│   교환·환불 14일 · 샘플 무상           │  ← 짧은 정책 한 줄
└─────────────────────────────────────┘
```
- **Layout**: 4 column icon row (모바일 2x2 grid)
- **Icon**: 단순 lucide 아이콘 + 1줄 라벨 (10-15자)
- **Copy**: 정책 한 문장
- **value 티어**: 화재 인증 prominent
- **luxury 티어**: "장인 보증" 같은 정성적 인증

### 12. FAQ — 인지적 용이성

```
┌─────────────────────────────────────┐
│      자주 묻는 질문                   │
│      ────                            │
│                                      │
│   세탁 가능한가요?              ▼     │  ← collapsible (또는 항상 펼침)
│   ───────────────────                │
│   배송은 며칠 걸리나요?         ▼     │
│   ───────────────────                │
│   샘플 받을 수 있나요?          ▼     │
│   ...                                │
└─────────────────────────────────────┘
```
- **Layout**: 5-10개 질문, hairline divider 만
- **Copy**: 질문 17px / 600, 답 17px / 400
- **luxury 티어**: 이 섹션 생략 (개별 문의 채널만)
- **value 티어**: 10개+, 가격·할인·결제 질문 포함

### 13. CTA / Closing (마무리) — Peak-End 마지막 절정

```
┌─────────────────────────────────────┐  ← dark tile (또는 풀 빅 비주얼)
│                                      │
│    [ 마지막 풀폭 비주얼 ]             │
│                                      │
│         지금, 결을 만나세요.           │  ← display-xl 56-72px
│                                      │
│    [ 샘플 무상 신청 ]  [ 미팅 예약 ]   │  ← pill CTAs
│                                      │
│    한정 50롤. 이번 주 입고.            │  ← caption (희소성, 옵션)
│                                      │
└─────────────────────────────────────┘
```
- **표면**: dark tile + 흰 텍스트, 또는 풀-블리드 비주얼 + 텍스트 오버레이
- **CTAs**: 2개 pill (primary + outline)
- **희소성** (옵션): "한정 50롤", "이번 주 입고", "Price upon request"
- **luxury 티어**: CTA 1개만 ("Price upon request") + 더 긴 여백
- **value 티어**: 가격 prominent + "지금 구매" CTA
